# 桌面端概览与安装

本页介绍共工空间桌面端是什么、怎么安装、首次打开怎么处理、怎么升级，以及它和命令行 `gg` 的关系。

## 桌面端是什么

桌面端是一个自带 daemon 的应用，支持 macOS 和 Windows。装好后**不需要再装命令行 `gg`**，也不用一直开着终端窗口：

- **内置 daemon**：应用本身就是这台机器的执行端，接收派给本机 Bot 的任务，调用本机的 Claude Code、Codex 等 Agent 干活。
- **常驻后台**：关掉窗口后程序仍在后台运行，菜单栏（Windows 为托盘）图标里有「打开」和「退出」两项。macOS 上点 Dock 图标也能把窗口叫回来。
- **图形化查看与管理**：本机的 Agent、Bot、工作区、穿透与服务、实时画面、市场、日志诊断和设置都能在窗口里查看，见 [功能页面](/desktop/pages)。
- **自带推流组件**：Bot 推送桌面应用、小程序实时画面用的 gg-cast 已内置在 macOS 安装包里，不用另外下载。

## 支持平台

| 平台 | 安装包 |
| --- | --- |
| macOS · Apple 芯片（M 系列） | `Gonggong_<版本>_aarch64.dmg` |
| macOS · Intel 芯片 | `Gonggong_<版本>_x86_64.dmg` |
| Windows（x64） | `Gonggong_<版本>_x64-setup.exe` |

两种 Mac 的安装包分开打包、分别签名公证，各自自动更新，装错芯片的版本无法运行。不确定芯片型号：点屏幕左上角苹果菜单 →「关于本机」查看。

Linux 没有桌面端，请使用 [命令行 gg](/cli/)。

## 安装

1. 获取安装包，任选一种：
   - 网页「绑定新机器」→「其他方式」→「① 安装客户端」：按你当前的系统推荐安装包，可在「选择系统」里切换，点「下载」。本空间还没有发布客户端时，会提示「前往 GitHub 下载」。
   - 直接从 [GitHub Releases](https://github.com/yoqu/gonggong-space/releases/latest) 下载。
2. 安装：
   - macOS：双击 dmg，把 **共工空间** 拖进「应用程序」文件夹，然后在「应用程序」里打开它。
   - Windows：双击 `setup.exe`，按安装向导完成，然后从开始菜单打开共工空间。
3. 按 [首次引导](/desktop/onboarding) 完成绑定。

::: tip 应用名称
安装后在 Finder、「系统设置」、窗口标题和菜单栏里显示的名称都是「共工空间」。早期版本的应用名是 Gonggong，装好新版后可把「应用程序」里旧的 Gonggong 删掉，绑定信息保存在 `~/.gonggong`，不受影响；若系统权限显示未授权，按 [权限与系统设置](/desktop/permissions) 重新授权即可。
:::

## 首次打开被系统拦截（macOS）

正式发布的 macOS 安装包已签名并公证，双击即可打开。如果拿到的是未签名或未公证的版本，macOS 会提示「无法打开」或「无法验证开发者」：

1. 先双击打开一次，看到提示后关闭提示框。
2. 打开「系统设置 → 隐私与安全性」，滚动到底部，点「仍要打开」。
3. 按提示输入密码确认，之后就能正常打开。

::: warning 未使用 Developer ID 签名的版本
macOS 的屏幕录制、辅助功能授权是跟应用签名绑定的。没有 Developer ID 签名的安装包每个版本的签名都不同，**升级后这两项权限会失效，需要重新授权**。详见 [权限与系统设置](/desktop/permissions)。
:::

## 升级

桌面端会自己检查更新：

- **从哪里更新**：先向已绑定的服务器检查，服务器在「客户端发布」里发布了本平台的更新包就从服务器下载；服务器没有发布时改查 GitHub Releases。
- **什么时候检查**：「设置」里的「自动升级」打开时，启动时和之后每 6 小时检查一次；也可以在「设置」的「版本」一行点「检查更新」。
- **怎么生效**：新版本在后台下载，下载好后窗口顶部提示「新版本 vX.Y.Z 已下载，重启以更新」，附更新说明。点「立即重启」完成升级，或点「稍后」。本机有任务正在运行时会先提醒「有运行中的任务，重启会中断」。
- **跨多个版本**：等待重启期间仍会继续检查，久开没重启跨了好几个版本，重启后直接升到最新。

## 退出与开机启动

- **关闭窗口不会退出**：daemon 继续在后台运行，本机 Bot 保持在线。
- **彻底退出**：点菜单栏（Windows 为托盘）的共工空间图标，选「退出」。退出后本机 Bot 显示离线，群里的消息会排队等待。
- **开机启动**：在「设置」里打开「开机启动」，登录系统后自动在后台运行。
- **隐藏 Dock 图标**（仅 macOS）：在「设置」里打开「关闭窗口后隐藏程序坞图标」，关窗后只保留菜单栏图标，从菜单栏「打开」即可回到窗口，后台服务继续运行。默认关闭。

## 与命令行 gg 二选一

桌面端和命令行 `gg` 用的是同一套本地数据（`~/.gonggong/`），包括绑定信息。因此：

- **同一台机器只能运行一个 daemon**。命令行 `gg run` 或 `gg service` 在运行时打开桌面端，概览页会提示「daemon 未运行」，说明本机已有 daemon 在运行。先停掉命令行的 daemon（`gg service uninstall` 或结束 `gg run`），再点「重试」。
- 已经用 `gg login` 绑定过的机器，打开桌面端会直接沿用这个绑定，不需要再绑一次。
- Mac、Windows 用户推荐用桌面端；Linux、服务器等没有图形界面的环境用命令行。

| | 桌面端 | 命令行 `gg` |
| --- | --- | --- |
| 平台 | macOS（Apple 芯片 / Intel）、Windows | macOS / Linux / Windows |
| 后台运行 | 关窗后菜单栏 / 托盘常驻，可开机启动 | `gg service install` 注册为后台服务，或前台 `gg run` |
| 实时画面推流组件 | macOS 安装包内置 | 首次推流时从服务器下载 |
| 升级 | 应用自动更新，重启生效 | 自动下载新版本并替换自身；Linux 可在网页一键升级 |
