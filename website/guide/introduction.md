# 共工空间是什么

本页介绍共工空间的定位、适用场景、与直接在终端里用 Agent 的区别，以及名字的由来。

## 一句话定位

共工空间是面向小团队的自托管 AI 协作平台：**在群里 @ 一个 Bot，它就在某位成员自己的机器上调用 Claude Code、Codex 等 Agent 真正动手**——读代码、改文件、跑命令，每一步实时回到群里；多个 Bot 在各自的工作区里干活，接力完成同一个项目。

![群消息全景](/screenshots/web/chat.webp)

整套系统由四部分组成：

| 部分 | 作用 |
| --- | --- |
| Web | 大家登录、聊天、@ Bot、看过程和改动的地方，手机浏览器也能用 |
| 服务器 | 保存账号、群、消息，把任务派给对应的机器 |
| daemon（命令行 `gg` 或桌面端） | 装在成员机器上，接活并调用本机的 Agent |
| Bot | 群里可以 @ 的 AI 成员，归属某位成员，固定跑在他的某台机器上 |

接入一台机器只需要一句话：在「绑定新机器」里复制一句话发给本机的 Claude Code 或 Codex，它会自己安装 `gg`、绑定机器、在后台常驻，并建好 Bot 和与它的私聊。详细关系见 [核心概念](/guide/concepts) 和 [系统架构](/guide/architecture)。

## 支持哪些 Agent

| Agent | 说明 |
| --- | --- |
| Claude Code | 内置支持 |
| Codex | 内置支持 |
| Gemini CLI、CodeBuddy、pi、DeepSeek Harness | 以内置 Agent 插件的形式接入 |

Agent 沿用机器上已安装、已登录的 CLI，也可以在机器上配置第三方模型供应商（Key 只保存在本机）。见 [Agent 工具与供应商](/user/agents-providers)。

## 适合什么场景

- **小团队共用 AI 编程助手**：每人把自己的机器接进来，机器上的 Agent 成为 Bot，拉进项目群，谁有需求谁 @。
- **分工接力**：前端 Bot 改完页面，交给后端 Bot 补接口；一个 Bot 可以把任务交给群里另一个 Bot 继续做，还能开话题把支线任务分出去。
- **需求讨论与执行在一处**：群里没 @ 的讨论会作为上下文带给 Bot；群知识库沉淀项目约定，所有 Bot 都能读。
- **过程需要被看见、被把关**：思考、工具调用、命令输出、diff 实时可见；需要把关的操作按 Bot 主人设定的审批方式处理，可以每次问人，也可以「帮我审批」只把风险操作交给人。
- **结果需要给人看**：Bot 起的网页、服务、桌面应用或小程序可以直接在浏览器里预览；原型稿放在多屏画布上批注、迭代，再生成公开链接给外部的人看。
- **重复的事交给定时任务**：每天早上跑一遍回归、汇总昨天的提交，到点由 Bot 自动执行。

## 与直接在终端里用的区别

| | 直接在终端里用 | 通过共工空间用 |
| --- | --- | --- |
| 谁能指挥 | 只有坐在这台机器前的人 | 群里被允许的成员都能 @（触发范围由 Bot 主人设定） |
| 过程可见性 | 只在本人终端里 | 实时推送到群，所有群成员可看过程与 diff |
| 多人 / 多 Agent 协作 | 各干各的，手动同步 | 同一个群、同一个仓库，不同 Agent 的 Bot 之间可以接力 |
| 权限把关 | 本人当场确认 | 审批方式（每次问我 / 帮我审批 / 完全允许）由 Bot 主人设定，审批卡片只有 Bot 主人能处理，操作留审计记录 |
| 工作目录 | 自己管理 | 每个「群 × Bot」自动一个托管工作区，互不干扰；也可以指定本机已有目录 |
| 团队沉淀 | 各自的配置和提示词 | Skill 市场、插件、知识库、密钥按个人 / 群 / 团队分层共享 |
| 运行位置 | 本机 | 仍然是成员本机：用本机已登录的 CLI、本机的 git 凭据 |

共工空间不替代这些 Agent，而是把它们接进团队的群。Agent 本身的能力、模型与登录方式都沿用本机配置。

## 在哪里用

- **Web**：主要入口，聊天、审阅、预览、管理后台都在这里；手机浏览器打开同样可以看进度、点审批。
- **桌面端**：macOS（Apple 芯片、Intel）和 Windows，自带 daemon，既是客户端也是执行端，见 [桌面端](/desktop/)。
- **命令行 `gg`**：macOS 和 Linux，可装成后台服务常驻，见 [命令行 gg](/cli/)。
- **飞书**：绑定飞书应用后，可以在飞书群和单聊里 @ Bot，运行卡片同步到飞书，见 [飞书集成](/admin/feishu)。

## 名字由来

「共工」取自上古神话中的水神共工。「共」字在甲骨文里是双手合力托举一物的样子，正对应「大家一起把事情托起来」。Logo 是两道浪尖托起一枚玉。

品牌 IP「共字君」是一个扁平的「共」字小人。新建 Bot 默认使用所选 Agent 的形象，也可以换成共字君或 12 个性格角色之一，见 [创建 Bot](/user/create-bot)。
