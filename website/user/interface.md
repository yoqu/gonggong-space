# 界面导览

本页介绍 Web 端主界面的布局：欢迎页、左侧导航栏、会话侧栏、消息区、右侧的侧栏和工作台，以及窄屏下的变化。

## 欢迎页

还没有加入任何群时，主区域显示欢迎页。

![欢迎页](/screenshots/web/welcome.webp)

**自己搭 Bot 的成员**看到一段使用演示和三步引导，完成的步骤会打勾并显示「已完成」：

1. **绑定新机器**：复制一句话发给本机的 Claude Code 或 Codex，它会自己安装、绑定这台机器并建好 Bot，见 [绑定机器](/user/bind-machine)。
2. **新建 Bot**：选择机器上的 Agent，给它起个好认的名字，见 [创建 Bot](/user/create-bot)。
3. **发起第一次对话**：和你的 Bot 私聊，或拉上同事建群，见 [群与私聊](/user/groups)。

**只在群里 @ Bot 的成员**看到的是简版：可以点「接入我的电脑，搭自己的 Bot」走上面的三步；侧栏里有可加入的群时，点「查看可加入的群」申请加入；也可以等同事把你拉进群，在群里 @ Bot 直接提问。

加入群后，侧栏里仍会显示一张「开始使用」卡片，直到三步都完成。头像菜单的「新手指引」可以随时重新打开新手引导。

## 整体布局

![主界面全景](/screenshots/web/interface.webp)

从左到右依次是：

| 区域 | 内容 |
| --- | --- |
| 导航栏 | 消息、作品、市场、机器与 Bot、通知、管理后台；最下方是头像菜单 |
| 侧栏 | 会话列表；在「机器与 Bot」里换成机器与 Bot 的树 |
| 消息区 | 当前群或私聊的消息、输入框 |
| 右侧 | 群信息、话题等侧栏，或打开了标签页的工作台 |

宽屏下再次打开网页，会自动回到上次打开的群。

## 导航栏

| 按钮 | 作用 |
| --- | --- |
| 消息 | 回到会话列表，角标是所有未免打扰的群的未读数 |
| 作品 | 作品库，团队开启了创作类插件时才出现，见 [原型、画布与作品库](/user/artifacts) |
| 市场 | Skill 与插件市场，见 [Skill 市场与插件](/user/market-plugins) |
| 机器与 Bot | 你的机器和 Bot，见 [我的机器与 Bot](/user/machines) |
| 通知 | 打开通知面板，角标是未读通知数，见 [通知](/user/notifications) |
| 管理后台 | 仅系统管理员可见，见 [管理后台](/admin/) |
| 头像 | 头像菜单，见 [登录与账号](/user/login#头像菜单) |

::: tip
「市场」和「机器与 Bot」是搭 Bot 用的。还没有机器、Bot，也不是群管理员或团队管理员的成员，导航栏默认不显示这两项；点头像菜单的「接入我的电脑」后出现。
:::

## 会话侧栏

顶部是「共工空间」标题（加入了多个团队时换成团队切换器）和「+」（发起会话），下面是搜索框。点搜索框或按 `⌘K`（Windows / Linux 为 `Ctrl K`）可以搜索会话、消息、文件、运行。

「+」打开的对话框里可以「发起会话」（选成员和 Bot：只选一个自己的 Bot 就是私聊，否则建群），也可以切到「新建终端」，见 [群与私聊](/user/groups) 和 [我的机器与 Bot](/user/machines#终端会话)。

搜索框下面依次是：

- **快捷入口**：「话题」（我关注的话题及新回复）、「全部未读」、「稍后处理」（收藏的消息与提醒）；
- **分区**：「星标」、团队分区、你自己建的个人分区、「频道」（群）、「私信」（私聊）。群和私聊按最新消息排序，可以拖到别的分区，分区可以折叠；
- **已完成**：标记为「完成」的会话收在最下面的「已完成 · N」里；
- **终端**：你开的机器终端会话；
- 有标记过的会话时，顶部会出现「只看已标记」筛选。

每行显示最近一条消息；正在运行、未读数、草稿、免打扰都会在行上标出。右键（或行上的菜单）可以加星标、移到分区、设置通知、清除未读、完成、标记、打开群信息、复制频道链接、离开频道等，详见 [群与私聊](/user/groups)。

侧栏底部是状态行：与服务器的连接（已连接 / 连接中… / 已断开 · 重连中）、在线 Bot 数和在线机器数。

::: tip 键盘操作
焦点在会话列表上时，用 `↑` `↓` `Home` `End` 切换并打开会话。
:::

## 消息区

消息区顶部是群头部：群头像、群名，副标题是群公告的第一行和绑定的仓库与分支（未绑定仓库时显示「未绑定仓库 · 各 Bot 使用本机目录」；私聊里显示 Bot 用的是托管工作区还是本机目录）。右侧几个按钮：

- **群成员**（私聊没有）：数字是人数，打开群信息侧栏的成员列表。
- **话题**：打开本群的话题列表，见 [定时任务与话题](/user/schedules-threads)。
- **工作台**：显示或隐藏右侧工作台，数字是已打开的标签页数。
- **群设置**：打开或关闭群信息侧栏。

群头部下方是群标签栏、Git 条和 Bot 条（分支、同步状态、上下文占用等），再往下是消息列表和输入框。这些内容分别见 [在群里指挥 Bot](/user/chat)、[运行过程](/user/runs)、[Git 管理](/user/git)。

## 右侧：侧栏

点击「群设置」或「群成员」打开群信息侧栏，显示群成员、Bot、公告等，内容见 [群与私聊](/user/groups)；点「话题」打开话题列表。侧栏左边缘可以拖动调整宽度（也可以聚焦后用 `←` `→` 调整），宽度会记在当前浏览器里。窗口宽度小于 1100px 时，侧栏默认收起。

## 右侧：工作台

在消息里打开运行过程、代码改动、文件或预览时，内容会以标签页的形式出现在消息区右边的工作台里。每个群有自己的一组标签页，最多 12 个。

![分栏布局：消息区右侧是工作台，当前为网页预览](/screenshots/web/workbench-split.webp)

常见的标签页：

| 标签页 | 内容 |
| --- | --- |
| 运行（`Bot 名 · 第 N 轮`） | 一轮运行的「过程」「改动」「上下文」「审批记录」，见 [运行过程](/user/runs) |
| 改动 | Bot 工作区的未提交改动，见 [代码变更与文件](/user/diff-files) |
| 文件 | Bot 工作区的文件树和文件内容 |
| Git | 提交、日志、贮藏、比较与冲突解决，见 [Git 管理](/user/git) |
| 终端 | Bot 工作区里的交互式 Shell（仅机器主人） |
| 知识库 / 原型 | 知识库条目、原型画布，见 [知识库与密钥](/user/knowledge-secrets)、[原型、画布与作品库](/user/artifacts) |
| 预览 / 小程序 / 桌面应用 | Bot 发布的网页、小程序或实时画面，见 [结果预览](/user/previews) |

工作台标签栏上的「+」（新建标签页）可以打开网页、添加群标签、浏览某个 Bot 的文件、打开它的 Git 面板或新建终端。

### 网页预览

工具栏可以刷新、输入路径、切换视口宽度（自适应 / 1440 / 1024 / 768 / 390）、在新窗口打开，以及生成「公开链接…」。

![网页预览标签页](/screenshots/web/workbench-web.webp)

### 小程序与桌面应用

小程序和桌面应用以实时画面显示。默认「仅观看」，点「开始控制」可以远程操作；帧率和画质可以调整，右上角可显示画面数据。

![小程序标签页](/screenshots/web/workbench-miniprogram.webp)

多人同时查看时，别人可以请求控制，当前控制者选择「同意」或「拒绝」，也可以随时「交还控制」。

![桌面应用标签页（实时画面与远程操作）](/screenshots/web/workbench-live.webp)

### 布局

工作台右上角可以切换三种布局：

| 布局 | 效果 | 快捷键 |
| --- | --- | --- |
| 分栏 | 会话列表、消息区、工作台并排 | `⌘\` 在分栏与专注间切换 |
| 专注 | 会话列表收成一列头像，给工作台更多空间 | `⌘\` |
| 全屏 | 消息区收成一条窄栏，工作台占满；按 `Esc` 返回 | `⌘⇧\` |

![专注布局](/screenshots/web/workbench-focus.webp)

![全屏布局](/screenshots/web/workbench-fullscreen.webp)

其他快捷键：`⌃Tab` / `⌃⇧Tab` 切换标签页，`⌥W` 关闭当前标签页（Windows / Linux 上 `⌘` 换成 `Ctrl`）。右键标签页可以「关闭其他标签页」「关闭右侧标签页」。消息区与工作台之间的分隔条可以拖动调整聊天栏宽度。

::: tip
窗口宽度小于 1100px 时没有「分栏」，会自动使用「专注」。网页预览标签页只保持最近使用的 4 个处于活动状态，其余的会休眠（标签上显示月亮图标）以节省内存，重新点开即恢复。标签页可以拖动排序。
:::

## 窄屏布局

窗口宽度小于 768px（如手机）时，界面变成单栏：

- 首页就是会话列表，导航栏变成底部标签栏（导航栏的各项和头像）。
- 点进一个群后只显示消息区，左上角的返回按钮回到会话列表。
- 群信息侧栏以浮层形式覆盖在消息区上。
- 工作台变成全屏页面，标签页收在顶部的下拉菜单里，点「返回聊天」回到消息区，草稿和滚动位置都会保留。
- 滑动消息区时，顶部条会收起、输入框缩小，回到底部或点输入区即恢复。
- 与服务器断开时，顶部会出现「连接已断开，正在重连…」。
