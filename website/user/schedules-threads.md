# 定时任务与话题

本页讲两件事：让 Bot 到点自动干活的**定时任务**，以及把一件事拆出去单独讨论的**话题**。

## 定时任务

定时任务到点由 Bot 自动执行一段指令，例如「每个工作日 9 点汇总昨天的 PR」。

![定时任务列表与编辑](/screenshots/web/schedules.webp)

### 在哪里看

- **群设置侧栏 →「定时任务」**：列出本群全部定时任务，显示「N / 20 个」。私聊的「私聊设置」里也有。
- **输入框上方的时钟按钮**：有启用中的任务时出现，显示「定时任务：N 个」。点开能看到每个任务的下次执行时间和最近结果，「管理」跳到列表。
- **群里的任务卡片**：新建任务时群里发一条「某某 创建了定时任务「…」」的卡片，卡片上可以直接「暂停」「恢复」「立即执行」「编辑」「删除」。

列表每行显示名称、执行时间、候选 Bot，以及状态：「下次 …」「已停用：原因」，跑过的还显示「最近 … · Bot 结果」。结果可能是「完成」「中断」「无权触发」「离线作废」「跳过」等。Bot 建的任务标「Bot 创建」。

### 新建定时任务

1. 在列表里点「新建定时任务」。
2. 填「名称」（最多 60 个字），如「每日 PR 汇总」。
3. 填「指令」（最多 4000 个字）：到点发给 Bot 的完整指令，写清要做什么、范围和产出。
4. 在「候选 Bot · 到点由第一个可用的执行」里点「+ Bot 名」添加 Bot，可以加多个并调整顺序（最多 10 个）。每个候选 Bot 可以单独选模型与推理强度。
5. 在「执行时间」里选频率并填时间，下方实时显示「接下来：…」几次执行时刻。
6. 点「创建」。

| 频率 | 要填的 |
| --- | --- |
| 每天 | 时间 |
| 每个工作日（默认，09:00） | 时间 |
| 每周 | 星期几和时间 |
| 每月 | 日期（每月第几日）和时间 |
| 仅一次 | 执行时刻 |
| 自定义 | cron 表达式，格式「分 时 日 月 周」（0 = 周日），如 `*/30 9-18 * * 1-5` |

- 时区用你浏览器所在的时区。
- 两次执行至少间隔 5 分钟，否则提示「执行间隔不能小于 5 分钟」。
- 每个群最多 20 个定时任务。

### 到点时发生什么

- 到点后，群里以**任务主人**（创建它的人）的身份发出一条 `@Bot 指令` 的消息，标「定时任务」。之后和主人亲自 @ Bot 一样：按主人的身份校验触发权限，需要审批时找 Bot 主人。
- 候选 Bot 里取第一个在线且空闲的；都在忙就用第一个在线的并排队。
- 每次都在**独立的新会话**里运行，不续接群里的对话，运行卡片注明「定时任务在独立的新会话中运行」。
- 上次还没跑完时，本次跳过，群里提示「定时任务「…」上次尚未结束，本次跳过」；候选 Bot 都不可用时也跳过。
- 服务器停机错过的重复任务，恢复后补跑一次再按计划继续；「仅一次」的任务错过超过 24 小时就不再执行。

### 管理与停用

| 操作 | 说明 |
| --- | --- |
| 启用开关 / 暂停、恢复 | 停用后不再按时执行；重新启用会清零失败计数 |
| 立即执行 | 马上跑一次，不受启停和时间影响，也不改变下次执行时间。提示「已触发「…」，结果见群聊」 |
| 编辑 | 改名称、指令、候选 Bot 和时间 |
| 删除 | 在群里的任务卡片上点「删除」，再点「确认删除」 |

- 任何成员都可以查看和新建；只有任务主人和群管理员可以编辑、启停、立即执行和删除，否则提示「仅任务主人或群管理员可操作」。
- 候选 Bot 的模型与推理强度只有 Bot 主人或群管理员能改。

任务在以下情况自动停用，群里提示「定时任务「…」已停用：原因」，任务主人收到「定时任务已停用」通知：

- 连续 3 次失败
- 主人已不在群内
- 候选 Bot 都已不在群内
- 仅一次的任务已执行
- 错过执行时间超过 24 小时

### 让 Bot 帮你建

直接在群里说就行，如「@后端助手 每个工作日 9 点汇总昨天合并的 PR 发到群里」。Bot 会用内置工具建好任务，群里出现任务卡片，列表里标「Bot 创建」。

- Bot 建的任务归**发起这一轮的人**所有，默认只有这个 Bot 一个候选，时区为北京时间（Asia/Shanghai）。
- Bot 只能修改或删除自己建的、或候选里有它的任务。
- 任务跑起来后，Bot 知道自己是被哪个定时任务触发的，不再需要时可以自己删掉它。

## 话题

话题让一条消息下面的讨论单独成串，不刷主聊天。Bot 在话题里被 @ 时，用**独立的会话**干活，和群里的主会话互不影响。

![话题侧栏](/screenshots/web/thread.webp)

### 开始话题

- 鼠标移到消息上点「回复话题」，或在右键菜单里选它。任何成员或 Bot 的普通消息都可以开话题。
- 右侧打开话题面板：顶部是原消息，下面是「N 条回复」和回复列表，回复里的运行卡片照常显示。
- 在话题输入框（提示「回复话题，@ 触发 Bot」）里发消息；@ Bot 就在话题里起运行。
- 勾选「同时发送到群」，这条回复也会出现在主聊天里，标「回复了话题」，点它可以回到话题。

有话题的消息下方显示一条回复条：参与者头像、「N 条回复」（有新回复时显示「N 条新回复」和「@我」）、「最后回复 …」；有 Bot 正在话题里干活时显示「Bot 回复中」。

### Bot 在话题里

- 每个 Bot 在每个话题里有自己的会话，第一次运行时会读整个话题（含原消息）。
- 没有同时发送到群的话题回复，不会作为背景上下文带给主聊天里的 Bot。
- 输入框上方的任务栏里，话题中的运行标「话题」，点一下回到话题。
- 在话题里发 `/new @Bot`，只重置这个 Bot 在该话题里的会话。

**Bot 回复进话题**：群管理员在「群设置 → 基本信息」打开后，在群里 @ Bot 时，它的回复自动放进这条消息的话题，不刷屏。私聊没有这个开关。

**Bot 开话题**：Bot 在干活中可以开一个话题，并指派一个 Bot（可以是它自己）在话题里接手，适合把一项任务拆出去单独讨论和推进。群和私聊都可以。

- 话题标题立刻以 Bot 的名义发出；本轮结束后，被指派的 Bot 在话题里被 @ 并开始干活。
- 发起这一轮的人自动关注这个话题。
- 每轮最多开 3 个话题；算在接力链里，受群级参数「接力链长上限」限制（默认 3 跳）。

### 关注与提醒

以下几种人自动关注话题：原消息的作者、在话题里回复过的人、在话题里被 @ 的人。

- 话题面板顶部可以「关注」或「取消关注」。
- 别人在你关注的话题里回复，算作新回复；Bot 在话题里回复你发起的任务，算作 @ 你，会收到「Bot 回复了我」通知。
- 本群通知设为「全部」时，话题回复只提醒关注者。

### 在哪里找话题

| 入口 | 内容 |
| --- | --- |
| 群头部「话题」按钮 | 本群全部话题：有 Bot 正在回复的排前面，其余按最新回复排序，有 @ 你的标「[有人@我]」 |
| 会话列表顶部「话题」 | 你关注的全部话题，按最新回复排序。数字只计**有人 @ 你**的话题，只有新回复时仅加粗 |

在「话题」收件箱里，每张卡片显示所在群、最新几条回复，可以直接「回复」，或「标为已读」「取消关注」；顶部有「全部标为已读」。
