# 群与私聊

本页讲怎么发起群和私聊、整理会话列表、公开频道与入群申请、拉人拉 Bot、群设置里的各项，以及退出和解散。

- **群**：团队成员和多个 Bot 一起协作，可以绑定 git 仓库。群分「公开频道」和「私有群」。
- **私聊**：只有你和一个 Bot（你自己的，或别人共享给你的），适合个人使用或试用 Bot。

## 发起会话

群和私聊都从同一个入口创建：点会话列表顶部的「+」（「发起会话」）。还没有会话时，列表里的「发起会话」按钮也能进入。

![发起会话对话框](/screenshots/web/new-group.webp)

对话框顶部有两个页签：「发起会话」和「新建终端」。「新建终端」用来在自己的机器上开一个终端会话，见 [我的机器与 Bot](/user/machines)。

在「发起会话」里：

1. 在「Bot」里点「添加 Bot…」，选一个或多个 Bot。候选分「我的 Bot」「其他成员的 Bot」两组，我的 Bot 按最近使用排在前面；搜索框支持拼音（全拼、首字母、混拼都行，如 `jwc` 能搜到「姜维川」）。
2. 在「成员」里点「+」添加同事。
3. 需要改代码时，在最下方选择仓库和「基准分支」，见 [仓库与工作区](/user/repos-workspaces#绑定仓库)。
4. 填「名称」（最多 60 个字），需要的话打开「公开频道」。
5. 点「创建群」或「开始私聊」。

**建出来的是群还是私聊**，由你选的内容决定：

- 只选了一个你自己的（或共享给你的）Bot，并且没加任何成员：创建私聊，按钮显示「开始私聊」，并提示「将创建与它的私聊，之后不能再加人」。私聊不用填名称。
- 其他情况都是群，按钮显示「创建群」，必须填名称。

建群时：

- 你自动成为群管理员。
- 拉入别人的 Bot 时，Bot 主人自动加入群（标注「Bot 主人」）。
- 未绑定机器或待确认的 Bot 不能拉入，显示「待绑定，暂不能拉入」或「待确认，暂不能拉入」。
- 填了仓库但没改过名称时，名称自动取仓库名。
- 仓库检查期间按钮显示「检查中…」；基准分支不存在时不能创建。

::: tip 从飞书群创建
系统管理员配置了飞书主应用后，对话框底部会出现「从飞书群创建…」，可以直接用一个已有的飞书群建出对应的群并绑定，详见 [飞书](/admin/feishu#在飞书群里使用-bot)。
:::

### 私聊的特点

- 私聊不能添加其他成员，也不能拉入别人的 Bot。
- 只有一个 Bot 的私聊里发消息不用 @，直接触发它。
- 私聊默认显示 Bot 的名字，可以在「私聊设置 → 基本信息」里改「私聊名称」。
- 和别人共享给你的 Bot 私聊时，标题下方显示「某某 共享的 Bot」，Bot 在独立的托管工作区里干活，不碰主人的目录；共享取消或 Bot 删除后，私聊变为只读。

## 会话列表

左侧会话列表按「星标」「频道」「私信」分区，你也可以建自己的分区。在会话上**右键**（触屏长按）打开菜单：

| 菜单项 | 作用 |
| --- | --- |
| 加星标 / 取消星标 | 放进或移出「星标」分区 |
| 移到分区 | 归入自己建的分区，或「新建分区…」 |
| 归入团队分区 | 群管理员或团队管理员把群归入团队分区（见下文） |
| 通知 | 本会话的提醒档位：「全部」「仅@」「关闭」，见 [通知](/user/notifications#每个会话的提醒档位) |
| 清除未读 | 把这个会话标为已读 |
| 完成 / 移回列表 | 处理完的会话收进底部「已完成」 |
| 标记 / 取消标记 | 打旗标，之后可以「只看已标记」 |
| 打开群信息 / 私聊设置 | 打开右侧群设置侧栏 |
| 复制频道链接、离开频道 | 仅群 |

- 会话可以直接拖进分区。分区标题旁的菜单可「重命名…」「新建子分区…」「上移」「下移」「删除分区」，最多三级。删除分区后，里面的会话回到默认分区。
- 列表顶部还有「话题」「全部未读」「稍后处理」三个入口，见 [定时任务与话题](/user/schedules-threads#话题) 和 [通知](/user/notifications#未读)。

## 公开频道与入群申请

### 公开频道

群分两种：

| 类型 | 谁能进 |
| --- | --- |
| 公开频道（名称前标 `#`） | 团队成员可在「浏览频道」里找到并自行加入 |
| 私有群（名称前标锁） | 只能由成员拉进来；归入团队分区后，其他人可以申请加入 |

建群时打开「公开频道」，或由群管理员在「群设置 → 成员」里打开。

点会话列表顶部的「浏览频道」，可以按名称搜索，按「全部」「已加入」「未加入」筛选，按「最近活跃」「人数最多」「名称」排序。没加入的点「加入」即可进群。

### 团队分区与入群申请

团队管理员可以在会话列表底部「新建分区」→「团队分区…」建立团队分区，团队所有成员都能看到。群管理员可以在「群设置 → 成员 → 团队分区」或右键菜单「归入团队分区」里把群放进去。

团队分区里你还没加入的群显示「未加入」，点开是入群预览：

- 公开频道：点「加入」直接进群。
- 私有群：可以填「申请说明」（选填）后点「申请加入」，等群管理员处理；处理前可以「撤回申请」。

群管理员会收到「待处理入群申请」通知，也可以在「群设置 → 成员」底部的「入群申请」里「同意」或「拒绝」。

## 群设置侧栏

点群头部的「群设置」按钮，打开右侧「群设置」侧栏（私聊为「私聊设置」）。点群头部的成员按钮直接进入「群成员」页。

![群设置侧栏](/screenshots/web/group-info.webp)

侧栏从上到下：

- **群名与标签**：标注「公开频道」或「私有群」，以及同步模式；下方是仓库地址与基准分支，未绑定时显示「未绑定仓库 · 各 Bot 使用本机目录」。
- **快捷按钮**：「成员」「公告」（仅群管理员）「设置」。
- **成员头像**：可在这里添加成员。
- **Bot**、**预览与服务**、**定时任务**、**知识库**、**群公告**：点开进入对应子页面。定时任务和知识库见 [定时任务与话题](/user/schedules-threads) 和 [知识库与密钥](/user/knowledge-secrets)，预览见 [结果预览](/user/previews)。
- **个人设置**（只对自己生效）：

| 设置 | 说明 |
| --- | --- |
| 通知 | 「全部」「仅@」「关闭」，见 [通知](/user/notifications#每个会话的提醒档位) |
| 星标 | 放进会话列表的「星标」分区 |
| 运行卡片默认折叠 | 只对我生效，审批与提问卡片始终展开 |

- **群管理**：「基本信息」「成员」「仓库与同步」「群级参数」「MCP」「Skill」「密钥」「飞书」，点开进入群设置对话框。非群管理员看到「仅群管理员 · 某某」，打开后是只读的。
- 底部：「退出群」「解散群」（私聊为「删除私聊」）。

## 群设置对话框

群设置对话框左侧是分页导航。群管理员可以修改；普通成员可以打开查看，底部提示「仅群管理员可修改」，只能在「密钥」页填写自己的值。

![群设置](/screenshots/web/group-settings.webp)

| 分页 | 内容 |
| --- | --- |
| 基本信息 | 群名称、群头像、回复风格、Bot 回复进话题、群管理员 |
| 成员 | 仅群管理员可拉人、公开频道、团队分区、入群申请 |
| Bot | 群里的 Bot，同侧栏的 Bot 页 |
| 仓库与同步 | 代码仓库、推送规则、同步模式，见 [仓库与工作区](/user/repos-workspaces) |
| 群级参数 | 审批、接力、离线等待参数（私聊中为「参数」） |
| MCP / Skill | 只对本群生效的 MCP 和 Skill；与团队层、平台层同名时以群层为准 |
| 密钥 | 群层密钥，见 [知识库与密钥](/user/knowledge-secrets#密钥) |
| 飞书 | 绑定飞书群（仅群管理员可见），见 [飞书](/admin/feishu#在飞书群里使用-bot) |
| 插件 | 系统开启插件后出现，见 [Skill 市场与插件](/user/market-plugins) |

私聊里只有「基本信息」「Bot」「仓库与同步」「参数」，系统开启插件时还有「插件」。

### 基本信息

| 设置 | 说明 |
| --- | --- |
| 群名称 | 最多 60 个字，改完点「保存」 |
| 群头像 | 可上传；未上传时由成员头像拼成 |
| 回复风格 | 「技术」或「业务」。「业务」让 Bot 先写结论、口语化，不贴表名、代码和 SQL，依据放在末尾 |
| Bot 回复进话题 | 打开后，在群里 @ Bot 时，它的回复放进这条消息的话题，不刷屏，见 [话题](/user/schedules-threads#话题) |

### 群级参数

群级参数覆盖系统默认值，改后点「保存」，对新会话生效。

| 参数 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 权限审批等待（分钟） | 1–1440 | 30 | 审批请求超过这个时间没人处理，自动拒绝，见 [审批与提问](/user/approvals) |
| 接力链长上限（跳） | 1–10 | 3 | Bot 之间接力（以及 Bot 开话题指派其他 Bot）最多几跳 |
| Bot 离线等待上线（分钟） | 1–1440 | 30 | Bot 离线时，请求等它上线的最长时间，超时作废并通知触发人 |

默认值来自系统参数，见 [系统参数](/admin/params)。Bot 的并发上限、触发范围是 Bot 自己的设置，不在群里设。

## 成员与群管理员

群里有两种角色：**群管理员**和**普通成员**。创建者是第一个群管理员，一个群可以有多个群管理员。

在侧栏点「成员」进入「群成员」页：

- 可以搜索成员（支持拼音），每位成员显示是否「群管理员」，以及带入了哪些 Bot（「带入 某某」或「未带入 Bot」）。
- 「添加成员」可多选，一次添加多人。
- 群管理员可以对其他成员「设为管理员」「取消管理员」「移出」。

| 操作 | 谁能做 |
| --- | --- |
| 添加成员 | 任何成员（开启「仅群管理员可拉人」后仅群管理员） |
| 拉入自己的 Bot | 任何成员 |
| 拉入别人的 Bot、移出 Bot | 群管理员 |
| 移出成员、设为 / 取消管理员 | 群管理员 |
| 改群名、群头像、发布或移除公告 | 群管理员 |
| 绑定或更换仓库、改群级参数和其他群设置 | 群管理员 |
| 解散群 | 群管理员 |
| 设置 Bot 在本群的审批方式、更换 Bot 的工作区 | Bot 主人 |
| 退出群 | 任何成员 |

::: warning
- 移出成员时，他的 Bot 一并移出本群，运行中的轮次按非主动中断处理。
- 唯一的群管理员不能被移出或取消管理员，要先指定其他群管理员。
:::

::: tip 团队管理员查看群
团队管理员打开自己不在其中的群时，是「只读查看」：不能发言或管理，可以点「进群并成为管理员」加入。
:::

## 群里的 Bot

在侧栏点「Bot」进入 Bot 页，显示「N 个 · 在线 M」。

- 点「拉入 Bot」添加：普通成员只能拉入自己的 Bot，群管理员可以拉入团队里任何 Bot。候选 Bot 的主人不在群里时，标注「主人将一并加入」。
- 每个 Bot 显示所在机器的工作区状态、审批方式（本群单独设置时标注「本群」）和触发范围。
- 「工作区…」查看这个 Bot 在本群用的全部目录；Bot 主人可以在这里更换，见 [仓库与工作区](/user/repos-workspaces#每个-bot-的工作区)。
- Bot 主人在「…」菜单的「本群审批方式」里可以为本群单独选择审批方式，或「跟随全局」。改动对运行中的轮次立即生效；本群为「完全允许」时仅指定名单可触发。「全局设置」打开 Bot 自己的设置，见 [Bot 设置与权限](/user/bot-settings)。
- 群管理员可以「移出」Bot。移出后保留它的工作区，由主人决定是否删除；运行中的轮次按非主动中断处理。
- 有 Bot 卡住时（未选择工作区、待主人确认、无法访问仓库），页面顶部提示「N 个 Bot 需要处理」。

## 群公告

群管理员在侧栏点「公告」，在「群公告 · 置顶展示在对话顶部」里编辑（最多 500 个字），点「保存」。

发布后公告置顶显示在群消息顶部，所有成员可见；隐藏后，公告第一行显示在群头部标题下方。

| 操作 | 谁 | 效果 |
| --- | --- | --- |
| 不再显示 | 任何成员 | 只对自己隐藏，可在「群公告」页重新「在对话顶部显示」 |
| 移除 | 群管理员 | 所有成员都不再看到，仍可在「群公告」页查看历史 |
| 发布新公告 | 群管理员 | 替换旧公告，旧公告留在历史里；已隐藏的成员会重新看到 |

侧栏「群公告」页可查看公告历史，当前公告标注「当前」。

## 群标签栏

群顶部可以挂标签，所有成员都能看到和打开。任何成员都可以添加，每个群最多 30 个。标签类型：

| 类型 | 内容 |
| --- | --- |
| 链接 | 一个网址 |
| 知识库 | 一条知识库条目 |
| 文件 | 某个 Bot 工作区里的文件，填相对路径，如 `docs/需求.md` |
| 入口 | 群公告、置顶消息、定时任务或某个 Bot 的 Git 日志 |

## 退出、解散与删除

在侧栏底部操作。按钮点第一次变成确认状态并显示说明，**再点一次**才生效。

**退出群**（任何成员）：点「退出群」，再点「确认退出」。你的 Bot 一并移出本群。也可以在会话列表右键「离开频道」。

- 你是唯一的群管理员时不能退出，要先在「群成员」里指定其他群管理员。
- 公开频道之后可在「浏览频道」重新加入；私有群需要成员重新邀请。

**解散群**（群管理员）：点「解散群」，再点「确认解散」。

- 群归档，运行中的轮次停止，消息与审计记录保留。
- 各 Bot 的托管工作区保留在机器上，由主人决定是否删除，见 [工作区清理](/user/repos-workspaces#工作区清理)。

**删除私聊**：点「删除私聊」，再点「确认删除」。消息与审计记录保留，Bot 的托管工作区保留在本机。
