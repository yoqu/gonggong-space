# 指令参考

本页列出输入框里输入 `/` 后可用的全部指令：共工空间自带的系统命令，以及 Agent 自己提供、原样转交的 Agent 命令。

![输入 / 弹出指令候选](/screenshots/web/composer-commands.webp)

## 怎么输入指令

- 在输入框开头输入 `/`，或点工具栏的「命令」，弹出候选列表。
- 也可以先 @ Bot 再输入指令，如 `@后端助手 /compact`，两种写法等价。
- 用 ↑ / ↓ 选择，Enter 或 Tab 插入，Esc 关闭。
- 指令名区分大小写。

候选列表分两组：

| 分组 | 内容 |
| --- | --- |
| 系统命令 | 共工空间自带，见下表 |
| AGENT 命令 | 标注「ACP 上报」，由消息里 @ 到的 Bot 所用的 Agent 提供 |

::: tip 看不到 Agent 命令？
Agent 命令只对 @ 到的 Bot 列出。先输入 `@Bot名`，再输入 `/`。另外 Bot 要在这个群里跑过至少一轮，它的 Agent 命令才会出现。
:::

指令消息不会触发普通运行，也不会作为背景上下文补给 Bot。执行结果以一条群提示显示。

## 系统命令

| 指令 | 界面说明 | 写法 | 谁能用 |
| --- | --- | --- | --- |
| `/stop` | 停止运行（未 @ Bot 时停止本群全部） | `/stop` 或 `/stop @Bot …` | 群成员 |
| `/new` | 开新会话 | `/new @Bot …` | 群成员 |
| `/cd` | 绑定本机目录（仅分区） | `/cd @Bot /绝对路径` 或 `/cd @Bot --reset` | Bot 主人 |
| `/hold` | 连续占用群锁 | `/hold` | — |
| `/release` | 释放群锁 | `/release` | — |

### /stop

停止运行中和排队中的轮次。

```text
/stop @后端助手
/stop
```

- 带 @：只停这些 Bot 的未完成轮次。
- 不带 @：停本群全部 Bot 的未完成轮次。
- 涉及 Bot 接力链时，整条链一起终止。
- 群里提示如「/stop · 停止 后端助手 的 1 个轮次」；没有可停的显示「没有运行中的轮次」。
- 操作会写入审计记录。

### /new

让 Bot 下一轮开一个全新会话，忘掉此前的对话。

```text
/new @后端助手
```

- 必须 @ 至少一个 Bot，否则提示「/new 需要同时 @ 一个 Bot」。
- 群里提示「后端助手 下一轮将开新会话」，下一张运行卡片会显示「已按要求开启新会话」。
- 同时清空这个 Bot 的上下文占用显示。
- 群头部上下文占用面板里的「开新对话」按钮发出的就是这条指令，见 [上下文占用与压缩](/user/chat#上下文占用与压缩)。

### /cd

让 Bot 直接在它所在机器上的某个本机目录里干活，而不是在共工空间托管的工作区里。

```text
/cd @后端助手 /Users/wanglei/code/todo-app
/cd @后端助手 --reset
```

- 只有 Bot 主人能用，只在分区模式的群里可用。
- 必须且只能 @ 一个 Bot；路径必须是 Bot 所在机器上的绝对路径。
- `--reset`：回到托管工作区。
- 成功提示「✓ 后端助手 已绑定到 /Users/…（本机目录）」或「✓ 后端助手 已使用托管工作区」。
- Bot 离线时无法执行。

常见报错：

| 提示 | 原因 |
| --- | --- |
| /cd 仅分区模式可用；强制同步群里非托管工作区的 Bot 为「不参与」 | 群不是分区模式 |
| 只有 Bot 主人可以使用 /cd | 你不是这个 Bot 的主人 |
| /cd 需要本机绝对路径，如 /Users/me/code/repo | 写了相对路径 |
| 某某 离线，无法执行 /cd | Bot 所在机器不在线 |

工作区与模式的说明见 [仓库与工作区](/user/repos-workspaces)。

### /hold 与 /release

用于强制同步群的群锁。当前版本在群里输入只会提示「/hold 仅在强制同步群可用」「/release 仅在强制同步群可用」，没有实际效果。

## Agent 命令

Agent 命令是 Bot 使用的 Agent（Claude Code、Codex 等）自己上报的命令，如 `/compact`。有哪些命令、各自做什么，以 Agent 本身为准，候选列表里的说明文字也来自 Agent。

```text
@后端助手 /compact
```

- 发送后，指令文字**原样**交给 Agent 执行，不附带群上下文。
- 必须 @ Bot，且 @ 到的每个 Bot 都支持这条命令，才会作为 Agent 命令执行。
- 只有一个 Bot 的私聊里可以不写 @。
- 不满足以上条件的 `/xxx` 按普通消息处理。例如 `/path/to/file @后端助手 看下` 会作为一条普通任务发给 Bot。

### 与系统命令重名

Agent 命令与系统命令同名时，候选里显示为 `/Bot名:命令`，并标注「与系统命令重名」。直接输入 `/new` 执行的是系统命令；要执行 Agent 的同名命令，用带前缀的写法：

```text
/后端助手:new
```

Bot 名里的空格要去掉。
