# Bot 设置与权限

本页讲 Bot 详情里的各项设置：谁能触发它、它能动哪些文件、命令要不要审批、并发、默认工作区、供应商、模型与推理强度，以及删除 Bot。

## 打开 Bot 详情

在侧栏「我的 Bot」点击 Bot 进入概况页，点右上角的「编辑」，打开「Bot 详情」。系统管理员也可以在「管理后台 → Bot」里选中一行修改，见 [Bot 与群](/admin/bots-groups)。

![Bot 设置](/screenshots/web/bot-settings.webp)

改完点底部的「保存」。设置在 **下一次新开会话时生效**，进行中的会话不受影响。

::: info 谁能改
- Bot 主人和系统管理员可以修改大部分设置。
- 「命令审批」只有 Bot 主人能改，系统管理员也不行。
- 「默认工作区」「供应商」只有 Bot 主人能改，且要求机器在线。
- 其他人打开时只能查看。
:::

## 角色与系统提示词

- **角色**：更换头像形象，见 [创建 Bot](/user/create-bot#角色)。
- **系统提示词**：Bot 的角色说明和群内简介，最多 4000 字。群里还可以再补充，见 [群与私聊](/user/groups)。

## 触发范围

决定群里谁 @ 它会让它开工：

| 选项 | 含义 |
| --- | --- |
| 任何群成员 | 默认，Bot 所在群的所有成员都能触发 |
| 指定名单 | 只有名单里的成员能触发。选中后出现「触发名单」，输入成员姓名添加 |
| 仅本人 | 只有 Bot 主人能触发 |

## 权限档位

决定 Bot 在工作区里能做什么：

| 档位 | 含义 |
| --- | --- |
| 只读 | 可以读文件；改文件、执行命令等操作需要审批 |
| 工作区写入 | 默认，可以直接修改工作区里的文件；执行命令等其他操作需要审批 |
| 完全访问 | 所有操作直接放行，不再审批 |

::: danger 完全访问
完全访问下 Bot 执行任何命令都不再询问，风险最大。因此它**只允许指定名单触发**：选择完全访问时，如果触发范围是「任何群成员」，会自动改为「指定名单」，且「任何群成员」不可选。请只把可信的人放进名单。
:::

权限档位是 Bot 的默认值，每个群还可以单独调整这个 Bot 在本群的档位，见 [群与私聊](/user/groups)。

## 命令审批

「只读」和「工作区写入」档位下，Bot 要执行命令时如何处理：

| 选项 | 含义 |
| --- | --- |
| 每次询问 | 默认，除只读命令外每条命令都要审批 |
| 白名单自动 | 命中白名单的命令自动批准，其他仍要审批 |
| 全部自动 | 除高危命令外所有命令自动批准 |

任何模式下：

- `cat`、`ls`、`git status` 等只读命令（及工作区内的 `cd`）自动批准，「每次询问」也不例外；
- `sudo`、`git push --force`、`rm -rf /` 等高危命令一律需要你审批，「全部自动」也不例外。完整清单见 [审批与提问](/user/approvals#高危底线)。

选「白名单自动」后出现「命令白名单」：输入命令前缀，按回车添加，如 `go build`、`npm test`。规则：

- 以这些前缀开头的命令自动批准；
- 用 `&&`、`;`、`|` 连接的命令，每一段都要在白名单内（只读命令除外）；
- 写文件的重定向（如 `> file`）或 `$( )` 仍需审批；
- 也可以写 `tool:工具名`，让同名的非命令请求（如 MCP 工具）自动批准。

### 始终允许

「每次询问」和「白名单自动」下还有「始终允许」列表。你在审批卡片上点「始终允许」时，卡片上「将始终允许：…」列出的规则会加进这里，对这个 Bot 所在的所有群生效。

- 规则是命令前缀（如 `npm run build`）或 `tool:工具名`，命中的请求自动批准；
- 可以点规则上的 × 删除，删除后再次需要审批；也可以输入前缀按回车手动添加；
- 「全部自动」下这份列表不显示。

规则怎么生成、哪些命令会记整条原文，见 [审批与提问](/user/approvals#始终允许)。

::: tip
「完全访问」档位本来就不审批，这里的设置对它无效。需要审批时由谁批准、怎么批准，见 [审批与提问](/user/approvals)。
:::

## 并发上限

Bot 同时运行的轮次数，范围 1–8，新建 Bot 时默认为系统参数里的值（默认 2）。超出的在本机排队。

## 默认工作区

只有 Bot 主人能看到这一项。点「选择…」在机器上选一个目录，点「清除」取消。

- 在未绑定仓库的群和私聊中，Bot 自动在这个目录里工作；
- 绑定了仓库的群默认使用托管克隆。

详见 [仓库与工作区](/user/repos-workspaces)。

## 供应商

选择 Bot 调用模型用的供应商：「继承机器（当前：…）」、「官方登录」或这台机器上的某个第三方供应商。设置只保存在 Bot 所在的机器上，进行中的会话开启新会话后才切换。

下拉框不可用时，旁边会说明原因，如「只有 Bot 主人可以设置其供应商」「机器离线，上线后才能设置」「请先升级该机器的 daemon」。供应商的添加和管理见 [Agent 工具与供应商](/user/agents-providers)。

## 模型与推理强度

![Bot 的模型与推理强度](/screenshots/web/bot-agent-config.webp)

- **模型**：「默认（…）」表示跟随 Agent 的默认模型；也可以选机器上报的某个模型。用了第三方供应商时，列表是该供应商的模型。
- **推理强度**：部分模型提供，选项随模型变化，如「低」「中」「高」「超高」「最高」，「默认（…）」表示该模型的起始档位。换模型时，如果新模型没有原来的档位，会回到默认。

机器还没上报可选模型时，显示「跟随默认 · 机器上报可选模型后可设置」。

这里设的是 Bot 的默认值。实际生效的优先级从高到低：

1. 发消息时在输入框下方为这一条单独指定；
2. 本群设置的默认值；
3. Bot 的默认值（这里）；
4. Agent 自己的默认值。

群内切换和单条指定见 [在群里指挥 Bot](/user/chat)。

## 其他信息

Bot 详情下方还显示：所在群数量、agent 版本、近 7 天用量，以及「谁用了」的分布。如果机器上的 CLI 版本低于适配器要求，顶部会提示「agent 版本低于适配器要求」，请到 [Agent 工具](/user/agents-providers#agent-工具) 升级。

## 飞书应用

Bot 主人可以在 Bot 详情的「飞书应用」里给 Bot 绑定一个飞书自建应用，之后就能在飞书群里 @它。绑定方式和飞书后台配置见 [飞书](/admin/feishu)。

## 删除 Bot

在 Bot 详情左下角点「删除 Bot」，确认后点「删除」：

- Bot 从所在的所有群移除；
- 群消息与运行记录保留；
- 删除后不可恢复。
