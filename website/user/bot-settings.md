# Bot 设置与权限

本页讲 Bot 详情里的各项设置：名称与形象、供应商与模型、默认工作区、审批方式、触发范围、并发、Git 提交身份、共享，以及删除 Bot。

## 打开 Bot 详情

在「机器与 Bot」里点 Bot 进入概况页，点右上角的「编辑」，打开「Bot 详情」。系统管理员也可以在「管理后台 → Bot」里修改，见 [Bot 与群](/admin/bots-groups)。

![Bot 设置](/screenshots/web/bot-settings.webp)

设置分为「基本信息」「运行配置」「权限」「高级」「飞书」「共享」几个页签（「飞书」只有 Bot 主人和系统管理员看得到）。改完点底部的「保存」，提示「已保存 · 下一次新开会话时生效」：**进行中的会话不受影响**，下一次新开会话才用新设置。

::: info 谁能改
- Bot 主人和系统管理员可以修改大部分设置；其他人打开时只能查看。
- 以下几项只有 Bot 主人能改，系统管理员也不行：「帮我审批」与「每次问我」之间的切换、「AI 预审」、「已允许的命令」、「Git 提交身份」、「Agent 设置」覆盖、「默认工作区」、「供应商」。
- 「默认工作区」「供应商」还要求机器在线。
:::

顶部可能出现提示，例如「agent 版本低于适配器要求」（机器上的 CLI 太旧，请到 [Agent 工具](/user/agents-providers#安装与升级) 升级）、「Claude Code 未安装」，或管理员替你创建、还在「等待确认」的 Bot 的「确认」按钮。

## 基本信息

- **名称**：最多 40 个字。
- **头像**：上传一张图片，裁剪后代替角色形象显示；也可以移除，回到角色形象。
- **角色**：默认「跟随 Agent」，也可以选共字君或 12 个性格角色之一，见 [创建 Bot](/user/create-bot#角色)。
- **系统提示词**：Bot 的角色说明和群内简介，最多 4000 字。群里还可以再补充，见 [群与私聊](/user/groups)。

## 运行配置

显示「执行机器」和「Agent」（CLI 名与版本），以及下面几项。

### 供应商

选择 Bot 调用模型用的供应商：「继承机器（当前：…）」、「官方登录」或这台机器上同一 Agent 的某个供应商。设置只保存在 Bot 所在的机器上，进行中的会话开启新会话后才切换；保存时如果有群还在用旧供应商，会先弹窗确认。

下拉框不可用时，旁边会说明原因，如「只有 Bot 主人可以设置其供应商」「只能在自己的机器上设置 Bot 的供应商」「机器离线，上线后才能设置」「请先升级该机器的 daemon」。供应商的添加和管理见 [Agent 工具与供应商](/user/agents-providers#供应商)。

### 模型与推理强度

![Bot 的模型与推理强度](/screenshots/web/bot-agent-config.webp)

- **模型**：「默认（…）」表示跟随 Agent 的默认模型；也可以选机器上报的某个模型。用了第三方供应商时，列表是该供应商的模型。Bot 主人的机器在线时，旁边有「刷新模型」，让机器重新读取可选模型。
- **推理强度**：部分模型提供，选项随模型变化，如「低」「中」「高」「超高」「最高」；「默认（…）」表示该模型的起始档位。换模型时，新模型没有原来的档位就回到默认。

机器还没上报可选模型时，显示「跟随默认 · 机器上报可选模型后可设置」。

这里设的是 Bot 的默认值。实际生效的优先级从高到低：

1. 发消息时在输入框下方为这一条单独指定；
2. 本群设置的默认值；
3. Bot 的默认值（这里）；
4. Agent 自己的默认值。

群内切换和单条指定见 [在群里指挥 Bot](/user/chat)。

### Agent 设置

仅 Claude Code 的 Bot 有。「语言」「扩展思考」「提交署名」可以选「跟随机器设置」或单独指定，下次启动 agent 时生效。机器上的默认值在 [Agent 工具与供应商](/user/agents-providers#agent-设置-claude-code) 里设置。

### 默认工作区

只有 Bot 主人能看到这一项。点「选择…」在机器上选一个目录，点「清除」取消。

- 在未绑定仓库的群和私聊中，Bot 自动在这个目录里工作；
- 绑定了仓库的群默认自动克隆；
- 不设也可以：Bot 默认使用共工空间托管的工作区，第一条 @ 就能执行。

详见 [仓库与工作区](/user/repos-workspaces)。

## 权限

### 审批方式

决定 Bot 想做有风险的操作时怎么处理，三选一：

| 选项 | 含义 |
| --- | --- |
| 每次问我 | 只读命令自动放行，其余操作都发审批卡片给你 |
| 帮我审批 | 构建、测试、lint、格式化、本地 git 和工作区内改文件直接放行（等于信任仓库里的脚本）；其余发审批卡片给你。开启「AI 预审」后先由 AI 评估，只把风险操作交给你 |
| 完全允许 | 不再询问，Bot 可以执行任何操作 |

「每次问我」和「帮我审批」下，高危命令（如 `sudo`、`git push --force`）、推送受保护的基准分支和客户端发版**始终需要你确认**。

**内置审核**：「帮我审批」下，Claude Code（官方登录）和 Codex（OpenAI 官方登录）改由 agent 内置的自动审核把关，共工空间不再预审；被它拦下的操作会让 agent 换个做法，不发卡片。用第三方供应商或不支持的模型时用不了内置审核，按上面的方式审批，运行过程里会注明本次由谁审。

::: danger 完全允许
完全允许下 Bot 执行任何命令都不再询问，能触发它的人发起的任务都不会被拦截，包括危险命令。因此它**只允许指定名单触发**：选择完全允许时，如果触发范围是「任何群成员」，会自动改为「指定名单」，且「任何群成员」不可选。建议只给自己用的群或 Bot 开启。
:::

旧版 Bot 可能还处在「只读」档：Bot 只能读取，其余操作都发审批卡片。改成其他方式后这个选项就不再出现。

这是 Bot 的默认值。每个群还可以在群信息里单独设置这个 Bot 的「本群审批方式」，见 [群与私聊](/user/groups)。

### AI 预审

选「帮我审批」后，Bot 主人可以设置「AI 预审」，默认「关闭」。从列表里选一个模型即开启：规则没放行、内置审核也没接手的请求，先由这个模型评估，低风险且明显是用户要求的自动批准，其余仍交给你，审批卡片附上风险和理由。

每次评估都消耗 token，请选小模型（如 haiku、mini、flash）。预审在空目录里用精简会话进行，每次约几千 token。Bot 所在机器还没上报可选模型时暂不能开启。

### 已允许的命令

「每次问我」和「帮我审批」下的白名单。你在审批卡片上选「批准，不再询问」时，规则会加到这里，对这个 Bot 所在的所有群生效。

- 以这些前缀开头的命令（或 `tool:工具名`）自动批准；
- 也可以手动输入命令前缀，如 `go build`，按回车添加；
- 点规则上的 × 删除，删除后再次询问。

审批卡片怎么处理、规则怎么生成，见 [审批与提问](/user/approvals)。

### 触发范围

决定群里谁 @ 它会让它开工：

| 选项 | 含义 |
| --- | --- |
| 任何群成员 | Bot 所在群的所有成员都能触发 |
| 指定名单 | 只有名单里的成员能触发。选中后出现「触发名单」，输入成员姓名添加 |
| 仅本人 | 只有 Bot 主人能触发 |

## 高级

- **并发上限**：同时运行的轮次，范围 1–8，超出的在该机器排队。新建 Bot 的默认值来自系统参数「Bot 并发上限 · 新建默认」（默认 2）。
- **Git 提交身份**：Bot 提交代码时的作者名和邮箱，留空用默认值（名字默认为 Bot 名），下次启动 agent 时生效。只有 Bot 主人能改。

## 飞书

Bot 主人和系统管理员能看到这一页。给 Bot 接入一个专属的飞书自建应用，之后就能在飞书群里 @ 它、在飞书里单聊它。点「扫码创建或接入」用飞书扫码即可，接入后下方的清单会写明还差哪几步（等企业飞书管理员审核、把应用的可用范围改为需要的成员）。这一页的内容即时生效，没有底部「保存」。

Bot 概况页的「飞书应用」一行显示状态：未接入、连接中、等待审核、连接失败或已接通。在群设置 · 飞书里，没有飞书应用的 Bot 旁边有「去接入」，会直接打开这一页。配置细节见 [飞书](/admin/feishu)。

## 共享

把 Bot 共享给团队里的其他人：在「共享给」里点「添加成员…」，即时生效。

- 对方可以和 Bot 私聊、查看它的配置，每个私聊使用独立的托管工作区；
- 命令审批仍由 Bot 主人处理；
- 取消共享后，对方的私聊转为只读。

别人也可以在 Bot 概况页点「申请共享」，你同意后自动加进名单。

## 会话什么时候重新开始

- 改了设置、切换了供应商，都要等**下一次新开会话**才生效；在群里发 `/new @Bot名` 可以立即开新会话，见 [指令参考](/user/commands)。
- Bot 在一个群里闲置超过 6 小时后，下次对话会自动开新会话，避免重新读取已失效缓存的长历史、浪费 token。时长由系统参数「Bot 闲置后下次对话自动开新会话」决定，见 [系统参数](/admin/params)。

## 删除 Bot

在 Bot 详情左下角点「删除 Bot」，确认后点「删除」：

- Bot 从所在的所有群移除；
- 群消息与运行记录保留；
- 删除后不可恢复。
