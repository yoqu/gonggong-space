# 创建 Bot

Bot 是群里可以 @ 的 AI 成员，固定在某台机器上用某个 Agent（Claude Code、Codex、Gemini CLI 等）干活。本页讲怎样得到第一个 Bot、「新建 Bot」对话框的各个字段、Bot 概况页，以及怎样让它开工。

## 最快的办法：绑定机器时自动建好

用「发给你的 Agent」绑定机器时，Agent 会顺手用它自己这种 Agent 建好一个 Bot（如「王磊的 Claude Code」）和你与它的私聊，网页直接打开私聊，不用再走下面的步骤。见 [绑定机器](/user/bind-machine#方式一-发给你的-agent-推荐)。

想在同一台机器上再建一个 Bot（比如换个 Agent、换个系统提示词），再用「新建 Bot」。

## 打开「新建 Bot」

任选一个入口：

- 左侧导航栏「机器与 Bot」顶部的「新建 Bot」，或某台机器下面的「新建 Bot」（会预先选好这台机器）；
- 「机器与 Bot」总览里机器卡片上的「新建 Bot」；
- 用「其他方式」绑定机器成功后，对话框里的「新建 Bot」；
- 欢迎页或侧栏「开始使用」卡片里的「新建 Bot」；
- 系统管理员还可以在「管理后台 → Bot」里新建，见 [Bot 与群](/admin/bots-groups)。

## 字段说明

对话框分「基本信息」和「运行配置」两部分。

### 基本信息

| 字段 | 说明 |
| --- | --- |
| 归属人 | Bot 属于谁、跑在谁的机器上。只有能为多人创建时才出现：系统管理员可为任何人创建，成员本人只能为自己创建 |
| 名称 | 默认是「归属人的 Agent」，如「王磊的 Claude Code」，可以改，最多 40 个字，不能与已有 Bot 重名。名称前的小图是 Bot 的头像预览 |
| 角色 | Bot 的形象，默认「跟随 Agent」。点「换个角色…」可以换，见下文 |
| 系统提示词 | 可选，告诉 Bot 它负责什么，同时作为群内简介，如「后端接口开发，只改 server/ 目录」。最多 4000 字 |

### 运行配置

| 字段 | 说明 |
| --- | --- |
| 执行机器 | 归属人名下的机器，显示系统和在线状态。归属人还没有机器时，Bot 以「待绑定」创建 |
| Agent | 这台机器能跑的 Agent，旁边显示检测到的版本；机器上没有的显示「未安装」，不能选；机器离线且从未上报时显示「待检测」 |

点「设置供应商、模型与默认工作区…」可以在创建时就设好下面几项（都可以在创建后的 Bot 设置里改）：

- **供应商**：「继承机器（当前：…）」「官方登录」或这台机器上的某个供应商，见 [Agent 工具与供应商](/user/agents-providers#bot-选用哪个供应商)；
- **模型 / 推理强度**：默认跟随 Agent 自己的默认值，见 [Bot 设置与权限](/user/bot-settings#模型与推理强度)；
- **默认工作区**：只在为自己创建且机器在线时出现。点「选择目录…」选机器上的一个目录；未绑定仓库的群和私聊中自动使用，绑定仓库的群默认自动克隆。

::: tip 不设默认工作区也能直接用
Bot 进群或私聊时默认使用共工空间托管的工作区（`~/gonggong/workspaces/<群名>/<Bot名>/…`），第一条 @ 就能执行。想让它在你已有的项目目录里干活，再设默认工作区或在群里更换工作区，详见 [仓库与工作区](/user/repos-workspaces)。
:::

### 角色

每个 Bot 都扮演一个角色：

- **跟随 Agent**（默认）：用 Agent 的官方形象，一眼看出是哪家；
- **共字君**：品牌吉祥物；
- 12 个性格角色，如「慢想」（深思 × 逆向 × 守边界）、「铁码」（毒舌 × 洁癖 × 实干）、「小步」（乐天 × 务实 × 敢割舍）、「哨兵」（警觉 × 冷静 × 讲流程）等。鼠标悬停在卡片上会动起来，下方提示这个角色的一句话介绍。

角色决定 Bot 的头像和概况页上的介绍，不会改变 Bot 的行为；要约束 Bot 的做法，请写在「系统提示词」里。创建后还可以在 Bot 设置里上传一张图片作为头像，见 [Bot 设置与权限](/user/bot-settings#基本信息)。

## 创建

对话框底部会预告创建后的状态，按钮文字也随之变化：

| 情况 | 预告 | 按钮 |
| --- | --- | --- |
| 为自己创建，机器已上报所选 Agent | 创建后立即可用 | 「创建并绑定」 |
| 机器没有所选 Agent | 绑定后暂不可用，在该机器安装并重新检测后自动可用 | 「创建并绑定」 |
| 归属人还没有机器 | 待绑定 | 「创建」 |
| 管理员为别人创建 | 等待归属人确认 | 「创建并发送确认」 |

创建后显示结果，例如「已就绪，可以在群里 @ 它了」。为自己创建且 Bot 已就绪时，点「和它聊一句」直接打开私聊。机器离线时提示打开该机器上的共工空间客户端；Bot 待绑定且是你自己的，结果页会直接给出接入链接，方便马上绑定机器。

::: info 管理员替你创建的 Bot
机器上的操作由机器主人负责。管理员为你创建并指定到你机器上的 Bot，需要你确认后才能被触发：你会收到通知，「机器与 Bot」里该 Bot 旁也有「确认」按钮。
:::

## 在哪里看到它

创建后，Bot 出现在「机器与 Bot」里它所在机器的下面，显示 Agent 和状态（在线 / 运行中 / 离线 / agent 缺失）；还没落到机器上的在「未绑定机器的 Bot」里，显示「待绑定」或「待确认」。

![Bot 概况页](/screenshots/web/bot-overview.webp)

点它进入 **Bot 概况页**：

- 头像、角色、状态；
- 「正在工作」：当前进行中的运行，空闲时显示「空闲，在群里 @ 它即可开工」；
- 「工作位置」：所在的群和私聊，以及各自的工作区；
- 近几天的用量：token 合计、运行轮次、谁用了、按群统计；
- 右侧是配置摘要：基本信息、运行配置、权限、高级、共享。

页面右上角：「私聊」打开和它的私聊，「编辑」打开 Bot 详情修改设置，见 [Bot 设置与权限](/user/bot-settings)。

你所有 Bot 的用量汇总在头像菜单的「我的用量」里。

![我的 Bot 与用量](/screenshots/web/my-bots.webp)

::: tip 用别人的 Bot
别人的 Bot 概况页右上角有「申请共享」，填一句用途后提交，主人同意后它出现在你的「共享给我」里，你就可以和它私聊。共享怎么设置见 [Bot 设置与权限](/user/bot-settings#共享)。
:::

## 让 Bot 开工

- **私聊**：在 Bot 概况页点「私聊」；或点会话列表顶部的「+」（发起会话），只选这个 Bot 就会「开始私聊」。私聊里只有一个 Bot，不用 @，直接说需求即可。
- **拉进群**：发起会话时加上这个 Bot 和同事，或在已有群里添加，见 [群与私聊](/user/groups)。

![与 Bot 私聊](/screenshots/web/bot-page.webp)

具体怎么给 Bot 派活，见 [在群里指挥 Bot](/user/chat)。
