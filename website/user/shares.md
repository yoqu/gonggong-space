# 公开分享

本页讲如何为 Bot 发布的网页预览生成公开链接，让没有账号的外部人员也能访问，以及有效期、收回和访问审计。

## 生成公开链接

只有 Bot 主人或群管理员能生成，且只支持网页类预览（网页 / 服务、静态页面）。预览本身见 [结果预览](/user/previews)。

1. 在预览卡片上点「公开链接」，或在工作台网页标签页的工具栏点「公开链接…」。
2. 在「有效期」里选择 1、3、7 或 30 天，默认 7 天。
3. 点「生成链接」。
4. 点「复制」，把链接发给对方。

![分享公开链接对话框](/screenshots/web/preview-share.webp)

::: warning
拿到链接的人无需登录即可访问这个预览。完整链接只在生成后显示这一次，关闭对话框后无法再次查看，请及时复制。
:::

## 有效期

- 公开链接一定会过期，没有永久链接。
- 最长有效期默认 **30 天**，由管理员在系统参数「预览公开链接最长有效期」调整，见 [系统参数](/admin/params)。超过时提示「公开链接最长有效 N 天」。
- 系统管理员可在管理后台把有效链接「延长 7 天」，见 [公开链接](/admin/shares)。

## 链接失效的情况

以下任一情况发生，链接立即失效：

- 到期；
- 被收回；
- 预览已关闭（包括空闲自动关闭）。

失效后访问会看到「公开链接已失效或已被收回。」。预览所在的机器离线时，访问者看到「预览所在的机器离线，稍后再试。」。

## 查看与收回

打开同一个预览的「公开链接」对话框，下方列出这个预览的全部公开链接，每行显示状态、创建人、到期时间和访问次数。

| 状态 | 含义 |
| --- | --- |
| 有效 | 可以访问 |
| 已过期 | 超过有效期 |
| 已收回 | 被手动收回 |
| 预览已关闭 | 预览已关闭，链接不可用 |

在有效的链接上点「收回」，立即失效。Bot 主人、群管理员和系统管理员都可以收回。

## 访问审计

生成、收回、延长公开链接，以及外部人员通过链接访问，都会写入审计记录：

- 生成预览「X」的公开链接，有效 N 天
- 收回预览「X」的公开链接
- 预览「X」的公开链接有效期改到 …
- 通过公开链接访问预览「X」

访问按每次通过链接进入记一条，不是每个请求都记。系统管理员可在管理后台「审计记录」里按「预览」筛选查看，见 [审计记录](/admin/audit)；全站的公开链接汇总在 [公开链接](/admin/shares)。
