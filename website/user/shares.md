# 公开分享

本页讲如何把 Bot 发布的网页预览和 Bot 做的原型分享给没有账号的外部人员：生成公开链接、有效期、密码与锁定版本、收回，以及访问审计。

公开分享有两种入口：

| 分享什么 | 入口 | 特点 |
| --- | --- | --- |
| 网页预览 | 预览卡片或工作台的「公开链接」 | 可选有效期，同一个预览可生成多条链接 |
| 原型（作品） | 作品的「分享」 | 一个作品一条链接，可设密码、锁定版本、扫码打开 |

::: warning
拿到链接的人无需登录即可访问。链接到期或收回后立即失效，访问会记入审计。演示模式下不能创建公开链接。
:::

## 网页预览的公开链接

只有 Bot 主人或群管理员能生成，且只支持网页类预览（网页 / 服务、静态页面）。预览本身见 [结果预览](/user/previews)。

1. 在预览卡片上点「公开链接」，或在工作台网页标签页的工具栏点「公开链接…」。
2. 在「有效期」里选择 1、3、7 或 30 天，默认 7 天。
3. 点「生成链接」。
4. 点「复制」，把链接发给对方。

![分享公开链接对话框](/screenshots/web/preview-share.webp)

::: warning
完整链接只在生成后显示这一次，关闭对话框后无法再次查看，请及时复制。
:::

### 查看与收回

打开同一个预览的「公开链接」对话框，下方列出这个预览的全部公开链接，每行显示状态、创建人、到期时间和访问次数。

| 状态 | 含义 |
| --- | --- |
| 有效 | 可以访问 |
| 已过期 | 超过有效期 |
| 已收回 | 被手动收回 |
| 预览已关闭 | 预览已关闭，链接不可用 |

在有效的链接上点「收回」，立即失效。Bot 主人、群管理员和系统管理员都可以收回。

## 原型的分享链接

Bot 做的原型、幻灯片等作品可以整体分享出去，对方打开后默认进入可点击的原型预览。作品本身见 [原型、画布与作品库](/user/artifacts)。

1. 在作品标签页顶部点「分享」，打开「分享产物」对话框。
2. 打开「开启分享」，链接自动生成；关闭时只有群成员能查看。
3. 按需设置：

| 选项 | 说明 |
| --- | --- |
| 链接内容 | 「锁定 vN」：对方始终看到这个版本，Bot 再修改也不变；「始终最新」：Bot 修改后对方看到的内容随之更新 |
| 密码访问 | 打开后自动生成 4 位数字密码，对方打开链接后要先输入；点「换一个」重新生成 |

4. 点「复制链接」，开了密码时为「复制链接和密码」，一起复制。

- 锁定了旧版本而作品已有更新时，对话框提示「已有更新的 vN，对方仍看到 vM」，可点「更新到 vN」。
- 在原型预览里点「扫码查看」，可以显示二维码，用手机扫码打开；还没开启分享时可直接「开启分享并生成二维码」。
- 导出面板里的「分享链接」同样可以一键「开启并复制链接」。
- 链接有效期 7 天（不超过系统参数「预览公开链接最长有效期」），对话框里显示「链接 某日 到期」。
- 只有 Bot 主人或群管理员能开关分享，其他人看到「只有 Bot 主人或群管理员能开关分享」。

对方输入密码时连续输错 5 次，需等 10 分钟后再试。

::: tip 分享和可见范围不同
「可见范围」（仅自己 / 本群 / 团队 / 全员）决定哪些**登录用户**能在作品库里看到这个作品；「开启分享」才会生成给外部人员的链接。
:::

## 有效期

- 公开链接一定会过期，没有永久链接。
- 最长有效期默认 **30 天**，由管理员在系统参数「预览公开链接最长有效期」调整，见 [系统参数](/admin/params)。超过时提示「公开链接最长有效 N 天」。
- 系统管理员可在管理后台把有效链接「延长 7 天」，见 [公开链接](/admin/shares)。

## 链接失效的情况

以下任一情况发生，链接立即失效：

- 到期；
- 被收回，或原型的分享被关闭；
- 预览已关闭（包括空闲自动关闭）。

失效后访问会看到「公开链接已失效或已被收回。」。预览所在的机器离线时，访问者看到「预览所在的机器离线，稍后再试。」。

## 访问审计

生成、收回、延长公开链接，以及外部人员通过链接访问，都会写入审计记录：

- 生成预览「X」的公开链接，有效 N 天
- 收回预览「X」的公开链接
- 预览「X」的公开链接有效期改到 …
- 通过公开链接访问预览「X」

访问按每次通过链接进入记一条，不是每个请求都记。系统管理员可在管理后台「审计记录」里按「预览」筛选查看，见 [审计记录](/admin/audit)；全站的公开链接汇总在 [公开链接](/admin/shares)。
