# 通知

本页讲通知中心里会出现哪些通知、怎样处理，以及怎样开启浏览器推送。

## 通知中心

点击左侧导航栏的「通知」（窄屏时在底部标签栏）打开通知面板，角标是未读通知数。

![通知中心面板](/screenshots/web/notifications.webp)

通知中心**只推送需要你操作的事项**；模式切换、机器落后等群级事件只在群内显示。

| 通知 | 什么时候收到 | 点击后 |
| --- | --- | --- |
| 待审批 | 你的 Bot 请求执行需要批准的操作 | 打开对应群和运行，见 [审批与提问](/user/approvals) |
| 待回答 | Bot 向你提了问题 | 打开对应群和运行 |
| Bot 离线作废 | 你 @ 的 Bot 所在机器一直没上线，请求等待超时后作废 | 打开对应群 |
| 接力链结束 | 你发起的 Bot 接力结束（完成或被 `/stop` 中断） | 打开接力的第一轮运行 |
| Bot 无法访问仓库 | 你的 Bot 所在机器访问不了群绑定的仓库 | 打开对应群，配置凭据后在群里点「重新检查」 |
| 待确认 Bot | 管理员为你创建了 Bot，需要你确认绑定 | 打开 Bot 管理页确认 |

每条通知显示类型、内容、所在群和时间。已经在别处处理掉的审批或提问会标「已处理」。

面板顶部和每一行的操作：

- 点击一条通知：标为已读并跳转到对应位置。
- 「全部标为已读」：清零未读数。
- 「清除已读」：删除所有已读通知。
- 行右侧的「×」：删除这条通知。

## 浏览器推送

开启后，即使共工空间的网页不在前台，新通知也会以系统通知的形式弹出，点击直接打开对应页面。

1. 打开通知面板。
2. 点击底部的「开启浏览器通知」。
3. 在浏览器弹出的权限请求中选择「允许」。

开启后底部显示「浏览器通知已开启」。推送内容与通知中心一致，每台设备、每个浏览器需要分别开启。

::: warning 需要 HTTPS
浏览器推送依赖 Service Worker，只能在安全上下文中使用：网址必须是 `https://`，或者本机的 `localhost` / `127.0.0.1`。用 `http://` 加局域网 IP 访问时，浏览器不提供推送能力，「开启浏览器通知」按钮不会出现。如需推送，请让管理员配置 HTTPS，见 [HTTPS 与证书](/deploy/https)。
:::

::: tip 显示「浏览器通知已被禁止」
说明之前在浏览器里拒绝过通知权限。到浏览器的网站设置里把本站的「通知」改为允许，刷新页面即可。
:::

- 登录后，如果这个浏览器之前已授权，会自动为当前账号重新订阅。
- 退出登录时会取消这个浏览器的订阅，不会再收到上一个账号的推送。
