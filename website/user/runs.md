# 运行过程

本页讲 Bot 被触发后的一次运行：运行卡片、输入框上方的任务条、运行详情（过程、改动、上下文、审批记录）、如何停止，以及发消息前选择模型与推理强度。

## 运行卡片

@ Bot 发送后，群里出现这个 Bot 的运行卡片，实时显示它在做什么。

![进行中的运行卡片](/screenshots/web/run-card.webp)

卡片包含：

- **标题行**：状态图标；Bot 接力时显示接力进度（如「接力 2/3」）；Bot 在后台任务跑完后自己续跑的一轮带「后台任务完成后继续」标签。
- **副标题**：Agent 与触发人，如「Claude Code · 王磊 触发」。
- **当前步骤**：共字君动画加上正在做的事，或正在输出的回复最后一行。
- **进度清单**：Bot 用进度卡片列出的步骤，显示在卡片里；清单较长时在卡片内部滚动。
- **统计**：「改动 N 个文件」（点击查看改动）、耗时、token 用量（未上报时显示「用量未上报」）、「使用了 N 个「我的 Skill」」、子 agent 数与运行中的后台任务数，以及本轮产出或修改的作品。
- **按钮**：「查看过程」「停止」「打断并追加」。

运行结束且有回复后，卡片变成 Bot 的回复消息，下方保留改动文件、耗时、用量和「查看过程」。群里的最终回复只保留 Bot 最后一次调用工具之后的正文，之前的过程说明都在运行详情里。

一条消息 @ 了多个 Bot 时，卡片显示「扇出 · N 个 Bot 并行」。

::: tip 折叠运行卡片
在「群设置」里打开「运行卡片默认折叠」，卡片默认收起，只对你生效。等待审批或回答的卡片始终展开。
:::

### 运行状态

| 状态 | 含义 |
| --- | --- |
| 排队中 | 等待开始，如「本群上一轮未结束，排第 N」「该 Bot 忙，排第 N」「工作区准备中」 |
| 离线等待 | Bot 所在机器离线，上线后自动执行 |
| 运行中 | 正在干活 |
| 等待审批 | 有权限请求等 Bot 主人处理，见 [审批与提问](/user/approvals) |
| 等待回答 | Bot 向群成员提问，等人回答 |
| 已完成 | 正常结束 |
| 已中断 | 被停止或异常中断 |
| 已作废 | 未执行就作废，如离线等待超时、触发消息被撤回 |
| 无权触发 | 你不在 Bot 的触发范围内，没有启动 |

「等待审批」「等待回答」直接显示文字，其他状态只显示图标，鼠标悬停可看文字。

### 排队规则

- 同一个 Bot 在同一个群里一次只跑一轮，下一轮排队。
- 每个 Bot 有并发上限（新建默认 2），多个群同时找它时超出的排队。并发上限在 [Bot 设置与权限](/user/bot-settings) 里改。
- 排队中的运行不占并发名额。
- Bot 离线时请求默认最多等 30 分钟（群级参数「Bot 离线等待上线（分钟）」可改），超时作废并通知触发人。

### 会话提示

Bot 默认续用上一次的会话。以下情况卡片上会提示开了新会话：

| 提示 | 原因 |
| --- | --- |
| 已按要求开启新会话 | 发了 `/new` |
| 本轮因配置变更开启新会话 | Bot 的模型、供应商等配置变了 |
| 距上次对话较久，已开启新会话 | Bot 闲置超过 6 小时（系统参数「Bot 闲置后下次对话自动开新会话」可改），旧会话的缓存已失效，开新会话更省 token |
| 定时任务在独立的新会话中运行 | 定时任务每次都用新会话，不续接群内会话 |
| 原供应商已删除，已开启新会话 | 会话所用的供应商被删除 |
| 会话恢复失败，已开新会话并补送最近 50 条群消息 | 机器上找不到原会话 |

## 输入框上方的任务条

群里有运行未结束时，输入框上方显示任务条，汇总「待我处理 N」「运行中 N」「等待中 N」。

- 等你审批或回答的请求排在最前，显示为「待审批」「待回答」，点击跳到对应卡片。
- 其余每个运行一个标签，显示 Bot 名；点开查看详情：当前步骤最多显示三行，进度清单在弹层内滚动。
- 弹层里「定位」跳到群里的运行卡片，「过程」打开运行详情。

## 共字君动作

卡片上的共字君随运行状态变化：

| 状态 | 动作 | 文字 |
| --- | --- | --- |
| 运行中，正在输出回复 | 打字 | 正在回复 |
| 运行中，其他时候 | 搬运 | 正在工作 |
| 排队中 | 等待 | 排队中 |
| 等待审批 | 举手 | 等待审批 |
| 等待回答 | 提问 | 等待回答 |

其他状态不显示共字君，只显示状态图标。Bot 换了形象时显示 Bot 自己的形象。

## 运行详情

点运行卡片上的「查看过程」，在右侧工作台打开标签页「Bot 名 · 第 N 轮」。有待你处理的请求时，标签上带「待处理」。

![运行详情的过程视图](/screenshots/web/process-panel.webp)

顶部显示触发人、状态、模型（未指定时为「默认」）、耗时、开始与结束时间和用量。右上角：

- 「复制过程」：可选「复制为纯文本」或「复制为 Markdown」。
- 「机器与会话」（ⓘ）：运行所在机器、会话 ID（可复制）、本次注入的密钥名称与来源，以及这轮生效的 Agent 设置（供应商、上下文窗口、自动压缩窗口、是否继承该机器的 CLI 配置等）。

下方有四个视图：

| 视图 | 内容 |
| --- | --- |
| 过程 | 每一步在想什么、做了什么 |
| 改动 | 本轮改了哪些文件，见 [代码变更与文件](/user/diff-files) |
| 上下文 | 上下文窗口用了多少、缓存命中与构成，见下文 |
| 审批记录 | 触发、权限请求及结果、提问及结果、停止等记录 |

- 有等你批准的权限请求或等你回答的提问时，过程视图顶部列出「待处理」，可以直接在这里批准或回答；「在审批记录中查看」跳到对应记录。
- 运行失败、中断或作废时，顶部显示原因横幅和处理建议，可「复制错误信息」，或点「重新运行」用同样的消息再跑一轮，新的运行卡片会出现在群里。
- 往上翻看历史时，点「回到最新」回到正在进行的步骤。
- 点「查看上一轮（还有 N 轮）」可以往前翻这个 Bot 在本群的历史轮次。

### 过程里有什么

最前面是触发这轮的消息，接着是「本轮上下文」：标注「续用会话」或「新会话」，说明这轮补送了哪些群消息，以及 git 默认动作。

之后按时间列出每一步，每行都带时间点：

| 类型 | 显示 |
| --- | --- |
| 思考 | 正在思考 / 思考 |
| 读取、搜索、列目录 | 正在读取 / 已读取、已搜索、已列出等；搜索无结果显示「未找到」 |
| 命令 | 命令本身；超过 2 秒显示耗时；展开看最后 6 行输出，「… 另有 N 行」看全部 |
| 编辑文件 | 文件名与 `+N −M`，点击直接查看该文件的改动 |
| 联网搜索与访问网页 | 连续的搜索和访问合成一行，见下文 |
| MCP 调用 | 「服务 · 工具」，共工空间自带工具显示中文名（如「向群成员提问」）；展开看「参数」和「结果」 |
| 子 agent | 名称、任务、「N 次调用 · 状态」（进行中 / 已完成 / 失败 / 已取消 / 已断开），展开看它自己的过程 |
| 后台任务 | 状态（运行中 / 已暂停 / 已完成 / 失败 / 已停止）与日志路径，可点「停止」 |
| 权限请求 | 请求内容与结果，如「等待 Bot 主人审批」「某某 已批准」「超时未审批，已自动拒绝」 |
| 向群成员提问 | 问题标题与回答结果 |
| 打断并追加 | 「某某 · 打断并追加」及追加的内容，出现在它进来的位置 |
| 压缩上下文 | 「正在压缩上下文…」「已自动压缩上下文」等，可展开看压缩摘要 |

- `ls`、`cat`、`grep`、`git status` 这类只读命令归为查阅，不算作命令。
- 按 Bot 的审批规则自动放行的命令合成一行「自动批准 N 条命令」。
- Agent 反复重试同一个失败的调用时合成一行，标注「同一错误重复 N 次」。
- 运行开头会注明这轮的审批由谁把关，如「审批由 Claude 内置审核（auto 模式）把关」，见 [审批与提问](/user/approvals#帮我审批)。

### 联网搜索

Bot 连续做的联网搜索和网页访问合成一行：

- 搜索中显示「正在搜索 “关键词”」和进度圈，来源列表自动展开。
- 结束后收起为「已搜索 N 个网站」（只访问网页时为「已访问 N 个网页」），旁边叠放来源网站的图标。
- 点这一行展开，可以看到每次搜索的关键词和找到的网页，点网页标题在新标签页打开。

![合并的联网搜索行](/screenshots/web/web-search.webp)

### 筛选与输出

过程顶部的「筛选过程」可切换「全部」「失败」「需处理」「命令」，子 agent 里的步骤也一起筛选。没有符合的步骤时显示「没有符合条件的步骤」。

展开命令的输出后，可以「搜索输出」（显示「N 行匹配」）或「复制输出」。

### 折叠规则

过程会把零碎的步骤合并，便于快速浏览：

- 回复文字、权限请求、本轮上下文、子 agent、后台任务始终单独一行。
- 它们之间连续 2 个及以上的调用合并成一组，组名是这组做过的事，如「读取了文件、运行了命令」；只有 1 个调用时不合并。思考夹在组里，不计入调用数。
- 组内有失败时标注「N 个失败」。
- 运行结束并给出最终回复后，回复之前的全部步骤收进「已工作 X 分 Y 秒」，摘要如「查阅 12 · 命令 3 · 改动 2 · 子 agent 1」。仍在运行的后台任务不收起。
- 默认全部折叠；正在进行的那一组和运行中的子 agent 保持展开。你手动展开或折叠的会被记住。

::: tip 过程保留期
审批与提问记录永久保存；完整运行过程默认保留 30 天，过期后卡片只保留摘要，显示「运行过程已过期，仅保留摘要」。保留天数由管理员设置，见 [系统参数](/admin/params)。
:::

### 上下文

「上下文」视图显示这一轮结束时 Agent 的上下文窗口状况，帮你判断要不要压缩或开新对话。

![运行详情的上下文页签](/screenshots/web/run-context.webp)

- **已用上下文**：已用 token / 窗口大小，「已用 N% · 剩余 …」，并标注「健康」「偏高」「将满」。
- **提示词缓存**：命中比例，以及多少来自缓存、多少是新增。
- **上下文构成**：用方块图显示「系统提示词与工具定义」、各次工具调用、各轮会话内容与「剩余空间」的占比。
- **内容**：按「全部」「系统」「工具调用」「会话内容」筛选，列出每一项的大小；较多时点「显示全部 N 项」。

::: info 构成是估算
分项按文本长度估算，系统提示词与工具定义为已用量减去其余各项。会话早先的部分（Agent 压缩或清理过，或机器上的 daemon 重启过）没有分项，合并显示为「系统与早先内容」。分项在本轮结束后统计；Agent 没有上报时显示「这次运行的 Agent 没有上报上下文用量」。
:::

群头部 Bot 条上的上下文圆环、压缩与新对话的用法见 [在群里指挥 Bot](/user/chat)。

## 停止运行

在运行卡片上点「停止」，或在群里发 `/stop @Bot`（见 [指令参考](/user/commands)）。

- 任何群成员都可以停止。
- 排队中的运行立即结束；运行中的运行在机器确认后结束。未处理的审批和提问一并作废。
- Bot 接力中的后续轮次显示「终止整条链」，确认后停止这条接力链上所有未完成的轮次，后续接力不再触发。

停止时如果本轮已经改了文件，卡片显示「已停止 · 本轮改动 N 个文件留在工作区」，并提供两个选择：

| 按钮 | 效果 |
| --- | --- |
| 保留改动 | 默认。不回滚、不自动提交、不 stash |
| 丢弃本轮改动 | 只还原本轮触及的文件，不影响此前已有的未提交改动 |

![停止后选择保留或丢弃改动](/screenshots/web/interrupt-choice.webp)

只有发起人或 Bot 主人可选，没有时间限制。下一轮的上下文会告诉 Agent 上一轮被 `/stop` 中断，以及这些文件的当前状态。

不想停下、只想补充要求时，用「打断并追加」，见 [在群里指挥 Bot](/user/chat)。

## 选择模型与推理强度

输入框里 @ 了 Bot 后，输入框下方出现这个 Bot 的配置标签，如「后端助手 · Sonnet」。点开可选：

![模型与推理强度菜单](/screenshots/web/run-config-chips.webp)

- 「模型」：机器上报的可选模型。列表不对时点「刷新模型」，让机器重新探测。
- 「推理强度」：Agent 支持的推理强度档位。

选择后标签显示「仅本条」，只对这条消息生效。在菜单里点「设为本群默认」，则作为这个 Bot 在本群的默认配置。

生效顺序：本条消息的选择 → 本群默认 → Bot 自己的默认配置（见 [Bot 设置与权限](/user/bot-settings)）。

- 只有 Bot 主人或群管理员能切换，其他人看到「只有 Bot 主人或群管理员可以切换」。
- 机器还没上报可选模型时，标签不可用，提示「机器尚未上报可选模型」。

审批方式不在这里选，见 [审批与提问](/user/approvals)。
