# 代码变更与文件

本页讲怎么查看 Bot 改了哪些代码（diff 面板）、Git 条，以及在文件查看器里浏览工作区文件和消息附件。

这些内容都在右侧**工作台**里以标签页打开。工作台的布局与快捷键见 [结果预览](/user/previews#预览工作台)。

## diff 面板

### 打开方式

- 运行卡片上的「改动 N 个文件」、回复下方的文件标签或「+N」：打开这一轮的改动。
- 过程面板里点某个编辑文件的步骤：直接定位到该文件的改动。
- 群头部 Git 条上的「改动」：打开标签页「改动 · Bot 名」。

![diff 面板](/screenshots/web/diff-pane.webp)

### 改动范围

面板顶部的「改动范围」可切换：

| 范围 | 内容 |
| --- | --- |
| 本轮 | 这一轮运行改动的文件（仅从运行打开时有） |
| 未提交 | 工作区里全部未提交的改动 |
| 对比主分支 | 当前分支相对基准分支的全部改动 |

从 Git 条打开时，工作区有未提交改动则默认「未提交」，否则「对比主分支」。运行进行中，diff 会自动刷新。

### 文件列表与 diff

- 左侧文件列表显示每个文件的名称、目录、新增与删除行数，以及一条增删比例条（悬停显示「新增 N 行，删除 M 行」）。
- 点列表上方按钮可在「以列表显示」和「以目录树显示」之间切换，选择会被记住。
- 每个文件旁的「在文件浏览器中定位」可跳到文件标签页查看完整文件。
- 右侧是统一视图（上下对照）的 diff，带代码高亮。
- 面板较窄时，文件列表收成下拉框「N 个文件」。

没有改动时显示「本轮没有文件改动」「没有未提交的改动」或「当前就在主分支，没有可对比的改动」。

## Git 条

绑定了仓库的群，群头部下方显示每个 Bot 工作区的分支、领先/落后提交数、是否有未提交改动和工作区类型，并提供「改动」「文件」两个入口。

![群头部 Git 条](/screenshots/web/gitbar.webp)

各字段含义见 [仓库与工作区](/user/repos-workspaces#git-条)。

## 文件查看器

点 Git 条上的「文件」，打开标签页「文件 · Bot 名」，只读浏览这个 Bot 工作区里的文件。

![文件查看](/screenshots/web/file-viewer.webp)

### 文件树

- 目录在前、文件在后，展开时再加载。
- 有未提交改动的文件标注「M」。
- 勾选「显示忽略的」可显示被 git 忽略的文件。
- 「搜索文件」按文件名查找；「刷新」重新读取。
- 顶部面包屑从「工作区」开始，点击可快速返回上级。
- 一个目录超过 1000 项时只显示前 1000 项。
- 选中的文件高亮显示并自动滚动到可见位置。

宽屏下点工具栏的「收起目录」可把文件树收起，完整查看文件内容，再点「展开目录」恢复。窄屏下文件树打开时会覆盖文件内容。

### 查看文件

| 文件类型 | 显示方式 |
| --- | --- |
| 代码与文本 | 行号 + 代码高亮；`.log`、`.txt` 等日志里含 ERROR / FAIL / WARN 的行会着色 |
| Markdown | 可切换「预览」和「源码」 |
| 图片 | 可切换「适应」和「1:1」，显示尺寸 |
| 视频、音频、PDF | 直接播放或显示 |
| 二进制或不支持的类型 | 提示可下载查看 |

工具栏还有：

- 「复制路径」：复制文件在工作区里的路径。
- 「下载」。
- 「在新标签页打开」。
- 「在聊天中引用」：把 `@文件路径` 填进输入框，方便让 Bot 针对这个文件干活。

::: warning 大小限制
超过 2 MB 的文件不预览，只能下载；文本文件最多显示前 5000 行。
:::

## 附件查看器

点消息里的附件（或「在工作台查看」），在工作台打开以文件名命名的标签页，查看方式与文件查看器相同，另外显示：

| 项 | 说明 |
| --- | --- |
| 来源 | 谁在哪条消息里发的 |
| 大小 | 文件大小 |
| 位置 | 在 Bot 工作区里的路径（`.gonggong/attachments/…`） |
| 发送给 Bot | 图片：Agent 支持图片时直接发送，同时落盘供按路径读取；视频：不直接发送，由 Agent 按路径读取 |
| 工作树 | 已加入 `.git/info/exclude`，不进 git |

附件的上传与限制见 [在群里指挥 Bot](/user/chat#附件)。
