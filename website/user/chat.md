# 在群里指挥 Bot

本页讲怎么在群里让 Bot 干活：@ 触发、输入框、背景上下文、附件、Bot 回复里的内容、引用回复、打断并追加、消息操作、搜索和上下文占用。

![群消息全景](/screenshots/web/chat.webp)

## @ 触发 Bot

在输入框里 `@` Bot 的名字，写上需求，按 Enter 发送：

```text
@后端助手 看一下登录接口为什么偶尔 500，找到原因后修复并跑测试
```

1. 输入 `@`，或点输入框工具栏的「@ 提及」，弹出候选。
2. 用 ↑ / ↓ 选择，Enter 或 Tab 插入，Esc 关闭。
3. 发送后，消息立即出现在列表里，群里随即出现这个 Bot 的运行卡片，过程见 [运行过程](/user/runs)。

![输入 @ 弹出候选](/screenshots/web/composer-mention.webp)

`@` 候选分两组：

| 分组 | 内容 |
| --- | --- |
| 成员 / Bot | 群里的 Bot（带在线状态）和成员。群管理员在群里（不在话题里）还能看到「所有人」 |
| 文件 | Bot 工作区里的文件和文件夹，选中后插入 `@路径`，告诉 Bot 看哪个文件 |

- 候选支持拼音检索：全拼、首字母、混拼都行，如 `jwc`、`jiangwc` 都能找到「姜维川」，命中的字会加粗。
- 一条消息里 @ 多个 Bot，每个 Bot 各起一个运行，并行执行。
- @ 成员只是提醒对方，不会触发 Bot；@所有人 会提醒全体成员。
- 和只有一个 Bot 的私聊里不用 @，直接发就会触发它。
- 删除 `@名字` 时，按一次退格会选中整个提及，再按一次整体删除。

@ 了 Bot 后，输入框上方会出现这个 Bot 的模型与推理强度，可以只为这条消息临时切换，见 [运行过程](/user/runs)。

以下情况 Bot 不会开工，群里会出现说明：

| 提示 | 原因 |
| --- | --- |
| 该 Bot 仅允许主人触发，未启动运行 | Bot 的触发范围是「仅本人」 |
| 该 Bot 仅允许指定名单触发，未启动运行 | 你不在它的触发名单里 |
| Bot 未绑定或未确认，不能被触发 | Bot 还没绑定到机器 |
| 某某 等待 某某 确认工作区，本次未执行 | Bot 主人还没确认工作区，见 [仓库与工作区](/user/repos-workspaces#进群时用哪个目录) |
| 某某 所在机器无法访问仓库，本次未执行 | 见 [Bot 暂停](/user/repos-workspaces#bot-暂停) |

Bot 主人总能触发自己的 Bot。触发范围在 [Bot 设置与权限](/user/bot-settings) 里改。

::: tip Bot 之间的接力
Bot 回复正文里写 `@另一个 Bot` 只是提及，不会触发对方；回复下方会出现「让 某某 处理」按钮，点一下把 `@某某` 填进输入框，由你决定是否发送。

Bot 需要另一个 Bot 真正动手时，会把任务交出去：本轮结束后，群里发出一条它 @ 对方并交代任务的消息，对方随即开始运行，这就是接力。接力按原始触发人校验触发权限，默认最多 3 跳（群级参数「接力链长上限」），见 [群与私聊](/user/groups#群级参数)。Bot 也可以开一个话题并指派 Bot 在话题里接手，见 [话题](/user/schedules-threads#话题)。
:::

## 输入框

输入框工具栏从左到右：「@ 提及」「表情」「命令」「附件」「图片」，群里启用了创作插件时还有「✦ 创作」。

| 按键 | 作用 |
| --- | --- |
| Enter | 发送 |
| Shift + Enter，或 Ctrl / ⌘ / Alt + Enter | 换行 |
| ↑（输入框为空时） | 编辑自己的上一条消息 |
| `/` | 指令与 Skill 候选，见 [指令参考](/user/commands) |
| `#` | 选本群的作品，见 [原型、画布与作品库](/user/artifacts) |
| ⌘K / Ctrl+K | 全局搜索 |
| Esc | 把当前会话标为已读 |

- 「表情」打开表情面板，有 8 类近 400 个表情。
- 没发出去的草稿按群（和话题）分别保存，在当前浏览器标签页里切换会话或刷新页面后还在。
- 消息按 Enter 后立即出现在列表里。网络不通时这条消息原地标「发送失败」，可以「重发」或「删除」；被服务器拒收时（如没有权限），内容退回输入框并提示原因。

## 没 @ 的消息：背景上下文

没有 @ 的消息不会触发 Bot。输入了内容却没 @ Bot 时，输入框下方会提示「未 @ 的消息不会触发 Bot，会作为背景补充给下一次任务」。

Bot 下一次被触发时，会带上它上次运行之后、这次触发之前的群消息：

- 从最新往前带，默认总量约 **8000** token（按字数估算，不限条数），由管理员在系统参数里调整，见 [系统参数](/admin/params)。
- 更早的消息不直接附带，Bot 需要时会自己去读群记录。
- 不算在内：Bot 自己的消息、指令消息、已撤回的消息、没有同时发送到群的话题回复。

所以可以先把背景、链接、截图分几条发到群里，最后再 @ Bot 下达任务。

## 附件

点工具栏的「附件」或「图片」，或把文件粘贴进输入框、拖到消息区（提示「将文件拖到这里」）。附件随下一条消息发给群里的 Bot。

![消息中的图片和附件](/screenshots/web/attachments.webp)

| 限制 | 默认值 | 说明 |
| --- | --- | --- |
| 单个附件大小 | 50 MB | 管理员可在系统参数里调低 |
| 每条消息附件数 | 10 个 | 管理员可在系统参数里调低 |

- 文件类型不限。选择后立即上传并显示进度，上传完才能发送。
- 发送前可以点附件「发送前预览」：文本、代码、Markdown、PDF、Office、音视频、SVG 都能直接看。
- 附件写进 Bot 工作区的 `.gonggong/attachments/` 目录，已加入 `.git/info/exclude`，不进 git。
- 图片：Agent 支持图片时直接作为图片发给它，同时落盘供按路径读取。视频和音频不直接发送，由 Agent 按路径读取。
- 消息里的附件可以「查看大图」「下载」「在工作台查看」，见 [代码变更与文件](/user/diff-files)。

超限时会提示「某文件 超过 50 MB，未添加」或「每条消息最多 N 个附件」。

### 视频与语音

聊天里的视频和音频用共工自带的播放器播放，同一页同时只播一个。

![聊天里的视频播放器](/screenshots/web/video-player.webp)

- **视频**：大播放键、可拖动的进度条（显示已缓冲部分，悬停看时间）、快退 / 快进 10 秒、音量、倍速（0.5–2×）、画中画、全屏。音量和静音会在各播放器之间记住。播放中鼠标静止一会儿，控件和光标自动隐藏。
- 视频获得焦点后可以用快捷键：Space / K 播放暂停，← / → 快退快进，J / L 也是快退快进，↑ / ↓ 调音量，M 静音，F 全屏，0–9 跳到对应位置，Shift + < / > 调倍速。
- **音频**显示为语音条：点播放，拖动或用方向键定位，点时间切换 1× / 1.5× / 2× 倍速。

## Bot 回复里的内容

- Bot 的长回复会自动折叠，点「展开全文」查看，「收起」折回。
- 回复里的文件路径可以点击，直接在工作台打开。
- Mermaid 图表直接渲染成图。
- **网页嵌入**：Bot 可以把一个 HTML 页面直接嵌在回复里，按聊天栏宽度排版，可以「全屏查看」；页面里的图片点开用共工的图片查看器。
- **按钮选择**：Bot 需要你做选择时，会在回复下方放一组按钮。点一个（或多选后确认），群里以你的身份发出「@Bot 选择了「…」」，Bot 接着干活。每组按钮只能有一人作答，结果所有人可见。

## 引用回复

把鼠标移到消息上，点「引用回复」。输入框上方出现「引用 某某」和被引用内容。

- **引用 Bot 的消息或运行卡片**：输入框里自动 @ 这个 Bot，提示「已自动 @ Bot，删掉 @ 就只引用、不触发」。
- **引用成员的消息**：只作为补充上下文，不触发任何 Bot。
- 引用内容最多带 2000 个字符。点引用可以跳回原消息。
- 被引用的消息之后被撤回，引用处显示「该消息已撤回」。

## 运行中打断并追加

Bot 还在跑时想补充要求，不用等它结束：

1. 在运行卡片上点「打断并追加」。
2. 输入框上方出现「打断并追加到 某某 · 已改内容保留，仍算同一轮」。
3. 输入补充内容（可带附件）后发送。

![运行中追加消息](/screenshots/web/append.webp)

- Bot 会中断当前这一步，带着你的追加内容在**同一轮**里继续，已经改好的文件保留。
- 这一轮里还没处理的审批和提问会被撤回。
- 只有触发人或 Bot 主人能打断并追加，否则提示「仅触发人或 Bot 主人可以打断并追加」。
- 发送时运行已结束，会提示「该运行已结束，请直接发送」。
- 追加消息里的 `/` 指令不会执行。

停止运行见 [运行过程](/user/runs)。

## 表情回应

把鼠标移到消息上，点「表情回应」，可选 👍 ✅ 👀 🎉 ❤️ 😂 六种。

![消息表情回应](/screenshots/web/reactions.webp)

- 再点一次同一个表情即取消。
- 消息下方显示回应，最多列出 3 个名字，其余显示「等 N 人」。

## 消息操作

鼠标悬停在消息上出现操作条（「回复话题」「引用回复」「复制」「更多」）；右键消息打开完整菜单；触屏上长按消息。

| 操作 | 说明 |
| --- | --- |
| 回复话题 | 在这条消息下开话题讨论，见 [话题](/user/schedules-threads#话题) |
| 表情回应、引用回复 | 见上文 |
| 复制 | 复制消息文字；先选中一部分时只复制选中的 |
| 稍后处理 | 收藏这条消息并设提醒，见 [通知](/user/notifications#稍后处理) |
| 复制链接 | 复制这条消息的链接 |
| 从这里标为未读 | 把未读分隔线挪到这条消息，见 [通知](/user/notifications#未读) |
| 置顶 / 取消置顶 | 置顶到群顶部，每个群最多 5 条 |
| 存入知识库 | 用这条消息新建知识库条目，见 [知识库与密钥](/user/knowledge-secrets#存入知识库) |
| 分支到新聊天 | 仅 Bot 主人，对这个 Bot 最近一次完成的回复可用：新开一个与它的私聊，从这一轮接着聊 |
| 编辑 | 仅自己发的普通消息，24 小时内 |
| 撤回 | 仅自己发的消息，24 小时内。所有人都看不到内容 |
| 删除 | 仅自己发的消息，不限时间。只对你隐藏，其他成员仍可见 |

**编辑**：

- 改完按 Enter 保存，Esc 取消；消息标「已编辑」。
- 不能改 @ 的对象，指令消息不能编辑。
- 这条消息触发的运行已经开始的，会被停止并按新内容重新运行；还在排队的直接用新内容。

**撤回**：

- 超过 24 小时提示「超过 24 小时，无法撤回」。
- 这条消息触发的运行如果还在排队或等待，会作废；已经开始的运行会继续。
- 撤回后 5 分钟内，可以点「重新编辑」把内容（包括附件）放回输入框。

## 搜索

按 ⌘K（Windows / Linux 上 Ctrl+K）打开全局搜索：

- 还没输入时列出「最近」的会话；输入后按会话名匹配。
- 下方分「消息」「文件」「运行」三个页签，搜当前团队里你所在的群。话题里的回复会直接在话题里打开。
- ↑ / ↓ 选择，Enter 打开，Esc 关闭。

## 手机端

在手机上滑动消息区时，顶部的 Git 条、标签和提示条会收起，输入框缩成一行，给消息留出更多空间；滑回底部，或点输入区，就恢复原样。

## 上下文占用与压缩

群头部 Bot 条上，每个 Bot 旁边有一个圆环，表示它当前会话的上下文占了模型上下文窗口的多少。鼠标悬停显示「上下文 已用 / 总量」，Agent 会自动压缩时还显示「还剩 N 自动压缩」。

![上下文占用](/screenshots/web/context-meter.webp)

- 圆环上的刻度标出 Agent 自动压缩的位置，快到时变橙色；Agent 关闭了自动压缩时，刻度标出它会停下的位置，并提示「已关闭自动压缩，用到 N 时 Agent 会停下，需要手动压缩或开新对话」。
- Bot 在这个群里跑过至少一轮、且 Agent 上报了用量后才显示。

点圆环打开面板：

| 操作 | 效果 |
| --- | --- |
| 压缩上下文 | 在群里发出 `/compact @Bot`，把此前的对话总结后保留。可以先在「压缩时保留的重点（可选）」里写要保留什么 |
| 开新对话 | 在群里发出 `/new @Bot`，下一轮不再带上此前的对话 |

::: tip
- 「压缩上下文」依赖 Agent 提供 `compact` 命令，作为 Agent 命令原样转交给 Agent 执行，见 [指令参考](/user/commands#agent-命令)。
- Bot 在群里闲置超过一段时间（默认 6 小时，系统参数「Bot 闲置后下次对话自动开新会话」）后，下次对话会自动开新会话，运行卡片注明「距上次对话较久，已开启新会话」。
:::
