# 外观与主题

本页讲怎样切换浅色 / 深色主题、调整玻璃效果，以及界面上其他会被记住的布局偏好。

## 设置入口

点击头像菜单里的「设置…」，默认打开「外观」页。

![设置 · 外观](/screenshots/web/settings-appearance.webp)

## 主题

| 选项 | 效果 |
| --- | --- |
| 浅色 | 默认 |
| 深色 | 深色背景，适合夜间 |
| 跟随系统 | 跟随操作系统的浅色 / 深色设置，系统切换时自动跟着变 |

![深色主题下的群](/screenshots/web/theme-dark.webp)

登录页右上角也有一个按钮，可以直接在浅色和深色之间切换。

## 玻璃效果

工具栏、菜单、弹出面板、提示条等半透明「玻璃」层的质感：

| 选项 | 效果 |
| --- | --- |
| 清透 | 更透明，能透出更多背后的内容 |
| 标准 | 默认 |
| 着色 | 不透明、无模糊，文字最清晰 |

::: tip
如果在操作系统里开启了「减少透明度」，无论选哪一项，玻璃层都会显示为不透明。
:::

## 偏好保存在哪里

主题和玻璃效果保存在**当前浏览器**里，不随账号同步：换一台机器或换一个浏览器需要重新设置；浏览器的无痕模式下关闭窗口后会恢复默认。

以下布局也会记在当前浏览器里：

- 右侧群信息侧栏的宽度、聊天栏的宽度（拖动分隔条调整）；
- 工作台的布局（分栏 / 专注 / 全屏）和各群已打开的标签页；
- 上次打开的群，下次进入时自动回到它；
- 登录页勾选「记住我」后记住的账号。

布局操作见 [界面导览](/user/interface)。
