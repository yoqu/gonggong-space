# 绑定机器

Bot 在成员自己的机器上运行。本页讲怎样把一台机器绑定到你的账号、查看机器详情，以及吊销机器。

## 开始之前

机器上需要先装好共工空间客户端，二选一：

- **桌面端「共工空间」**（macOS）：自带 daemon，不用开终端，见 [桌面端](/desktop/)。
- **命令行 `gg`**（macOS / Linux / Windows）：见 [命令行安装](/cli/)。

Claude Code、Codex 和 Node.js 可以先不装，绑定后可以在 Web 上一键安装，见 [Agent 工具与供应商](/user/agents-providers)。

## 生成接入链接

1. 点击头像菜单里的「绑定新机器」（也可以点侧栏「我的机器」旁的「+」，或欢迎页的「绑定机器」）。
2. 对话框会自动生成一个一次性的**接入链接**，10 分钟内有效，倒计时显示在下方。

![绑定新机器对话框](/screenshots/web/bind-machine.webp)

对话框顶部的步骤条显示进度：「生成接入链接」→「客户端绑定」→「上报机器与 agent」。

::: tip
接入链接过期后会显示「接入链接已失效」，点「重新生成」即可。每个链接只能用一次。
:::

## 在机器上完成绑定

### 方式一：桌面端

- 在要绑定的那台 Mac 上打开网页，点击「在客户端中打开」，桌面端会自动带入链接。
- 或者点「复制接入链接」，粘贴到桌面端首次引导的「接入链接」输入框里。

桌面端会显示服务器地址和绑定码，确认是你们团队的服务器后点「绑定」。详见 [桌面端首次引导](/desktop/onboarding)。

### 方式二：命令行

展开对话框里的「使用命令行」，点复制按钮，在机器的终端里执行。命令形如：

```bash
gg login --server https://gg.example.com --code ABCD-EF23
```

也可以直接把接入链接交给 `gg login`：

```bash
gg login 'gonggong://bind?server=…&code=…'
```

绑定成功后终端会输出「绑定成功：本机已归属 王磊（…）」。然后启动 daemon，让机器保持在线：

```bash
gg run
```

`gg run` 在前台运行，关闭终端就会离线。想让它在后台常驻，见 [命令行](/cli/)。

### 绑定完成

绑定成功后，Web 端对话框会自动变为「绑定成功」，并列出这台机器上检测到的 Claude Code / Codex 及版本，点击「完成」关闭。机器随即出现在侧栏「我的机器」里。

::: warning 常见报错
- 「绑定码已失效（已过期或已被使用），请在 Web 端重新生成」：回到 Web 重新生成接入链接。
- 「尝试次数过多，绑定码已锁定」：同一网络短时间内输错太多次，等 10 分钟后重新生成。
- 「无法连接服务器 …」：检查服务器地址是否能从这台机器访问（防火墙、端口、内网/VPN）。
:::

::: tip 服务器地址与证书
`http://` 和 `https://` 地址都可以绑定；`https://` 服务器用自签证书也能直接绑定，客户端不校验证书指纹。没有自己的服务器时，可以直接绑定演示环境 `http://gg.uyoqu.com`。
:::

## 多台机器

一个账号可以绑定多台机器（比如办公室的 Mac 和一台 Linux 云主机），每台各生成一次接入链接。创建 Bot 时选择它在哪台机器上运行，见 [创建 Bot](/user/create-bot)。

- **同一台机器重新绑定**：会恢复原来的机器记录和上面的 Bot，Web 显示「已恢复原有机器」。
- **机器换主人**：如果这台机器之前归属别人，且上面还有他的 Bot，绑定会被拒绝，需要原主人先删除这些 Bot。

## 机器详情

在侧栏「我的机器」里点击一台机器，打开「机器详情」。

![机器详情](/screenshots/web/machine-dialog.webp)

「概览」页显示：

- 主机名、系统版本、架构、daemon 版本，以及「在线 / 离线」；
- **名称**：可以改成好认的名字（最多 64 个字），留空则使用主机名，点「保存」；
- CPU、内存、内核、MAC 地址；
- **Agent**：检测到的 Claude Code / Codex 版本，或「未安装」；
- **运行的 Bot**：这台机器上的 Bot 及状态，点击进入 Bot 概况页；
- 最后在线时间（离线时）、首次绑定、最近绑定时间。

另外两页「Agent 工具」「供应商」只有机器主人能看到，且需要机器在线，见 [Agent 工具与供应商](/user/agents-providers)。

## 吊销机器

不再使用某台机器时，在机器详情左下角点击「吊销机器」，确认后点「吊销」：

- 该机器的 daemon 立即断开；
- daemon 会清理本机托管工作区，`/cd` 指定的目录与备份保留；
- 之后要再用这台机器，需要重新生成接入链接绑定。

::: warning
机器上还有 Bot 时不能吊销，会提示「还有 N 个 Bot 绑定在这台机器上，请先删除」。先在 [Bot 设置](/user/bot-settings#删除-bot) 里删除这些 Bot。
:::

只想让这台机器暂时下线，停掉 `gg run` 或退出桌面端即可，不必吊销。在机器上执行 `gg logout` 会删除本机凭据，以后再 `gg login` 会恢复这台机器及其 Bot。
