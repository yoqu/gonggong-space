# 用量

本页介绍「用量」页：按 Bot、触发人或群汇总全系统近 30 天的 token 用量。

![管理后台 · 用量](/screenshots/web/admin-usage.webp)

## 查看方式

顶部三个标签切换汇总维度：

- **按 Bot**：每个 Bot 消耗了多少。
- **按触发人**：谁 @ Bot 触发的运行消耗了多少。
- **按群**：每个群消耗了多少。

标签下方依次是汇总数字、每日趋势图、占比分布，以及明细表：

| 列 | 说明 |
| --- | --- |
| Bot / 触发人 / 群 | 随所选维度变化 |
| 占比 | 该行 token 占最高一行的比例条 |
| token | token 合计；没有任何上报时显示「未上报」 |
| 轮次 | 运行轮数 |
| 未上报 | 适配器没有上报用量的轮数 |

统计窗口固定为近 30 天，趋势图的日期按浏览器所在时区划分。

## 注意事项

- 用量只做统计，**不做配额限制**，超用不会被拦截。
- 用量来自 Agent 适配器的上报。Codex 适配器未上报用量的轮次计为「未上报」，不计入 token 合计，因此 Codex Bot 的 token 数可能偏低。
- 成员在头像菜单「我的用量」里看到的是同一套统计，但只包含自己的 Bot。管理后台看到的是全部 Bot。
