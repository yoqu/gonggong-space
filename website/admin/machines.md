# 机器

本页介绍「机器」页：查看所有成员机器的系统、版本、在线状态和网络质量，处理过旧的 daemon，以及如何吊销一台机器。

![管理后台 · 机器](/screenshots/web/admin-machines.webp)

## 机器列表

页面标题为「机器与网络」，工具栏显示「N 台 · M 台在线」，列表每 15 秒自动刷新一次。右上角搜索框可按机器名、主机名或主人过滤。

| 列 | 说明 |
| --- | --- |
| 主人 | 机器归属的成员 |
| 机器 | 机器名（未改名时即主机名，鼠标悬停可看主机名） |
| 系统 | 操作系统及版本 |
| 硬件 | CPU 型号、核数、内存 |
| daemon | daemon 版本。协议过旧的版本标为警示色 |
| Agent 版本 | 机器上可用的各 Agent 版本；有新版本时显示「可升级」，悬停可看最新版本和「共工空间托管 / 自行安装」 |
| 延迟 / 带宽 | 最近一次网络测量结果，悬停可看测量时间 |
| 状态 | 在线 / 离线 |
| 最后心跳 | 在线显示「刚刚」；离线显示多久以前，从未连上显示「从未连接」 |

已吊销的机器不出现在列表中。

### 网络质量

延迟和带宽由成员在自己机器上测量后上报：命令行执行 `gg net`，或在桌面端点「测量延迟与带宽」。结果只在这里展示，不会出现在群里。

## 机器详情

双击一行，或选中后点工具栏「机器详情…」，打开这台机器的页面（与机器主人看到的是同一个页面），顶部提示「正在以管理员身份查看 某人 的机器」，点「返回后台」回到列表。

系统管理员在这里只能看到「概览」：系统信息、在线状态、运行的 Bot 和版本信息，可以给机器改名或吊销。「Agent 与供应商」「工作区」「Git 访问」「诊断」「插件授权」和终端只有机器主人本人能用，管理员无法代为安装工具、修改供应商或升级 daemon。供应商的 Key、URL 等只保存在成员机器本地，服务器不存储。机器主人的操作见 [我的机器与 Bot](/user/machines)。

## daemon 版本与升级

### 协议过旧提醒

daemon 的协议版本低于服务器时，服务器会拒绝它连接，页面底部出现黄色提示「N 台 daemon 协议版本过旧」，并列出机器名、版本和协议版本。

### 怎样让机器升级

先在 [客户端发布](/admin/releases) 上传新版本，之后各类机器的升级方式不同（机器页「概览」里的「如何升级」会按机器类型给出对应说明）：

| 机器 | 升级方式 |
| --- | --- |
| 命令行 `gg`（macOS / Linux / Windows） | 在线时自动下载新版本，没有任务运行时重启完成升级；协议过旧被拒的 daemon 会立即升级 |
| Linux 命令行 daemon | 除自动升级外，机器主人还可以在机器页点「立即升级」：下载后在空闲时自动重启，不打断正在运行的任务 |
| Docker 容器里的 daemon | 新版镜像把 `gg` 放在数据卷里，机器主人同样可以在网页「立即升级」，重建容器也不丢；较旧的镜像需要在服务器上修改 `GG_VERSION` 后重建容器，见 [Docker 部署](/deploy/docker) |
| 桌面端 | 桌面端作为应用整体更新，见 [客户端发布](/admin/releases#桌面端自动更新) |

关闭了自动升级的机器，需要机器主人手动重启 daemon 或更换 `gg`，见 [命令行安装](/cli/)。

## 吊销机器

机器丢失、成员离职，或怀疑 token 泄露时，可以吊销机器：

1. 在该行菜单选择「吊销机器…」，或在机器页点「吊销」。
2. 确认对话框「要吊销机器 xxx 吗？」，点「吊销」。

吊销后：

- 该机器的 daemon 立即断开，token 作废。
- daemon 会清理该机器上的托管工作区；用 `/cd` 指定的目录与备份保留。
- 要再次使用，成员需要重新生成接入链接并绑定，见 [绑定机器](/user/bind-machine)。

吊销会写入 [审计记录](/admin/audit)。要一次性断开某个成员的所有机器和登录，可以直接 [停用账号](/admin/users#停用与启用)。
