# 机器

本页介绍「机器」页：查看所有成员机器的系统、版本、在线状态和网络质量，以及如何吊销一台机器。

![管理后台 · 机器](/screenshots/web/admin-machines.webp)

## 机器列表

页面标题为「机器与网络」，工具栏显示「N 台 · M 台在线」，列表每 15 秒自动刷新一次。右上角搜索框可按机器名、主机名或主人过滤。

| 列 | 说明 |
| --- | --- |
| 主人 | 机器归属的成员 |
| 机器 | 机器名（未改名时即主机名，鼠标悬停可看主机名） |
| 系统 | 操作系统及版本 |
| 硬件 | CPU 型号、核数、内存 |
| daemon | daemon 版本。协议过旧的版本标为警示色 |
| Agent 版本 | 机器上可用的 Claude Code / Codex 版本；有新版本时显示「可升级」，悬停可看最新版本和「共工托管 / 自行安装」 |
| 延迟 / 带宽 | 最近一次网络测量结果，悬停可看测量时间 |
| 状态 | 在线 / 离线 |
| 最后心跳 | 在线显示「刚刚」；离线显示多久以前，从未连上显示「从未连接」 |

已吊销的机器不出现在列表中。

### 网络质量

延迟和带宽由成员在自己机器上测量后上报：命令行执行 `gg net`，或在桌面端点「测量延迟与带宽」。结果只在这里展示，不会出现在群里。

延迟高于、或带宽低于 [系统参数](/admin/params#同步与锁) 里「开启强制同步」两个阈值的机器，会以红色和警示图标标出，方便发现网络较差的机器。

### 协议过旧提醒

daemon 的协议版本低于服务器时，服务器会拒绝它连接，页面底部出现黄色提示「N 台 daemon 协议版本过旧」，并列出机器名和版本。处理方式：

- 在 [客户端发布](/admin/releases) 上传新版本。能下载新版的 daemon 会立即自动升级。
- 关闭了自动升级或没有写权限的机器，需要成员手动更换 `gg`，见 [安装](/cli/)。

## 机器详情

双击一行，或选中后点工具栏「机器详情…」，打开机器详情：系统信息、在线状态和运行的 Bot。系统管理员可以在这里给机器改名或吊销。

::: tip
「Agent 工具」和「供应商」只有机器主人本人能管理，管理员无法代为安装工具或修改供应商。供应商的 Key、URL 等只保存在成员机器本地，服务器不存储。详见 [Agent 工具与供应商](/user/agents-providers)。
:::

## 吊销机器

机器丢失、成员离职，或怀疑 token 泄露时，可以吊销机器：

1. 在该行菜单选择「吊销机器…」。
2. 确认对话框「要吊销机器 xxx 吗？」，点「吊销」。

吊销后：

- 该机器的 daemon 立即断开，token 作废。
- daemon 会清理本机托管工作区；用 `/cd` 指定的目录与备份保留。
- 要再次使用，成员需要重新生成绑定码并执行 `gg login`。

吊销会写入 [审计记录](/admin/audit)。要一次性断开某个成员的所有机器和登录，可以直接 [停用账号](/admin/users#停用与启用)。
