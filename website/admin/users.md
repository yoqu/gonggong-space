# 账号与角色

本页说明系统管理员如何在「账号与角色」页创建账号、分配角色、重置密码，以及停用账号会带来什么影响。

![管理后台 · 账号与角色](/screenshots/web/admin-users.webp)

## 角色

共工Bot 只有两种账号角色：

| 角色 | 能做什么 |
| --- | --- |
| 普通成员 | 登录 Web、绑定自己的机器、为自己创建 Bot、建群与私聊、在群里指挥 Bot；只能看到和修改自己的 Bot 与机器 |
| 系统管理员 | 普通成员能做的全部，外加进入管理后台：管理账号、为任何成员新建或修改 Bot、查看所有群与机器、吊销机器、配置中心、系统参数、客户端发布、全局用量、公开链接与审计记录 |

::: warning 系统管理员也改不了的东西
Bot 的「命令审批」（每次询问 / 白名单自动 / 全部自动）和白名单只有 Bot 主人本人能改，系统管理员也不行。为他人创建的 Bot 固定从「每次询问」开始。这样管理员无法远程放开别人机器上的命令执行。
:::

「群管理员」不是账号角色，而是群内的身份，在群设置里指定，见 [群与私聊](/user/groups)。

## 账号列表

表格列出所有账号：

| 列 | 说明 |
| --- | --- |
| 成员 | 头像与姓名 |
| 账号 | 登录用的账号名 |
| 角色 | 系统管理员 / 普通成员 |
| 机器 | 绑定的机器数量与在线情况，如「2 台 · 在线」；没有绑定显示「未绑定」 |
| 状态 | 「正常」、「待修改密码」（还没用初始密码登录并改密）或「已停用」 |

右上角搜索框可按姓名或账号过滤。双击一行打开编辑；每行右侧的操作菜单有「编辑…」「重置密码…」「停用…」（已停用的账号显示「启用」）。不能对自己执行重置密码和停用。

## 新建账号

1. 点击工具栏「新建账号…」。
2. 填写：
   - **账号**：2–32 位小写字母、数字或 `.` `_` `-`，如 `wanglei`。创建后不能修改。
   - **姓名**：界面上显示的名字，如「王磊」。
   - **角色**：普通成员或系统管理员。
   - **初始密码**：已自动生成一个易读的临时密码（形如 `k7qm-4x2p-9d`），可点「重新生成」或自己改写，至少 8 位。
3. 点击「创建」。账号和初始密码会一起复制到剪贴板，私下发给对方即可。

![「新建成员」对话框](/screenshots/web/admin-user-new.webp)

对方首次登录时会被要求修改初始密码，改完才能进入系统。见 [登录与账号](/user/login)。

::: tip 自助注册
如果不想逐个建账号，可以在 [系统参数](/admin/params) 里打开「开放自助注册」。开启后登录页出现注册入口，注册的账号一律是普通成员。
:::

## 编辑账号

在「编辑成员」对话框里可以修改**姓名**和**角色**。账号名不能改；不能修改自己的角色（避免唯一的系统管理员把自己降级）。

## 重置密码

成员忘记密码时：

1. 在该行菜单选择「重置密码…」。
2. 对话框里已生成临时密码，可重新生成或改写（至少 8 位）。
3. 点击「重置并复制」，临时密码复制到剪贴板，私下发给对方。

重置后：

- 对方所有网页登录**立即失效**，需要用临时密码重新登录并马上修改。
- 已绑定的机器与 Bot **不受影响**，daemon 继续在线。

## 停用与启用

在该行菜单选择「停用…」，确认后立即生效：

- 立即吊销该成员所有 daemon token 和 Web 会话，登录页会提示「账号已停用，请联系系统管理员」。
- daemon 下次连接失败后清除本机托管工作区（尽力而为，不保证一定执行）。
- 其 Bot 从所有群移除；正在运行的轮次按非主动中断处理。
- 群消息与审计记录保留。

停用的账号可以随时点「启用」恢复登录，但之前被吊销的机器和移除的 Bot 不会自动回来：成员需要重新 [绑定机器](/user/bind-machine)，并把 Bot 重新拉进群。

::: danger
不能停用自己的账号。停用前请确认该成员名下没有需要保留的运行中任务。
:::

## 审计

新建账号、修改姓名或角色、重置密码、停用、启用、自助注册都会写入 [审计记录](/admin/audit)（类型「管理」）。
