# 管理后台概览

本页介绍管理后台是什么、谁能进入，以及每个页面管什么。

## 谁能进入

管理后台只对「系统管理员」开放。系统管理员登录后，聊天窗口最左侧的导航栏会多出「管理后台」图标，点击即可进入；普通成员看不到这个入口，直接访问 `/admin` 也会被带回消息页。

::: tip
成员自己的 Bot、机器、用量都在聊天界面里的弹窗中管理（头像菜单 →「绑定新机器」「我的用量」等），不需要进后台。后台只放全局性的管理与观测功能。
:::

服务器首次启动时会按 `GONGGONG_ADMIN_PASSWORD` 创建第一个系统管理员 `admin`，见 [从源码部署](/deploy/install#首次管理员)。之后可在「账号与角色」里把其他成员设为系统管理员。

## 页面一览

后台左侧导航分三组，底部「返回消息」回到聊天界面。

| 分组 | 页面 | 作用 |
| --- | --- | --- |
| 管理 | [账号与角色](/admin/users) | 创建账号、分配角色、重置密码、停用与启用 |
| 管理 | [Bot](/admin/bots-groups#bot) | 查看全部 Bot 的归属、绑定与状态；为任何成员新建 Bot |
| 管理 | [群](/admin/bots-groups#群) | 查看所有群的模式、仓库、成员数与存档状态 |
| 配置 | [配置中心](/admin/config) | 在仓库基线之上叠加服务器全局层配置（目前为 MCP） |
| 配置 | [系统参数](/admin/params) | 自助注册开关与各项全局默认值 |
| 配置 | [客户端发布](/admin/releases) | 上传 daemon 与 gg-cast 新版本，成员机器自动升级 |
| 观测 | [机器](/admin/machines) | 所有机器的系统、硬件、daemon 版本、在线状态与网络质量；可吊销 |
| 观测 | [用量](/admin/usage) | 按 Bot、触发人、群汇总 token 用量 |
| 观测 | [公开链接](/admin/shares) | 所有预览公开链接，可延长或收回 |
| 观测 | [审计记录](/admin/audit) | 审批、提问、管理员操作等记录，永久保存 |

每个页面顶部是工具栏（标题、数量、操作按钮、搜索框和账户菜单），下方一行灰字说明本页用途。
