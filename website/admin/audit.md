# 审计记录

本页介绍「审计记录」页怎么查，以及系统会记录哪些事件。

![管理后台 · 审计记录](/screenshots/web/admin-audit.webp)

## 查看与筛选

记录按时间倒序排列，**永久保存**，不受「完整运行过程保留」等清理参数影响。

- 顶部分段控件按类型筛选：全部 / 审批 / 提问 / 同步 / 管理 / 运行 / 预览。终端、机器、定时任务等其他类型的记录只在「全部」里出现。
- 「全部操作人」下拉框按操作人筛选；系统自动产生的记录（如审批超时、定时任务自动停用）操作人显示为「系统」。
- 工具栏的团队筛选只看某个团队的记录，默认「全部团队」。
- 右上角搜索框按摘要、群名或操作人搜索。

页面每次载入 50 条，工具栏显示「已载入 N 条」，底部「加载更多」继续往前翻。操作人筛选和搜索只作用于已载入的记录，查较早的事件请先多加载几页，或先用类型、团队筛选缩小范围。

表格列为时间、类型、操作人和摘要。双击一行打开详情，可看到完整摘要、所在群和原始字段。

团队管理员在「团队设置 → 审计」里也能看到本团队的记录。

## 记录哪些事件

### 审批

- 批准、拒绝 Bot 的权限请求，超时自动拒绝。
- 审批请求作废（已 /stop、接力链已终止、运行已结束）。

权限请求只有 Bot 主人能处理，见 [审批与提问](/user/approvals)。

### 提问

- 回答 Bot 的提问、提问超时未答、提问作废。

### 运行

- `/stop` 中断运行、终止整条接力链。
- 保留或丢弃被中断轮次的改动，重新运行。
- `/cd` 切换或恢复 Bot 的工作目录，`/new` 开新会话。
- 中断 Bot 的后台任务。
- Bot 跨群读取其他群的内容。

### 管理

| 对象 | 事件举例 |
| --- | --- |
| 账号 | 新建、修改姓名或角色、重置密码、停用、启用、自助注册、绑定或解绑飞书 |
| 团队 | 新建、归档、恢复、指定所有者、修改团队、接受邀请 |
| Bot | 为他人新建 / 修改 / 删除 Bot，确认 Bot，修改审批方式，「始终允许」新增规则，「本次运行免审批」，设置 Bot 的供应商，批准共享申请 |
| 机器 | 吊销机器、转移到新主人名下、网页确认接入、网页升级 daemon、安装或升级 Agent 工具、修改镜像源与 Agent 设置、保存 / 删除 / 导入供应商 |
| 群 | 修改群名称与公告、删除公告、修改群级参数、设置或取消群管理员、邀请或移出成员、拉入或移出 Bot、绑定或更换仓库、附加仓库、开关同步、解散群 |
| Git | 成员发起 Git 操作申请、主人批准或拒绝、执行 Git 写操作 |
| 配置 | 平台 / 团队 / 群层 MCP、Skill、插件、密钥的增删改；群启用插件；修改系统参数（记录每项旧值和新值） |
| 市场 | 发布、审核、封禁等市场操作 |
| 飞书 | 保存或移除飞书应用，绑定、解绑、创建飞书群，同步群成员 |
| 客户端发布 | 上传或移除 daemon、gg-cast、桌面端文件，修改版本说明，脚本发布 |

### 预览

- 生成公开链接（含有效天数）、收回、修改有效期。
- 通过公开链接访问预览。
- 原型画布等产物的分享。

### 其他

- **终端**：机器主人创建、连接、断开、结束终端会话等。
- **机器**：在网页上删除或清理机器上的工作区。
- **定时任务**：创建、删除、自动停用。

::: tip
「同步」类型目前没有记录。
:::

## 审计里有什么、没有什么

- 审计只记录「谁在什么时候做了什么」和必要的上下文（如账号名、Bot 名、仓库地址），不记录密码、密钥值等敏感内容。
- 审批记录里的命令标题在入库前已统一脱敏，见 [安全模型](/deploy/security#脱敏)。
