# Bot 与群

本页介绍管理后台的「Bot」和「群」两个页面：查看全系统的 Bot 与群、为成员新建 Bot、修改或删除 Bot。

## Bot

![管理后台 · Bot](/screenshots/web/admin-bots.webp)

「Bot」页列出系统里全部 Bot，左侧是表格，右侧是选中 Bot 的详情。右上角搜索框可按 Bot 名、归属人或机器过滤。

### 表格各列

| 列 | 说明 |
| --- | --- |
| Bot | 头像与名称 |
| Agent | 使用的 Agent（Claude Code / Codex）及机器上报的版本 |
| 归属人 | Bot 的主人，对这台机器上的操作负责 |
| 绑定 | 「已绑定」；或橙色标签「待确认」「待绑定」 |
| 机器 | Bot 运行所在的机器 |
| 状态 | 在线空闲 / 运行中 / 离线 / agent 缺失 / 不可触发 |

「不可触发」表示还没完成绑定：

- **待确认**：管理员为他人创建并绑定到对方的机器，需要机器主人在 Web 通知或 Bot 详情中确认后才能被触发。
- **待绑定**：归属人还没有绑定机器。归属人绑定第一台机器并上报对应 Agent 后自动绑定，无需再操作。

### 为成员新建 Bot

系统管理员可以为任何成员创建 Bot，普通成员只能为自己创建。

1. 点击工具栏「新建 Bot…」。
2. 依次选择：
   - **归属人**：Bot 属于谁。
   - **执行机器**：归属人名下的机器（显示系统与在线状态）。归属人还没有机器时可以不选，Bot 进入「待绑定」。
   - **Agent**：Claude Code 或 Codex，旁边显示该机器上报的版本或「未安装」。
   - **名称**、**角色**（性格头像）、**系统提示词**（同时作为群内简介）、**默认工作区**（可选）。
3. 对话框底部会预览创建结果，按钮文字随情况变化：

| 情况 | 按钮 | 结果 |
| --- | --- | --- |
| 为自己创建且已选机器 | 创建并绑定 | 创建后立即可用 |
| 为他人创建且已选机器 | 创建并发送确认 | 进入「待确认」，对方收到确认通知 |
| 未选机器 | 创建 | 进入「待绑定」 |

选中机器没有上报所选 Agent 时，会提示「绑定后暂不可用」，在该机器安装 Agent 并重新检测后自动可用，见 [Agent 工具与供应商](/user/agents-providers)。

### 修改 Bot

选中一行后，右侧详情里可以直接修改角色、系统提示词、默认工作区、供应商、模型与推理强度、触发范围、触发名单、权限档位、并发上限，点「保存」生效（下一次新开会话时生效）。详情还显示所在群数、agent 版本、近 7 天用量和「谁用了」。

各项设置的含义见 [Bot 设置与权限](/user/bot-settings)。

::: warning
「完全访问」档位只允许「指定名单」触发。命令审批与白名单只有 Bot 主人能改，管理员在详情里看得到但改不了。
:::

### 删除 Bot

在该行菜单选择「删除 Bot…」。删除后不可恢复，Bot 会从所在的群移除，群消息与运行记录保留。

为他人新建、修改、删除 Bot 都会写入 [审计记录](/admin/audit)。

## 群

![管理后台 · 群](/screenshots/web/admin-groups.webp)

「群」页只读，列出所有群（包括私聊和已解散归档的群），可按群名或仓库地址搜索。

| 列 | 说明 |
| --- | --- |
| 群 | 群名；私聊显示为「成员 ⇄ Bot」 |
| 模式 | 「分区模式」；已解散的群显示「已归档」 |
| 仓库 | 绑定的 Git 仓库地址；没有绑定显示「未绑定」 |
| 成员 | 群成员人数 |
| Bot | 群内 Bot 数量 |
| 存档 | 已解散的群显示「归档 · N 天后清除」，N 按 [系统参数](/admin/params) 中「删群后存档保留」计算 |

群的日常管理（改名、公告、加减成员和 Bot、换仓库、群级参数、解散）由群管理员在群设置中完成，见 [群与私聊](/user/groups) 和 [仓库与工作区](/user/repos-workspaces)。
