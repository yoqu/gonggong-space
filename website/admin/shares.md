# 公开链接

本页介绍「公开链接」页：集中查看所有群里为 Bot 预览生成的公开链接，并延长或收回它们。

![管理后台 · 公开链接](/screenshots/web/admin-shares.webp)

## 什么是公开链接

Bot 做出的网页等预览，默认只有群成员登录后才能打开。群成员可以为预览生成一个**公开链接**，拿到链接的人不用登录就能访问，适合给外部客户或同事看效果。生成方法见 [公开分享](/user/shares)。

公开链接总是有有效期，最长不超过 [系统参数](/admin/params#其他) 里的「预览公开链接最长有效期」（默认 30 天）。到期、被收回或预览关闭后立即失效，访问者会看到「公开链接已失效或已被收回。」

开启 [演示模式](/admin/params#演示) 后不能创建公开链接，已发出的公开链接也会立即失效。

::: tip
原型画布、作品的分享（可设密码、锁定版本）不在这个列表里，见 [产物与原型画布](/user/artifacts)。
:::

## 链接列表

工具栏显示「N 条 · M 条有效」，右上角可按预览、群或创建人搜索。

| 列 | 说明 |
| --- | --- |
| 预览 | 预览标题 |
| 群 | 预览所在的群 |
| Bot | 开放该预览的 Bot |
| 创建人 | 生成链接的成员 |
| 到期 | 到期时间 |
| 访问 | 通过该链接访问的次数 |
| 状态 | 有效 / 已过期 / 已收回 / 预览已关闭 |

## 延长或收回

有效的链接在行菜单里有两个操作：

- **延长 7 天**：在当前到期时间基础上延长 7 天。到期时间不能超过从现在起的「预览公开链接最长有效期」，超出时会报错。
- **收回**：立即作废，访问者无法再打开。

::: tip
发现链接被误传到外部，直接「收回」即可，无需关闭预览本身；群成员仍可正常查看预览。
:::

生成、延长、收回链接，以及每一次通过公开链接的访问，都会写入 [审计记录](/admin/audit)（类型「预览」）。
