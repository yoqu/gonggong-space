# 共工空间 · 一叶知秋聊AI 口播（191.5s，1920×1080）

Concept: 个人开发者的深夜工位——终端 × 群聊的科技界面。画面是「我」在讲，界面替我演示：消息弹出、终端打字、机器节点连成网。电光蓝单强调色，青绿只表示「通了 / OK」，红只表示「痛点 / 报错」。

## 全局（index.html 已实现，场景不要重复）
- 背景：深蓝黑 + 漂移点阵 + 两团呼吸光晕 + 扫描线。场景根节点保持透明，不要铺满屏背景。
- HUD：左上「logo 一叶知秋聊AI / 开源自荐 · 共工空间」，右上章节 + REC + 时间码，四角取景框，底部进度条。
- 左下主播头像（一叶知秋 IP），随语音起伏的光环；底部居中字幕（关键词蓝色，艾特显示为 @）。
- 安全区：场景内容只放在 y 96–880 之间（`.stage`），x 80–1840；左下 260×260 留给头像，底部 190px 留给字幕。

## 场景写法约定
- 文件 `compositions/sNN.html`，`<template>` 包住 style + `#root`（data-composition-id="sNN"，`class="scene"`）+ script；timeline key = "sNN"。
- 所有 id / class 前缀 `sNN-`，避免和其他场景冲突；可用 kit.css 的公共类（.big .kicker .win .win-bar .term .msg .ava .bubble .chip .node 等）。
- 时间用场景内秒数，对齐 CUES.md 中本场景的句子起点；关键视觉在对应口播开口时出现（可提前 0.1–0.2s）。
- 入场 0.3–0.6s，至少 3 种不同缓动 / 方向；场景最后 0.35s 把内容包裹层淡出（opacity→0，y 或 scale 轻微变化）。不要对 `#root` 本身做 autoAlpha。
- 只用 fromTo；不准 Math.random / Date.now；循环用有限 repeat。
- 截图路径 `assets/shots/<名>.webp`（亮色 UI，放进 `.win` 玻璃窗里，带 3D 倾斜或推近），字体：标题 `.big`（得意黑），正文 GG Sans，代码 JetBrains Mono。
- 中文标题 72–150px；正文 ≥ 28px；不要整句复述字幕，只上关键词 / 数据 / 界面。
- 不编造产品功能和数字；界面文案用产品里的真实叫法（Bot、群、审批、预览、工作区可写……）。
