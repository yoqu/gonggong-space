# 产物与原型编辑器 · 现状

> 范围：产物托管（版本、同步、预览、分享、作品库）与原型编辑器（画布、直接编辑、批注、原型预览、导出），对标 Google Stitch。只写仍有效的决定，以代码为准，更新于 2026-11-15。

## 核心模型

- 真相源在服务端：每轮开跑前把 head 检出到 Bot 工作区，跑完上传为新版本；画布上的人工修改直接在服务端生成新版本。
- 只托管产物目录 `design/<slug>/`（`ArtifactDir`，同群唯一），不托管整个工作区；创建时预分配 `design/<模板>-<4 位随机>`（`plugins/creations.ts`）。
- 表 `artifacts`：群、插件版本、设计系统、`botId`（默认交给它改）、`headVersionId`、卡片 `messageId`、收藏屏 `favorites`、`checkoutBotIds`、`shareToken`、`visibility`、`archivedAt`（`db/schema.ts`）。
- 表 `artifact_versions` 不可变：产物内递增 `n`，`source` 为 `run | edit | local`，`submitKey` 幂等，`files[{path,hash,size}]`、`digest`、缩略图、每屏截图 `screenThumbs`、`stale`、`issues`。
- 表 `artifact_annotations`：按 `(versionId, file, ggId)` 定位，状态 `open → sent → resolved`；发给 Bot 后记 `sentMessageId`（`commands.ts`）。
- 文件内容存独立 blob 目录 `<data>/artifacts/<groupId>/`，与强制同步分开，配额 5GB，版本引用的 blob 永久保留（`artifacts/blobs.ts`）。
- 上限：单文件 10MB、单版 200MB、最多 500 个文件；路径不得含点开头的段和 `node_modules`（`protocol/artifacts.ts` `ArtifactFiles`）。
- 结构 L1：`gg-artifact.json`（title、device `miniprogram|mobile|desktop`、entry、screens[id,title,file,statusBar,prompt,x,y]、refs）+ `tokens.css` + `DESIGN.md` + `screens/<id>.html` + `assets/` + `refs/`。
- 没有 `gg-artifact.json` 的按 L0 单页渲染（入口 `index.html`）。
- 外壳（设备框、状态栏、胶囊、跳转、`_gg/gg-kit.css|js`）属于平台，放在插件 `kit/`；AI 不写也不改。
- 可见范围四档 `private | group | team | all`，默认 `group`；群外成员（team/all）只读。
- 权限入口：只读接口用 `viewArtifact`；写、批注、导出、交给 AI 用 `requireArtifact`（`artifacts/service.ts`）。改可见范围限创建人、Bot 主人、群管理员（`isArtifactManager`）。
- 左侧「作品」跨群汇总可打开的产物（`works.ts` `listWorks`/`workGroups`，web `features/works/`）；创作仍在群聊发起。

## daemon 与服务端同步

- `RunStart.artifacts`：触发消息引用的产物与 `artifact_checkout` 请求的产物一定下发，其余补本 Bot 的产物，最多 20 个（`RUN_ARTIFACTS_MAX`，`runArtifacts`）；只发给带 `artifacts` 能力的机器。
- `RunStart.artifactExclude` 列出群内全部产物目录，强制同步扫描跳过它们（`crates/gonggong/src/sync.rs`、`replicas.rs` `set_exclude`）。
- 开跑前：本地有未上传改动（离线、上次失败、手改）先以 `source=local` 上传；上传失败则本轮不检出该产物、目录原样保留（`crates/gonggong/src/artifacts.rs`）。
- 检出：digest 不同才拉清单和缺失 blob，先下载到 `.gg-checkout-*` 暂存目录再原子落盘；状态存 `<home>/artifacts/<id>/<folder>/state.json`，不放在工作区。
- 跑完：扫描、提交（带 `submitKey`），并按清单逐屏截图，入口屏截图兼作缩略图；上传失败不阻塞，下一轮开跑前用同一幂等键重试。
- daemon 路由只认本轮下发的产物（`runs.artifacts`）：`/api/daemon/runs/:runId/artifacts/:id/{blobs,versions}`；GET blob 只能取该产物版本引用的哈希（`routes.ts` `requireRunArtifact`/`referenced`）。
- 提交在 `submitVersion` 里锁产物行：父版本是 head → 成为新 head；同一 `submitKey` 重试 → 返回已有版本。
- 父版本是旧版本：按文件三方合并（`mergeFiles`）。run/local 的上传先留下 Bot 原稿作 stale 候选，合并结果另存为新 head。
- 不变量：返回给 daemon 的版本内容必须等于它本地的文件，否则下一轮会悄悄回退人工改动。
- 人工编辑（`onlyHead`）：不冲突就直接合并成 head；冲突返回 409「产物已有新版本」。
- AI 运行期间画布不锁：`ArtifactDto.running` 只表示有运行检出了它。
- 设为当前版本、采用候选、Undo/Redo 都走 `restoreVersion`：只移动 head，被采用的候选清掉 `stale`，不新建版本。
- 人工编辑或恢复版本后没有截图的，服务端发 `artifact.snapshot` 让 Bot 机器补拍；机器离线就等上线再拍（`snapshots.ts`）。没有截图时显示最近祖先版本的截图并标 stale。
- 旧 daemon（无 `artifacts` 能力）：创作指令回退为写 `design/<slug>/`、复制 kit 并用 `preview_static` 发布，不建产物。

## 渲染与桥接

- 产物预览是 `previews.kind='artifact'`：从服务端 blob 读，Bot 离线也能看；可以跟随 head，也可以固定到某个版本（`serve.ts`、`share.ts` `openArtifactPreview`）。
- L1 的 `/` 用插件**最新已审核版本**的外壳（`kit.ts` `currentShell`）；`_gg/*` 取产物自己插件版本的 kit；其余文件从版本 blob 读，并加 `nosniff`。
- 成员打开的屏幕 HTML 会被注入 `data-gg-id`（起始标签偏移，parse5 定位）和 `/__gg/bridge.js`（`html.ts` `injectBridge`），不改存储内容。
- 分享链接不注入桥接，访客访问 `/__gg/bridge.js` 返回 404。
- 桥接消息定义在 `BridgeToShell` / `BridgeFromShell`。主站只接受来自预览精确 origin、且 `source` 是对应屏幕 iframe 的消息（web `bridge.ts`）。
- 桥接消息只作界面提示；真正的修改都以 `(versionId, file, ggId)` 走服务端，由服务端重新定位和转义。
- 画布直接平铺各屏 iframe，不套外壳；外壳只用于新标签页、分享页和 Bot 本机截图。离开视口的屏换成截图（`Canvas.tsx` `nearView`）。

## 编辑器能力

- 工作台标签 `{kind:'artifact'}`（`app/workbench.ts`）→ `ArtifactTab`：画布（`Canvas.tsx`），以及原型预览/编辑（`PrototypeEditor.tsx`）。
- 画布节点：屏幕、设计系统、DESIGN.md、原型、参考文件；支持框选、右键菜单、⌘K、快捷键和屏间连线（`Links.tsx`）。
- 屏幕可以自由摆放，位置存在清单的 `x/y`（`screen-move`）。
- `POST /api/artifacts/:id/edits` 的 op：`text`、`attr`（`src/href/alt/data-gg-link/data-gg-transition`）、`style`（白名单 `STYLE_PROPS`）、`token`、`delete`、`asset`。
- 其余 op：`file`（整体替换 DESIGN.md / tokens.css）、`design-system`、`manifest`（rename/duplicate/delete/reorder）、`screen-move`、`ref*`。
- 一次保存最多 50 个 op，生成一版（source=edit）。同一文件内从后往前拼接，同一元素的 op 先合并，范围重叠的拒绝（`html.ts` `editHtml`）。
- 颜色只能取令牌（`styleValueOk` 对颜色属性只认 `var(--…)`）；改全局颜色走设计系统面板（`DesignSystemPanel.tsx`，预设来自插件 `designSystems`）。
- JS 生成或解析器自动补出的元素没有 `data-gg-id`，只能批注或交给 AI 修改。
- 交给 AI 都转成以当前用户身份发出的 @Bot 消息，正文给 agent 看、不翻译：批注发送、`ArtifactCommand` 指令、插件 `contributes.commands`、群输入框的画布上下文芯片 `ArtifactContext`（`commands.ts`、`ContextChips.tsx`）。
- 原型：外壳和编辑器都支持 `data-gg-link` 跳转与转场（`ArtifactTransition`）、连接/移除连接、扫码、新标签页；独立页的视图叫「总览 / 预览」。
- 热点默认关闭，点到非热点时闪现 0.8 秒。
- 导出（`export.ts`、`ExportPanel.tsx`）：zip（内嵌清单，双击 index.html 即可打开，不含未引用的 assets）、复制代码、实现提示词、项目简报（让 Bot 写 brief.md）、分享链接。
- 分享：只能由人在界面上开启，默认 7 天；可固定到某版本或跟随 head，可加 4 位密码（`share.ts`）。
- 规范校验 `lint.ts` 只提示不拦截，检查项：清单无效、屏文件缺失、写死色值、外部资源（含 img/srcset/url()）、改了外壳等。下一轮上下文最多附 20 条问题。
- 刻意不做：第三方导出（Figma、AI Studio 等）、Live 语音、Predictive Heatmap、六种配色方案自动推导、首页项目列表、.fig 导入、MCP/API（用实现提示词替代）、⌘S（修改即成版本）。
- 刻意不做：独立的 AI 输入框和 Agent 面板（复用群聊和运行卡片）、一个产物多个设计系统、版本对比。
- 产物内容约定（插件 SKILL.md 硬规则）：只用令牌；内容写成静态 HTML；不引入框架、CDN 和网络字体；图片下载到 `assets/`，不外链；顶层区块加 `data-section`；不改 `index.html` 和 `_gg/`。

## 关键约束

- 安全：路径越界、非法资源、转义失败、越权一律 400/403 硬拒绝；只有设计规范类问题放行。
- 安全：`text` 做 HTML 转义；`href` 只接受相对路径或 http(s)，`src` 只接受相对路径或 https；整份 tokens.css 用 `tokensCssOk` 校验。
- 安全：上传的图片校验魔数和结构，拒绝 SVG（`edits.ts`、`images.ts`）。
- 预览域与主站隔离；源码查看接口 `/api/artifacts/:id/files/*` 固定返回 `text/plain` 并带 `CSP: sandbox`。
- 兼容：daemon 消息变化要同步 fixture 和 `crates/gonggong/src/protocol.rs`；截图依赖 Bot 机器上的 Chrome 系浏览器（`artifactSnapshot` 能力）。
- 已知遗留：清单 `gg-artifact.json` 两边都改时整文件冲突，后续可改为按字段合并。

## 主要代码入口

- 契约：`packages/protocol/src/artifacts.ts`；`daemon.ts`（RunStart.artifacts/artifactExclude、`ArtifactSnapshot`）；`plugins.ts`（`PluginManifest.artifact`）。
- 服务端：`apps/server/src/modules/artifacts/`，含 service、routes、edits、html、lint、serve、kit、share、works、commands、annotations、export、snapshots、bridge.js。
- 服务端相关：创作入口 `apps/server/src/modules/plugins/creations.ts`；表定义 `apps/server/src/db/schema.ts`。
- daemon：`crates/gonggong/src/artifacts.rs`（检出、上传、截图、本机外壳服务 `serve_shell`）；`sync.rs`、`replicas.rs`（排除产物目录）。
- Web：`apps/web/src/features/artifacts/`（ArtifactTab、Canvas、PrototypeEditor、DesignSystemPanel、ElementPopover、AnnotationsPanel、ExportPanel、share、bridge.ts、store.ts）、`features/works/`。
- 插件：`apps/server/plugins/official/web-prototype/`（`gonggong-plugin.json`、`skills/web-prototype/SKILL.md`、`kit/`、`design-systems/`、`craft/`）。
