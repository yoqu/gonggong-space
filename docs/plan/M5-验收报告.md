## M5 E2E 场景（`e2e/m5-admin-ops.spec.ts`）
1. 停用账号：成员的 bot 在托管工作区写入文件 → 管理员在「账号与角色」停用该成员 → 成员的 Web 会话失效，跳回登录页 → daemon 被拒（revoked）后以非 0 退出，托管工作区和 token 被清除（/cd 目录与本机备份不动）→ bot 从所有群移除 → 审计中出现「停用账号 …」。
2. 群设置：修改群名和公告（顶部公告栏同步更新）→ 群级参数「接力链长上限」改为 1 → 置顶、免打扰 → 解散群后从侧边栏消失。
3. 运维（测试自带可启停的服务端）：运行中停掉服务器 8 秒后重启，daemon 退避重连，该轮最终在服务端「已完成」，最终回复入库 → 运行中重启 daemon，重连时 hello 对账把丢失的轮次标为「已中断 · daemon 重启」→ 旧协议的 hello 被拒绝（reason protocol）。

## 真实环境实测（切片内）
- 服务器宕机发生在 agent 回合中间：Claude 执行 30 秒的 Bash 命令期间停服 12 秒，daemon 按 1/2/4/8/16 秒退避重连，该轮 completed，过程和回复完整。
- 自动升级：用两个真实构建（0.1.0 和 0.2.0）测试。发布错误的 sha256 时拒绝升级，继续运行、不重试；发布正确的 sha256 时下载、校验、替换并以 exec 原地重启，重连后上报 0.2.0，只升级了一次。
- TLS：自签证书 + HTTPS/WSS，`aiws login` 首次信任并记录指纹，daemon 走 WSS 跑通真实 Claude 一轮；改掉配置里的指纹后 `aiws run` 和 `aiws bots` 都拒绝连接；`AIWS_INSECURE_DEV=1` 可显式关闭校验；用 http 连非本机地址被拒绝。有一条可选 E2E：`AIWS_E2E_TLS=1 pnpm exec playwright test -c e2e/tls.config.ts`。
- 静态加密：直接查数据库，确认运行过程和 patch 以 `v1:` 信封加密；附件在磁盘上加密，Web 端和 daemon 下载时透明解密。
- 停用账号：管理后台 UI + 真实 daemon + 真实 Claude 全链路验证。
- 响应式：所有页面（聊天、侧边栏、抽屉、对话框、8 个后台页面）在 1440 / 1000 / 390 宽度下截图，并用脚本检查元素是否溢出，修复 3 处。

## 已知限制（写入 P1 总验收）
- 网络延迟和带宽：P1 不测量，机器页显示「—」（测量属于 P2 开启强制同步的流程）。
- 提问卡片题数上限在 daemon 中固定为 4；备份保留天数、归档保留天数、写锁释放时长、网络阈值这些参数只存储不生效（多数属于 P2）。
- 协议没有应用层确认：TCP 恰好在写入时断开，单条消息仍可能丢失。run.done 已有断线缓存和补发，但写入这一瞬间的丢失没有兜住。
- 运行过程加密后，⌘K 不再搜索 agent 的流式输出和思考内容（最终回复和工具步骤仍可搜）。
- 基准分支镜像不做逐文件加密，依赖服务器磁盘加密（见 `docs/plan/安全说明.md`）。
- daemon 升级发布只有管理员接口，没有界面。
