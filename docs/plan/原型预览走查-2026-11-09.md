## 待办（中低优先级，按收益排序）

1. **「演示 / 预览 / 原型编辑器 / 画布·演示」四套叫法**（中，信息架构）：画布按钮叫「演示」，进去标题是「原型编辑器」，模式叫「预览 / 编辑」，新标签页又是「画布 / 演示」。方案：统一为「预览」——画布按钮「预览」，编辑器模式「预览 / 编辑」，独立页「总览 / 预览」，aria 标签同步。
2. **预览模式混入编辑入口**（中，用户流程）：预览模式下屏幕列表底部仍有「添加屏幕 / 构想新屏」，舞台下方有无文字的铅笔按钮（实为「用 AI 修改这屏」）。方案：这三个入口只在编辑模式显示；铅笔改为带文字的「AI 改这屏」胶囊。
3. **编辑模式「已连接」标签堆叠**（中，视觉层级）：每个热点上方一枚蓝底「已连接」，相邻热点标签互相压住（「营位电源」被盖成「营位…已连接」），整屏噪音大。方案：常态只描细边框，悬停或选中才显示标签，标签内容改为目标屏名（「→ 选营位和日期」）比「已连接」更有信息量。
4. **顶栏缺少位置感与回退**（中，用户流程）：预览中不知道当前在哪一屏、走了几步，也没有「返回上一屏 / 回到首屏」，只能靠屏内返回键或左侧列表。方案：顶栏中间显示「营地首页 · 1/4」，提供「返回」「重新开始」按钮，键盘 ← / Home 对应。
5. **分享弹窗说明叠三层、主按钮像禁用**（中，反馈机制）：「群成员都能查看和修改」「只有群成员能查看」「开启后，任何拿到链接的人…」三段说明；分享关闭时「复制链接」是浅蓝满宽按钮，像坏了。方案：开关右侧只留一句当前状态；关闭时主按钮改为「开启并复制链接」一步完成。
6. **扫码前置条件**（低）：扫码弹窗提示先开分享，点了跳回分享再回来。方案：弹窗内直接放开关，开启后原地出码。
7. **画布上的「原型」节点是黑块**（中，视觉）：缩略图只有一个小播放图标，认不出是什么。方案：用入口屏截图 + 居中播放按钮 + 「点击预览」标签。
8. **右侧工具栏只有图标**（低，组件一致性）：设备、重新加载、高亮热点、扫码、新标签页五个图标无文字，设备图标不显示当前尺寸。方案：设备按钮显示「375」短标签；悬停提示带快捷键。
9. **屏幕列表缩略图是活 iframe**（低，性能）：每屏一个完整 iframe（7 屏即 8 个页面同时加载图片）。方案：复用服务端屏幕截图，仅当前屏用 iframe。
10. **独立预览页「返回」常驻置灰**（低）：首屏时「返回」灰色占位，和屏幕切换胶囊并列不易理解。方案：首屏隐藏，入栈后出现。

11. **手机端引导条与「原型中的屏幕」药丸重叠、右侧工具栏压住设备边缘**（中，修复后复查发现）：390 宽下提示条被截断。方案：窄屏提示条换行放药丸下方；工具栏改为底部横排。
12. **横滑卡片里的热点没被识别**（中）：首页「选一种过夜方式」横滑卡片带 `data-gg-link`，热点闪现时没有框出来（横向滚动容器内的元素没上报矩形）。方案：bridge 上报热点时包含溢出滚动容器内的可见部分。
