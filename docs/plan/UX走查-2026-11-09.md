# UX 全量走查（2026-11-09）

范围：web 全部一级页面（消息/群/Bot/机器/作品/市场/话题/未读/稍后/404/登录）、管理后台 14 页、关键交互（⌘K、新建群、@、/、成员、群设置、工作台、话题、通知、右键菜单），桌面 1440 明/暗 + 390 手机。数据为真实库副本 `gonggong_audit`。

## 待办（中低优先级，按收益排序）

1. **侧栏里的「已删除的 Bot」私信**（中）：同名多条、灰色「已删」头像散落在各分区，占位又无用。方案：已删 Bot 的私信显示原名 + 「已删除」标签，自动沉到「私信」末尾；右键补「从侧栏移除」。
2. **@ 提及按名字最长匹配，Bot 删除后误高亮成人**（中）：「@系统管理员的 Claude Code」被渲染成提及用户「系统管理员」。方案：按 `meta.mentions` 的 id 渲染，目标已删时显示灰色纯文本。
3. **输入框常驻提示「未 @ 的消息不会触发 Bot…」**（中）：每个群永远显示，和输入内容抢注意力。方案：仅在群里有 Bot、草稿非空且不含 @ 时显示；或首次展示后可关闭。
4. **作废运行卡文案重复**（中）：「已作废 / Bot 离线超过 30 分钟，已作废并通知 系统管理员」。方案：标题「已作废」，正文「Bot 离线超过 30 分钟，已通知系统管理员」，并提供「重新发送」。
5. **市场筛选过重**（中）：顶部 4 段标签 + 类型 + 来源 + 排序 + 搜索，手机上占 4 行才见内容。方案：类型/来源合并为一个筛选弹层；「引入申请/我的发布/待审核」收进「管理」下拉，无权限者不显示。
6. **管理后台手机表格**（中）：列被横向裁掉（状态、机器看不到），「新建账号…」按钮被截断。方案：窄屏改卡片列表，主操作保留图标 + 短文案。
7. **离线机器无下一步**（低）：卡片只写「最后在线 31 天前」。方案：离线卡片给「如何重新连接」（复制 `gg` 启动命令）。
8. **会话统计小样本下的 ↓100%**（低）：0 对比前期少量数据显示 ↓100%，制造恐慌。方案：基数过小时显示「—」或中性色。
9. **404 页脱离应用外壳**（低）：没有左侧栏，用户失去位置感。方案：在 AppShell 内渲染。
10. **群头部图标簇**（低）：成员/话题/工作台/设置全是图标，新用户分不清话题和工作台。方案：确认 tooltip 带名称与快捷键，激活态加文字。
11. **直达 /works 时左栏无高亮**（低）：作品入口按条件显示，URL 直达时没有任何选中项。方案：直达时也显示并高亮入口。

## 未判为缺陷
登录页演示卡动画初始空白、后台彩色图标、顶栏玻璃胶囊、粘性日期胶囊压住作者行（与 Slack 一致）、草稿跨会话保留。
