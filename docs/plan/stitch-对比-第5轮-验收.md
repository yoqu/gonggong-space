## 4. 剩余问题

### P1（2 项）

- **P1-N1 原型编辑模式下，靠近设备底部的元素点开后，编辑浮层被设备裁掉看不见**（新发现）
  - 证据：`light-r-new-tabbar-pop`。点标签栏「我的」后，浮层位于 y=829、高 180，几乎全部落在设备外框以下，被裁掉。`light-r-g19-pop-event-card` 中，卡片下方元素的浮层只露出 3 项，「构想新屏」被裁掉。标签栏是最常需要连线的元素，这个问题直接挡住了给它连线。
  - 原因：浮层 `.proto-pop` 渲染在 `.proto-clip` / `.proto-scroll` 的 `overflow:hidden` 里面。第 4 轮之前 `.proto-scroll` 就已经裁剪，所以这不是回归。
  - 改法：把浮层 portal 到舞台层（`proto-stage`）或 body；空间不够时翻到元素上方。
