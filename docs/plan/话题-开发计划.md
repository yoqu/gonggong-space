# 话题（Thread）开发计划

对标 Slack 话题：任意消息可以展开成话题，回复不刷主频道。组件层已有 `ThreadPanel`（含「同时发送到群」）、消息菜单「回复话题」，本计划把它们接上业务，并让 Bot 在话题里有独立会话。

## 已定决策（姜维川 2026-11-08）

| 问题 | 决定 |
|---|---|
| 话题里 @Bot 用哪个会话 | 话题独立会话：上下文只有根消息和话题内回复，不打断群主会话 |
| 主频道 @Bot 的回复放哪里 | 群设置可选「Bot 回复进话题」，默认关闭（关闭时与现状一致） |
| 飞书同步 | 首期不映射飞书话题：共工的话题回复以「引用根消息」的形式同步到飞书群；飞书来的消息一律进主频道 |
| 话题收件箱 | 首期做：侧栏「话题」入口，汇总我关注的话题和未读回复 |

## 规则

- 只有一层：话题回复不能再开话题；群事件（`kind = 'event'`）不能作为根。根消息撤回或删除后话题保留且仍可打开，根显示「已撤回」/「你已删除这条消息」。
- 主时间线只显示 `thread_root_id is null` 或勾了「同时发送到群」（`meta.alsoSent`）的消息。
- 群未读（`group_members.last_read_seq`）不计话题回复（`alsoSent` 除外）；话题未读单独记在 `thread_follows`。话题里 @我、或 Bot 在话题里回复我触发的任务，照常发通知（点开直达话题），计入侧栏「话题」的数字，不计入群的「@」提示；读群不会结清话题里的 @，读话题才会。
- 自动关注：话题有第一条回复时根消息作者开始关注（取消过的不再自动关注）；在话题里回复的人、被 @ 的人（重新）关注。可手动「关注 / 取消关注」；取消后重新关注，之前的回复算已读。
- 引用、反应、置顶、编辑、撤回、隐藏在话题内照常可用。

## Bot 在话题

- 话题里 @Bot：`runs.thread_root_id = 根消息 id`，恢复 `thread_sessions(root, bot).session_id`；上下文为根消息 + 话题内 `seq > thread_sessions.context_seq` 的回复（第一次进话题时取根消息和全部回复，按 `contextInlineTokens` 截断），不推进 `group_bots.context_seq`，也不改 `group_bots.session_id`。daemon 按 `resumeSessionId` 加载会话，**协议和 Rust 不改**。
- `/new` 只影响所在位置：话题里发 `/new` 清空该话题的会话；主频道发则清空群会话。
- 回复落点：Bot 的回复消息和接力运行（`parentRunId`）继承 `run.thread_root_id`。
- 「Bot 回复进话题」打开时：主频道 @Bot 的这一轮仍用群会话和群上下文（保持连续），只是回复写进以触发消息为根的话题；之后在这个话题里继续 @，就走话题会话。
- 同一 Bot 在同一工作区串行，沿用调度器的「该 Bot 忙，排第 N」。
- 运行卡片显示在话题面板里；根消息的回复条显示「Bot 回复中」；任务栏里话题运行带「话题」标记，点一下回到话题。
- 定时任务（`scheduleOf`）不变。
- 给 agent 的提示：run.start 系统提示加一句「你正在话题中回复，根消息是…」；`list_messages` 工具加 `thread` 参数（读话题内消息），默认仍读主频道。

## 数据（一次迁移）

- `messages.thread_root_id`：可空，引用 `messages.id`；索引 `(thread_root_id, seq) where thread_root_id is not null`。
- `runs.thread_root_id`：可空。
- `thread_sessions`：`root_message_id, bot_id, session_id, context_seq, new_session_reason, updated_at`，主键 `(root_message_id, bot_id)`。
- `thread_follows`：`root_message_id, user_id, group_id, last_read_seq, following, created_at`，主键 `(root_message_id, user_id)`；索引 `(user_id, following)`。
- `meta.alsoSent`、群参数 `botRepliesInThread` 放在现有 jsonb 里，不加列。
- 根消息的回复摘要（回复数、最后回复时间、最多 3 个参与者）在分页加载时按当页的根消息聚合，不做冗余表。

## 接口

协议先改 `packages/protocol`：`MessageDto.threadRootId`、`MessageDto.thread?: { replyCount, lastReplyAt, participants: { kind, id }[] }`（只出现在根消息上）、`RunDto.threadRootId`、`ThreadInboxItemDto`；实时事件 `thread.updated { groupId, rootId, summary }`、`thread.read`。

| 接口 | 说明 |
|---|---|
| `POST /api/groups/:id/messages { threadRootId?, alsoSent? }` | 发消息时带上话题；校验根消息属于本群、不是回复、也不是事件；同一事务里写自动关注 |
| `GET /api/groups/:id/messages` | 主时间线过滤话题回复；根消息带 `thread` 摘要 |
| `GET /api/messages/:rootId/thread?before=` | 话题内回复，分页 |
| `PUT /api/messages/:rootId/thread/read { seq }` | 标记已读 |
| `PUT /api/messages/:rootId/thread/follow { following }` | 关注 / 取消关注 |
| `GET /api/threads?cursor=` | 收件箱：我关注的话题，按最后回复时间倒序，每条带根消息、最近 2 条回复和未读数 |
| `GET /api/threads/unread` | 侧栏用：有未读的话题数、其中 @我 的数量 |

搜索结果包含话题回复，点击后打开所在话题。

## 前端

- **根消息回复条**：最多 3 个参与者头像 +「N 条回复」+「最后回复 X 分钟前」；有 Bot 在运行时显示状态点；有未读时文字加粗。点击后右侧打开 `ThreadPanel`。
- **话题面板**：根消息 + 回复 + 运行卡片 + 输入框（支持 @ 和「同时发送到群」）；标题栏放「关注 / 取消关注」；深链 `/g/:id?thread=<rootId>`。
- **入口**：消息悬停菜单和右键的「回复话题」接上；主频道里 `alsoSent` 的消息带一行小字「回复了话题：<根消息摘要>」。
- **侧栏「话题」**：放在星标上方。有未读时加粗，只有话题里 @我 时才显示数字。
- **收件箱页** `/threads`：每个话题一张卡片（所在群、根消息、最近 2 条回复，不含群事件），卡片内「回复」直接展开话题输入框；点卡片主体进入话题，进入后标为已读。
- **群设置 › Bot**：开关「Bot 回复进话题」。
- desktop 复用 web 组件，一起验证。

## 分步与验收

每步 TDD：服务端集成测试 → web 组件测试，最后补 e2e。

1. **数据与消息**（含迁移、协议）：发话题回复；主时间线过滤；根消息摘要；话题分页；同时发送到群。
   - 测试：不能回复「回复」或事件；不能跨群挂根；主时间线不出现话题回复；群未读不计话题回复；话题里 @ 照常计入「@」提示。
2. **话题面板 UI**：回复条、面板、深链、悬停入口、`alsoSent` 显示。
3. **Bot 话题会话**：`thread_sessions`、`runs.thread_root_id`、上下文范围、回复落点、接力继承、话题内 `/new`、「Bot 回复进话题」开关。
   - 测试：话题运行不推进群 `context_seq`、不改群 `session_id`；第二次进话题能续上话题会话；开关打开时回复落进话题，且这一轮仍用群会话。
4. **关注、未读与收件箱**：自动关注规则、已读、侧栏入口、收件箱页、实时 `thread.updated`。
5. **周边**：飞书出站时引用根消息；搜索跳到话题；`list_messages` 加 `thread` 参数。
6. **e2e**：A 在群里发消息 → B 回复话题并 @Bot → Bot 在话题里回答，主频道不出现 → A 的侧栏「话题」加粗 → A 打开收件箱看到回复。

涉及数据库迁移，推送前需确认。

## 优化迭代（2026-11-08，五轮）

- **右侧栏**：话题、群话题列表与工作台并排停靠，不再遮挡工作台；空间不足时先折叠会话列表，再占用聊天栏；右侧栏换位置不重挂载。手机（<768px）全屏覆盖，关闭或返回后回到聊天。
- **任务栏与运行**：话题里的待处理卡片（审批、提问）也进任务栏并可定位闪烁；话题里 @Bot 被拒的提示落在话题里；话题内流式文字不重复，关面板不丢。
- **群话题列表**：群头部「话题」按钮，列出本群话题，Bot 回复中的置顶，带未读与 @ 标记；从列表进入的话题，头部可返回列表。
- **Bot 回复我 = @我**：Bot 在话题里回复我触发的任务，按「被 @」处理：发通知、计入侧栏「话题」数字。话题回复另推给通知「全部」档的关注者（同时发送到群的按主频道规则）。
- **根消息撤回/删除**：根撤回或删除后，回复条与话题仍在，仍可进入话题；列表、计数、置顶、搜索各处一致。
- **深链**：`/g/:id?thread=<rootId>&msg=<replyId>` 打开话题并定位到具体回复，置顶、通知、搜索、稍后处理都用它；回复不在话题里时给出提示。
- **回复条未读**：回复条显示我的新回复数，有 @我 时加「@我」。
- **输入归属**：话题内的引用、@（用户名片、Bot 名片）、撤回后「重新编辑」都进话题输入框，主频道的不串进话题。
- **关注**：取消后重新关注，期间的回复算已读，只有之后的回复算未读。
