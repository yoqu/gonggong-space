## E2E 场景
1. 首次启动：初始管理员强制改密 → 新建成员 → 成员首次登录改密 → 生成绑定码 → `aiws login` 绑定 → 新建 bot，直接绑定到本机 → 建私聊 → @bot → 卡片从「运行中」变为「已完成」→ 显示最终回复 → 托管目录 `workspaces/<群>/<bot>/_empty/hello.txt` 真实生成。
2. bot 离线时被 @：卡片显示「离线等待」→ daemon 上线后自动执行 → 重启 daemon 后下一轮恢复原会话（仍记得上一轮的暗号）。
3. 管理员为他人创建的 bot 在主人确认前被 @：显示「无权触发」。
4. 骨架连通性检查。

## 切片内已验证的边缘场景（摘要）
- 身份：密码错误、账号停用、登录失败节流；强制改密会拦截其他接口，改密后其他会话失效；绑定码格式错误 / 过期 / 重复使用 / 同一个码失败 5 次锁定 / 同一 IP 失败 10 次锁定；机器被吊销后 daemon 被断开（4003），重连被拒绝。
- bot：成员为他人创建（拒绝）、选用他人的机器、机器已吊销、重名、full 档位强制使用指定名单、非主人确认（拒绝）、待绑定的 bot 在首台机器绑定后自动绑定、机器上下线时 bot 状态实时更新。
- 群聊：用他人的 bot 建私聊（拒绝）、非成员访问、双击或重试时消息只存一条（advisory lock + clientId）、带空格的 bot 名、超长消息、两个浏览器之间未读数实时同步、手机宽度下的布局。
- 运行：并发满时排队并按顺序出队、离线等待、重复收到 run.done 时幂等、agent 崩溃（假 agent）、取消后在同一会话继续（真实 Claude 和 Codex 均实测）。
- **集成阶段修复**：agent 结构化错误（实测本机 Codex 模型配置无效）原先显示为「已完成」，现为「已中断 · agent 异常：<原因>」；新会话原因之前显示了内部值 `first`。
