# 本机 daemon 空间管理 — 开发计划

姜维川 2026-11-03 定范围：工作区克隆 + 孤儿状态；缓存处理只做 `git gc --prune`；孤儿与旧版本缓存自动清，工作区/备份只提醒不自动删；入口为 Web 机器弹窗「空间」Tab。

## 现状
- 根目录 `~/.gonggong`（`GONGGONG_HOME`）。克隆按 `(groupId, botId, repoId)` 各一份完整 clone，无共享 mirror。
- 只有 `workspaces.list` / `workspace.delete`（特性 `machineAdmin`），需手动删；删群/Bot 不通知 daemon。
- 无回收：`skill-sets/<g>-<b>`、`plugin-links/<g>-<b>.json`、`artifacts/<id>/<sha>`、`sync/<g>/<b>`、`plugin-sets` 旧 digest、`runtime/node-v*` 旧版本、`bin/gg-cast-*` 旧版本。
- `workspace.delete` 只看服务端 `running`，不查 daemon 内存占用（`Workspaces.dirs`）、托管服务、终端、预览、强制同步副本。

## 方案
### 1. 工作区列表增强（protocol `MachineWorkspace` 加可空字段，老 daemon 兼容）
- `lastUsedAt`：turn 占用目录时 touch `workspaces/<g>/<b>/.<leaf>.used`（在工作区旁边，git 与 agent 都看不到）；没有记录为 null。
- `changes: { uncommitted, unpushed } | null`：`git status --porcelain` 计数 + `rev-list --count HEAD --not --remotes`（不依赖上游）。
- `WorkspacesResult` 加 `disk: { free, total } | null`。
- Web 按群 → Bot 聚合，列：仓库、大小、最后使用、改动、状态；表头显示合计与磁盘剩余。
- 提醒：`removed/unused` 或 30 天未用的工作区在 Tab 标「可释放 N GB」，不自动删。

### 2. 清理操作（新特性 `storageAdmin`，无则隐藏新按钮）
- 删除：支持多选（客户端循环调 `workspace.delete`）。有未提交/未推送改动时弹二次确认并列出。
- daemon 删除前加固：对克隆目录取独占 `hold`，有 turn 或手动 Git 操作即拒绝（删除期间新 turn 排队）；先停根目录在其中的托管服务（预览随服务关闭）。已删 pair 的强制同步状态由 janitor 清。沿用三层托管路径 + 非符号链接约束。
- 瘦身：新消息 `workspace.gc {path}` → `workspace.gc.result {before, after, error}`，持目录占用执行 `git gc --prune=now`，运行中拒绝。
- 服务端 `admin.ts` 加 `POST /api/machines/:id/workspaces/gc` 转发，无表改动、无迁移。

### 3. 自动清理（daemon janitor，启动时 + 每 24h）
- 拉 `/api/daemon/workspaces` 得活跃 pair；**拉取失败则跳过本轮**（不能把空列表当全部孤儿）。
- 孤儿：不在活跃 pair 中、且超过 1 天没动的 `skill-sets`、`plugin-links`、`sync/<g>/<b>`（防刚加入的 pair 被误删）。`artifacts/<id>/<sha>` 只存目录哈希、无法反查目录，且体积很小，不清。
- 旧版本缓存：30 天没有 turn 用过的 `plugin-sets` 版本（每次安装 touch `.<name>-<digest>.used`）；非 `current` 且无进程在跑的 `runtime/node-v*`；除最新外无进程在跑的 `bin/gg-cast-*`。没有 `current` 时一个 Node 都不删。
- 不碰：工作区、`backups`、`/cd` 目录、`~/.claude`/`~/.codex`。清理结果写 daemon 日志。
