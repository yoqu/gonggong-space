# 动效回归记录

每晚动效回归（定时任务）的统一 token、规则与每轮记录。只做动效/过渡，不改业务逻辑与文案。

## 统一动效 token（现行，源头：`apps/web/src/styles/motion.css`、`apps/web/src/lib/motion.ts`）

| 用途 | CSS token | JS（motion/react） | 说明 |
|---|---|---|---|
| 位移/缩放进出场（默认） | `--spring-snappy` 308ms | `TRANSITION.snappy` | 零回弹弹簧；面板切换、卡片入场位移 |
| 较大位移（面板、列表卡片、抽屉） | `--spring-smooth` 379ms | `TRANSITION.smooth` | 零回弹 |
| 跟手/按压/小位移 | `--spring-interactive` 213ms | `TRANSITION.interactive` | 按下缩放（`scale` 属性）、拖动松手归位 |
| 有意回弹（开关圆钮、勾、按钮图标换形） | `--spring-bouncy` 369ms | — | 只用于小元素的「完成」反馈，数据图表禁用 |
| 出现淡入 | `--fade-in` 150ms ease-out | `TRANSITION.fadeIn` | 进场 opacity |
| 消失淡出 | `--fade-out` 110ms ease-out | `TRANSITION.fadeOut` | 出场比进场快 |
| 悬停/按下底色、颜色切换 | `--fade-fast` 90ms ease-out | `TRANSITION.fadeFast` | 高频操作最快 |
| 数据形变（柱、进度、数字） | `--motion-data` 240ms `--ease-standard` | `TRANSITION.data` | 零过冲 |
| 列表入场错峰 | `--stagger-step` 20ms，最多 6 项 | `STAGGER` | 总延迟 ≤120ms |
| 一次性：高亮闪/抖动/描线 | `--flash` 1.4s、`--shake` 360ms、`--draw` 320ms | — | |
| 循环：呼吸/在线环 | `--pulse` 1.6s、`--live-ring` 1.8s | — | reduced-motion 下在使用处停掉 |
| 按压缩放量 | `--press-button` .97、`--press-card` .98、`--press-icon` .92 | — | `transition: scale var(--spring-interactive)` |

共用关键帧与类（`apps/web/src/ui/motion.css`）：`ui-fade-in` / `ui-fade-out`、`ui-enter`（读 `--enter-x/y/scale`）、`ui-exit`（读 `--exit-x/y/scale`）、`.ui-panel-swap`（视图/标签页切换）、`.ui-leaving`（列表行离开，配 `useLeaving`）、`.ui-shimmer`（进行中文字流光）、`ui-live-ring`。挂载/卸载用 `usePresence` / `<Presence>`（`data-state=open|closed`，出场跑完再卸载）。

### 规则

- **进出场**：进场 = `ui-fade-in var(--fade-in)` + `ui-enter var(--spring-*)`（位移 4–8px 或 scale .96–.98，从触发源方向来）；出场 = `--fade-out`，位移更小、不回弹，`forwards` 防闪。
- **同类同节奏**：悬停/按下底色一律 `--fade-fast`；按压一律 `scale` + `--spring-interactive`；卡片列表入场一律 smooth + 6px。
- **只动 transform/opacity（及颜色）**：不 transition `width/height/top/left/margin/padding`；需要变宽高的用 FLIP（如 `Button` 的 `useWidthMorph`）。
- **reduced-motion**：弹簧与位移 token 归零（`base.css`），opacity/颜色淡入保留；循环动画在使用处停掉或放慢到 3s；一次性 token 留 1ms 保证 `animationend` 触发。
- **高对比**：流光等装饰在 `hc-*` 主题与 `prefers-contrast: more` 下去掉。
- 硬编码时长只允许出现在循环/装饰动画（转圈、骨架流光、吉祥物），其余必须走 token。
