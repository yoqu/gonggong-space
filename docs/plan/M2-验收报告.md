## 切片内已验证的边缘场景（摘要）
- 仓库校验：地址格式错误 / 分支不存在 / 无法访问 / 通过，四种状态；校验超时为 15 秒，不弹交互式凭据提示。
- 工作区：daemon 离线时建群，上线后只 clone 一次，重连不会重复发事件；更换仓库会重建工作区（新目录），旧目录保留；不同群的工作区互相隔离；clone 先写到 `.partial` 再原子改名；托管工作区统一 `core.autocrlf=false`；工作区未就绪时 run 显示「工作区准备中」并排队。
- git 默认动作：工作树干净时快进；有未提交改动或本地领先时不快进，并把原因告诉 agent；无上游分支、detached HEAD、fetch 失败都不会导致本轮失败；统计改动文件数时计入 untracked 文件，排除 `.gonggong/`，也计入本轮内的 commit；本轮开始前已存在的未提交文件不计入。
- 命令：路径带空格、相对路径（拒绝）、`--reset`、bot 离线、非 bot 主人使用 /cd、不带 @ 的 `/new`、大小写不符的 `/New`（当普通消息处理）、`/hold` 和 `/release` 在分区群中给出提示。
- 集成期修复：同一「群 × bot」同时只运行一轮（spec §8.9）；daemon 只在会话 id 与服务端一致时才复用进程内的会话；presence 测试原来靠固定等待时间，改为按条件等待，消除不稳定；`pg.sh` 在 worktree 里复用主仓库的数据库集群。
