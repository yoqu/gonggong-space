# 原型编辑器 · 墨刀化改版方案（一期已做，二三期待定）

> 2026-11-26，蒋庆提：按墨刀的界面布局和交互升级画布；现有功能全部保留，按墨刀的位置重新安排，墨刀有而我们没有的补上。参照墨刀原型 V9（顶栏工具、左侧目录/素材、右侧属性面板、演示/总览/标注）。

## 前提：和墨刀的根本差别

墨刀的页面由「自由摆放的组件」组成（每个组件有 X/Y），我们的页面是 AI 写的 HTML（元素按流式排版，文字多了会把下面的内容往下推）。所以：

- 真相仍是 HTML 文件，所有人工修改继续走 `POST /api/artifacts/:id/edits`（按 `versionId + file + ggId` 定位，服务端转义），不引入第二套组件数据。
- 「插入元素」默认插到所选元素之后或之内（跟随排版）；墨刀式「拖到任意位置」只在「自由层」里做（待定，见决策 2）。
- 拖动元素改位置 = 在图层里改顺序（同级内移动），不是改坐标。

## 新增功能清单（按期）

### 一期：换布局（纯前端为主，不改数据）
1. 顶栏横排工具 + 左侧图标栏 + 固定右侧属性面板；元素气泡里的操作搬进右栏，选中后元素旁只留一个小工具条（AI 修改、批注、更多）。
2. 图层面板：桥接上报当前屏的元素树（只含有 `data-gg-id` 的元素，按 `data-section`/标签/文字取名），点选、悬停高亮双向联动；显示/隐藏（`style display:none` 编辑）、锁定（本地，只防误选）。
3. 右栏「样式」覆盖现有 `STYLE_PROPS`：尺寸、填充、边框、圆角、不透明度、文字、间距；颜色从令牌里选。
4. 右栏「事件」：现有的点击跳转 + 转场 + 屏内状态切换（`data-gg-link`/`data-gg-transition`/`data-gg-set`）。
5. 页面属性（未选元素时）：名称、设备、状态栏、屏内状态维度、规则摘要；画布属性：设计系统、背景。
6. 标尺、Alt 测距、一屏线（只读计算，不写文件）。
7. 拆分 `Canvas.tsx`（已 2362 行，超体积基线），新布局按区域拆文件。

### 二期：补编辑能力（服务端新 op + 协议）
1. `insert` op：在所选元素后/内插入基础组件（文字、矩形、按钮、图片、输入框、分割线、图标），服务端生成转义过的 HTML 片段，只用令牌。
2. `move` op：同级内改顺序（图层拖拽、↑↓）；复制/粘贴元素（跨屏）。
3. 样式扩展：阴影（预设档位）、字体样式（斜体/下划线）、显示/隐藏；`STYLE_PROPS` 与 `styleValueOk` 同步。
4. 事件补齐：返回上一页、打开链接、显示/隐藏元素、滚动到元素（gg-kit.js 增加 `data-gg-toggle`/`data-gg-scroll`，只增不改）。
5. 卡片批注 + 打点批注两种形态（现在只有打点式）。

### 三期：资源与交付
1. 组件库：内置基础/表单/导航组件（插件 kit 提供 HTML 片段）、「存为我的组件」（团队级资源）。
2. 母版：共用的头部/底栏一处改、所有页面同步（`masters/<id>.html` + 页面里引用，渲染时展开）。
3. 标注模式（演示里的第三种）：点元素看尺寸、间距、颜色令牌、CSS 代码，给开发用。
4. 页面标识（颜色/进度符号）。

### 刻意不做
钢笔/矢量、流程图与思维导图（已有白板）、变量与表达式、Axure/Figma 导入、图表组件、自由拖拽坐标（除非决策 2 选自由层）。

## 待确认
1. 颜色：继续只允许令牌，还是像墨刀一样可选任意颜色（规范检查提示但不拦）？建议：先选令牌，下方「自定义」可填任意色，规范检查照常提示。
2. 插入/拖动元素：跟随排版（推荐，AI 后续改起来不乱），还是加墨刀式自由层（绝对定位，AI 改版时容易错位）？
3. AI 对话的位置：左侧图标栏的一个标签（推荐，与墨刀「目录/素材」同级，底部输入框不变），还是右栏的一个标签？
4. 范围：先做一期上线看效果，还是一、二期一起做？

## 一期落地（2026-11-27）

蒋庆定：先做一期；**左侧（页面列表 + AI 对话）和底部输入框保持现状**，其余按墨刀布局分配。与上面草案的出入：

- 工具条原本在画布右侧竖排，改为画布上方横排顶栏：左边撤销/重做，中间工具与面板开关（设计系统、收藏、批注、显示角标），右边缩放、快捷键、属性面板开关。「直接编辑」「标记」仍是独立工具，没有合并。
- 右侧属性面板常驻（可收起，记在 `gg.art.inspector`），标签：属性 / 图层 / 批注 / 规则。属性随选中变化：直接编辑选中元素 → 元素样式与跳转（原 ElementPanel）；选中屏幕 → 页面属性（原 DetailsPanel）；都没选 → 画布属性（设备、设计系统、收藏、标尺/连线/角标开关）。原来浮在画布上的侧栏（设计系统、收藏、导出、共享规则）都停靠在这一栏里。
- 图层：桥接新增 `layers`（列出带 `data-gg-id` 的元素，按嵌套缩进，隐藏的标出）与 `pick`（像点击一样选中并滚到可见）；在非编辑工具下点图层会先切到直接编辑。显示/隐藏、锁定没有做（要新的编辑操作，放二期）。
- 标尺：画布上沿和左沿，单位为画布坐标，选中的屏幕在标尺上高亮（开关记在 `gg.art.rulers`）。Alt 测距、一屏线没有做：屏幕在画布上已按设备尺寸裁切，一屏线意义不大；测距要桥接上报两元素位置，留到二期和「标注」模式一起做。
- 顶栏「预览」改名「演示」。

## 一期优化（2026-11-27，蒋庆提）

- 右侧面板默认是「画布设置」：选中页面时可改名称、尺寸（手机/平板/桌面预设）、背景色（改 body 的内联样式）、看源码、管理热区；下面是画布级的设计系统、标尺/连线/角标、收藏。「查看详情」菜单仍打开原来的详情面板。
- 用「直接编辑」点中模块后，标签变为 外观 / 交互（共用一份草稿，一次保存）：
  - 外观：文字与图片、尺寸、间距、填充、边框（颜色/粗细/线型/圆角）、不透明度、阴影（三档预设）、文字（颜色/字号/字重/行高/字间距/对齐/斜体/下划线/删除线）。
  - 交互：点击跳转到页面 + 转场、链接地址、添加热区；动效等复杂交互提示用底部输入框交给 AI。
- 颜色（蒋庆定）：设计系统颜色优先，也可用取色器选任意颜色；服务端放行十六进制色值，规范检查照常提示「写死的色值」，不拦。
- 热区（蒋庆定为墨刀式热区）：新编辑操作 `hotspot`，在 body 末尾加一个透明的绝对定位 `<a data-gg-hotspot data-gg-link>`，坐标为文档坐标；之后按普通元素选中、改跳转或删除。页面若是内部滚动容器布局，热区位置可能偏，后续再处理。
- 协议：`STYLE_PROPS` 增加 box-shadow、font-style、text-decoration；样式校验从 `artifacts.ts` 拆到 `styles.ts`；`layers` 回报元素的跳转目标、热区标记和 body。
- 模块旁的小弹窗去掉（蒋庆定），操作按类收进右侧面板顶部：外观里是编辑文字（图片为输入地址/上传）、用 AI 修改、删除；交互里是构想新屏、添加规则。「连到屏幕」与交互里的「点击跳转到」合并，「属性」不再需要。标记工具的批注小弹窗保留。
- 外观/交互改完自动生效（蒋庆定）：输入框离开或回车、选择类控件停 0.5 秒后保存为新版本，撤销退回；不合法的值不保存。保存后新版本里按原 `data-gg-id` 重新选中同一模块，面板不跳走。
- 画布上方的浮动工具条（生成/修改/预览/更多）去掉，与顶栏、右侧合并同类项（蒋庆定，不简单全挪）：「修改」里的编辑、设计系统已在顶栏；尺寸、查看代码已在画布设置；导出在标签栏；重新加载即顶栏刷新。剩下的放进画布设置的「页面操作」：生成（含按维度出变体）与交给哪个 Bot、新标签页打开、二维码、全高、查看详情、下载、删除；多选时只显示能批量做的。右键菜单不变。
