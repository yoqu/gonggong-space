# v0.4.11

本次桌面端「Skill」页改为「市场」，补上搜索、详情与版本状态；服务端同步上线市场体验迭代与群内多工作区。

The desktop Skill page becomes the Market page, with search, details and version status; the server ships market usability improvements and multiple workspaces per Bot in a group.

## 桌面端 / Desktop

- 侧栏「Skill」改为「市场」，新增搜索与刷新；连不上服务器时给出提示，不再显示 HTTP 原文。
  The sidebar Skill page is renamed Market and adds search and refresh; a clear message replaces raw HTTP errors when the server is unreachable.
- 「我的 Skill」每行显示版本状态：跟随最新、锁定版本、有新版本、已下架、已封禁（附原因）；市场里已引入的条目标「已引入」。
  Each My Skills row shows its version status: following latest, pinned, update available, unlisted or banned with the reason; installed listings are marked in the market.
- 点任意条目可看只读详情，并在网页中直接打开该条目。
  Open any listing for read-only details, or jump straight to it in the web app.

## 服务端（已上线）/ Server (already deployed)

- 市场：已引入状态、条目链接、待审核页、新版本与封禁提示、同名冲突与重复申请预警、发布前预检、上游更新提醒，市场通知支持浏览器与飞书推送；聊天 `/` 候选显示「我的 Skill」。
  Market: installed status, listing links, a review queue, update and ban notices, early warnings for name conflicts and duplicate requests, pre-publish checks, upstream update hints, browser and Feishu push for market notices; My Skills appear in chat `/` suggestions.
- 群里一个 Bot 可同时使用多个仓库与自带目录，附加仓库可改用本机克隆，并显示各自的分支、领先/落后与未提交改动。
  A Bot can use several repositories and its own directories in a group; extra repositories can use a local clone and show their branch, ahead/behind counts and uncommitted changes.
- 拉 Bot 时按「我的 Bot / 其他成员的 Bot」分组排序；普通成员可只读查看群设置并填写自己的密钥。
  The Bot picker groups My Bots and other members' Bots; regular members can view group settings read-only and fill in their own secrets.

## 升级 / Upgrade

- 服务端已部署。daemon 本版无改动，可不升级；桌面端升级后即可使用新的市场页。
  The server is already deployed. The daemon is unchanged in this release; upgrade the desktop app to get the new Market page.
