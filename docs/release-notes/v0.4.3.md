# v0.4.3

本次修复工作区 clone 卡住后无法切换目录的问题，并补上网络停滞保护。

This release fixes workspace switching when a clone is stuck and protects against stalled network transfers.

## 工作区 / Workspaces

- 切换到本机目录或重新选择托管工作区时，立即取消同一 Bot 的旧 clone，不再等待它结束。
  Switching to a local directory or reselecting a managed workspace immediately cancels the Bot's previous clone instead of waiting for it to finish.
- 取消时会结束 Git 的 SSH/HTTPS 子进程并清理托管 `.partial` 目录。你的本机项目目录不会被删除，旧 clone 的迟到回包也不会覆盖新选择。
  Cancellation ends Git's SSH/HTTPS children and removes the managed `.partial` directory. Local project directories are not deleted, and late replies cannot replace the new selection.
- 修复 daemon 重连与新入群目录选择之间的竞态，避免自动 clone 打断确认过程。
  Fix a reconnect race that could let automatic cloning interrupt new workspace confirmation.

## 网络 / Network

- HTTP(S) Git 传输连续 30 秒低于每秒 1 字节时，结束 clone 并提示网络问题。大仓库正常下载仍不限制总时长。
  End a clone with a network error when its HTTP(S) transfer remains below one byte per second for 30 seconds. Large repositories still have no total download deadline.

## 升级 / Upgrade

- 本次需要服务端与桌面端配套升级。已卡死的旧客户端需更新并重启一次，之后才能取消它留下的旧进程。
  Deploy the server and upgrade the desktop app together. An old client with a stuck clone must be updated and restarted once before it can cancel the old process.
- 已安装 v0.2.0 及以上客户端可自动更新。
  Clients on v0.2.0 and later can update automatically.
