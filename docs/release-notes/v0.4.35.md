# v0.4.35

本次更新 daemon 与 macOS、Windows 桌面客户端。
This release updates the daemon and the macOS and Windows desktop apps.

- Codex Bot 在「工作区」和「帮我审批」模式下可以访问数仓等联网服务。文件沙箱不变，越界写入仍走原有审批；「只读」模式不变。
  Codex bots can reach network services in Workspace and Approve-for-me modes. Filesystem sandboxing and the approval flow for writes outside permitted paths are unchanged, as is Read-only mode.
- 修复多个 Bot 并发下载同一个附件时的临时文件冲突。
  Fixed temporary-file collisions when multiple bots download the same attachment.
- CodeBuddy 支持登录检测和授权引导；话题可按标题或内容搜索，可分栏查看，也能原地改名。
  CodeBuddy adds sign-in detection and authorization guidance. Search threads by title or content, view them side by side, and rename them inline.
- 作品按类型分区；原型编辑器支持就地编辑，重新组织了工具栏、图层和外观、交互属性。
  Works are grouped by type. The prototype editor adds inline editing and reorganizes its toolbar, layers, and appearance and interaction properties.
