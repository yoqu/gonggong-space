# v0.4.6

本次新增统一的机器管理与独立终端会话，改进会话列表、HTML 回复展示和目录选择。

This release adds unified machine management and standalone terminal sessions, with improvements to the conversation list, HTML replies and directory selection.

## 机器与终端 / Machines and terminals

- 最左侧新增「我的机器管理」，按机器分组查看 Bot、在线状态与运行位置，集中维护机器和 Bot 设置。
  Add machine management to the left rail, grouping Bots by machine with online status and execution locations in one place.
- 机器主人可在 macOS/Linux 机器的已有目录中创建独立终端会话，入口与群聊、私聊一同保留；可重连、重命名和删除。
  Machine owners can create standalone terminal sessions in existing macOS/Linux directories, keep their entries alongside chats, and reconnect, rename or delete them.
- 机器页新增工作区清理、daemon 日志和可升级版本提示；远程日志会先打码再发出。
  Machine pages add workspace cleanup, daemon logs and available-version notices; remote logs are redacted on the machine before transmission.

## 会话与内容 / Conversations and content

- 群聊和私聊合并为一个列表，置顶在前，其余按最后消息时间倒排；顶部「+」可根据所选成员创建群聊或私聊。
  Groups and direct chats share one list, pinned first and otherwise ordered by latest message; the top plus button creates the appropriate conversation from the selected members.
- HTML 页面可直接嵌入 Bot 的最终回复，页面中的图片可通过宿主查看器打开。
  HTML pages can appear directly in final Bot replies, with images opened in the host viewer.
- 群 Bot 的附加目录改为通过所在机器的目录选择器添加，支持去重和移除，不再手输路径。
  Add extra Bot directories through its machine's directory picker, with deduplication and removal instead of manual path entry.

## 升级 / Upgrade

- 请先部署最新服务端，再升级桌面端与 daemon；机器终端、远程工作区和日志需要配套的新版本 daemon。
  Deploy the latest server before upgrading desktop clients and daemons; machine terminals, remote workspaces and logs require the matching new daemon.
- 服务端包含数据库迁移 `0083`，部署时自动执行；已安装 v0.2.0 及以上客户端可自动更新。
  Server migration 0083 runs automatically during deployment; clients on v0.2.0 and later can update automatically.
