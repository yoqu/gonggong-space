# v0.4.5

本次改进任务执行与审批、终端重连和 Git 工作流，并压缩 Agent 的上下文占用。

This release improves task execution and approvals, terminal reconnection and Git workflows, while reducing agent context usage.

## 任务与审批 / Tasks and approvals

- 定时任务新增「立即执行」：停用状态也能手动触发，不改变启停设置或下次执行时间；上次运行未结束或候选 Bot 不可用时明确提示。
  Scheduled tasks add Run now: manually trigger even disabled tasks without changing their enabled state or next run time, with clear errors for unfinished runs or unavailable Bots.
- Web 与飞书审批卡新增「本次运行免审批」：Bot 主人可将当前运行临时切为完全访问，后续请求不再询问，运行结束自动恢复原档位。
  Web and Feishu approval cards add Allow for this run: the Bot owner can temporarily grant full access to the current run, skip further prompts and automatically restore the previous tier when it ends.

## 终端 / Terminal

- 修复大粘贴导致终端断流、刷新后无法重连的问题；断开只影响当前连接，重连可从保留的输出恢复。
  Fix large pastes breaking terminal streams and terminals failing to reconnect after refresh; disconnects affect only the current attachment, and reconnects resume from retained output.

## Agent 与创作 / Agent and creation

- 精简系统提示词与内置工具描述，减少每轮上下文占用；未绑定飞书或未启用创作插件的群不再向 Bot 列出相应工具。
  Trim the system prompt and built-in tool descriptions to reduce per-turn context; groups without a Feishu binding or creation plugins no longer list the corresponding tools to Bots.
- Agent 可见的消息与运行时间统一带 `UTC` 后缀，避免误当本地时间。
  Message and run timestamps visible to agents now carry a UTC suffix, avoiding confusion with local time.
- 新增 HTML 预览与渲染工具：网页截图与按宽度排版的页面可直接呈现到群聊。
  Add HTML preview and rendering tools: webpage screenshots and width-fitted pages can appear directly in chat.
- 子 Agent 进度显示在运行过程里；不带托管仓库的本地 Git 工作区也能识别状态。
  Sub-agent progress appears in run details, and Git status works in local workspaces without a managed repository.

## Git / Git

- 提交、日志、贮藏集中到同一 Git 面板，移除「记录」「控制台」并精简工具栏；待审批申请保留在面板顶部。
  Commit, log and stash now share one Git panel; Operations and Console are removed and the toolbar streamlined, while pending approvals stay at the top of the panel.
- 群聊顶部不再常驻「Git 失败」；改动统计更紧凑，点击可直接进入代码审查。
  Chat no longer keeps a persistent Git failed label; change counts are more compact and clickable for code review.
- 兼容 Git 2.56 的重命名历史追踪。
  Support rename history tracking with Git 2.56.

## 升级 / Upgrade

- 请先部署最新服务端，再升级桌面端与 daemon，以配套使用 `terminal-v2` 和按群配置裁剪工具列表；旧版本组合保持兼容，但无法使用新增能力。
  Deploy the latest server before upgrading desktop clients and daemons for terminal-v2 and group-specific tool lists. Mixed versions remain compatible but do not provide the new capabilities.
- 无数据库迁移；已安装 v0.2.0 及以上客户端可自动更新。
  No database migration; clients on v0.2.0 and later can update automatically.
