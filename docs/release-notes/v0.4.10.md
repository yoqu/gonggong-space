# v0.4.10

本次新增 Skill 市场与桌面端只读 Skill 页，并完善本机空间管理和目录选择。

This release adds the Skill market and a read-only desktop Skill page, along with local storage management and directory picker improvements.

## Skill 市场 / Skill market

- 支持上传文件夹、ZIP、粘贴 SKILL.md 或从 GitHub 导入 Skill；审核后可引入到个人、群、仓库或团队，并选择跟随最新或锁定版本。
  Upload a folder or ZIP, paste SKILL.md, or import from GitHub. After review, install Skills for yourself, a group, a repository or a team, following the latest version or pinning one.
- 个人 Skill 只在自己发起的运行里生效；成员可申请引入，审核时可查看版本差异，管理员可封禁危险条目。
  Personal Skills apply only to runs you start. Members can request installs, reviewers can inspect version differences, and administrators can ban unsafe listings.
- 桌面端新增只读「Skill」页，可查看个人 Skill 和市场，并跳转到网页进行操作。
  The desktop app adds a read-only Skill page for personal Skills and the market, with a link to the web app for management.

## 本机管理 / Local management

- 「空间」页按群和 Bot 展示工作区占用，支持多选删除和 Git 瘦身，并自动清理旧插件及运行时文件。
  The Storage page shows workspace usage by group and Bot, supports bulk deletion and Git slimming, and automatically cleans old plugins and runtime files.
- 目录选择器新增本机快捷位置、新建文件夹、排序、当前目录搜索和最近使用。
  The directory picker adds local shortcuts, folder creation, sorting, current-directory search and recent locations.
- 支持在服务器上用容器运行 daemon。
  Run the daemon in a container on a server.

## 升级 / Upgrade

- 请先部署最新服务端，再升级桌面端与 daemon。桌面端 Skill 页、空间管理和目录选择器的新能力需要 v0.4.10。
  Deploy the latest server before upgrading desktop clients and daemons. The desktop Skill page and the new storage and directory-picker capabilities require v0.4.10.
