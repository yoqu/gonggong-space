# v0.4.7

本次新增一群多仓库、托管产物画布与原型编辑，并改进运行过程和 Git 分支操作。

This release adds multi-repository groups, hosted artifact canvases and prototype editing, with improvements to run details and Git branch navigation.

## 多仓库 / Multiple repositories

- 群可保留一个主仓库并添加多个附加仓库，每个仓库可指定默认分支。daemon 将附加仓库克隆到主仓库旁，并作为附加目录交给 Bot。
  Groups can keep one primary repository and add extra repositories with individual default branches. The daemon clones extras beside the primary and exposes them to Bots as additional directories.
- Git 面板按仓库查看分支与改动，提交、拉取和推送按仓库执行；禁止直推基准分支按各仓库的默认分支判断。
  The Git panel shows branches and changes per repository; commits, pulls and pushes stay repository-scoped, and base-branch protection uses each repository's default branch.
- Claude 可加载附加仓库的 CLAUDE.md 和 Skill；Codex 会在系统提示中收到仓库位置并被要求先读取 AGENTS.md。强制同步群暂不支持附加仓库。
  Claude can load CLAUDE.md and Skills from extra repositories; Codex receives their locations and is instructed to read AGENTS.md first. Force-sync groups do not support extra repositories yet.

## 产物与原型 / Artifacts and prototypes

- 网页原型可保存为带版本的多屏产物，在画布中查看缩略图、撤销重做、批注、上传参考素材，并维护设计系统。
  Web prototypes can be saved as versioned multi-screen artifacts, with thumbnails, undo and redo, annotations, reference uploads and design-system editing on the canvas.
- 原型支持屏幕连接、转场与热点，可直接改字和元素属性，或把整屏、局部与批注交给 AI 修改；支持导出代码、项目简报和分享链接。
  Prototypes support links, transitions and hotspots, direct text and property edits, and AI edits for whole screens, selected elements or annotations, plus code export, project briefs and share links.
- daemon 在检出产物版本前上传本地改动，并在运行后提交产物版本与缩略图，避免本地工作被直接覆盖。
  The daemon uploads local changes before checking out artifact versions and submits new versions and thumbnails after runs, avoiding direct overwrites of local work.

## 会话与 Git / Conversations and Git

- 运行过程显示触发消息、打断追加消息和提问回答；已回答、超时或作废的提问卡片折叠为简要结果，可展开查看。
  Run details show trigger messages, interruptions and question answers; answered, timed-out or voided question cards collapse to concise results and can be expanded.
- 仓库切换并入 Git 分支弹窗；子仓库在弹窗旁空间足够时并排展开，便于连续查看。
  Repository switching moves into the Git branch popup, and subrepositories expand beside it when space allows for easier browsing.

## 升级 / Upgrade

- 请先部署最新服务端，再升级桌面端与 daemon。旧 daemon 会忽略附加仓库，多仓库和托管产物能力需要配套的新版本。
  Deploy the latest server before upgrading desktop clients and daemons. Older daemons ignore extra repositories; multi-repository and hosted artifact features require the matching new version.
- 服务端包含数据库迁移 `0084`–`0088`，部署时自动执行；已安装 v0.2.0 及以上客户端可自动更新。
  Server migrations 0084 through 0088 run automatically during deployment; clients on v0.2.0 and later can update automatically.
