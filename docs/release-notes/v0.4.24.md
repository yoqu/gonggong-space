# v0.4.24

本次同步更新 daemon 与桌面客户端。
This release updates both the daemon and desktop app.

## Agent 计划 / Agent plans

- 桌面端运行卡片与运行页展示 Agent 计划，并修复侧栏选中态的位置。
  The desktop app shows agent plans in run cards and run details, and fixes sidebar selection positioning.

- daemon 上报主 Agent 的 ACP 计划及后续更新，支持在运行中查看计划进展。
  The daemon reports the main agent's ACP plan and subsequent updates so progress can be viewed during a run.

## Agent 与审批 / Agents and approvals

- 修复 Antigravity CLI 的命令未被审批规则正确识别的问题，运行步骤中也会显示命令。
  Fix Antigravity CLI commands not being recognized by approval rules, and show the command in run steps.
- 并行探测 Agent 模型，探测完成后及时上报，不再等待其他较慢的 Agent。
  Probe agent models in parallel and report each result without waiting for slower agents.
- Antigravity CLI 的最低建议版本提升至 1.5.9；低于此版本时会提示，但不阻止运行。
  The recommended minimum Antigravity CLI version is now 1.5.9. Older versions show a warning but can still run.
