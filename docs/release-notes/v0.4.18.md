# v0.4.18

Bot 默认使用托管工作区，插件可扩展 MCP、命令与供应商，并可查看上下文构成。
Bots get managed workspaces by default, plugins can contribute MCP, commands and providers, and context usage gets a breakdown.

## 工作区 / Workspaces

- Bot 进会话默认使用共工托管工作区，没有默认目录时第一条 @ 也能执行；旧的「待绑定」Bot 被 @ 时自动改用托管目录。Bot 栏菜单新增「更换工作区…」。
  Bots use a Gonggong-managed workspace by default, so the first @ works even without a default directory. An @ to an older unbound Bot switches it to a managed directory. The Bot menu adds Change workspace.

## 插件 / Plugins

- 插件可带 MCP 服务、斜杠命令、画布指令和供应商预设。运行插件代码须开启系统开关「插件代码」，并由机器主人逐版本授权。
  Plugins can contribute MCP servers, slash commands, canvas commands and provider presets. Plugin code requires the Plugin code system switch and per-version approval by the machine owner.
- 插件上传改用路径白名单，daemon 清除插件目录中的 hooks、`.mcp.json`、commands 与 agents。
  Plugin uploads use a path allowlist, and the daemon removes hooks, `.mcp.json`, commands and agents from plugin directories.

## 运行 / Runs

- 运行详情新增「上下文」页签，显示上下文窗口用量、提示词缓存命中和构成估算。分项按文本长度估算，压缩或续接后无法拆分的早先内容会合并显示。
  Run details add a Context tab with window usage, prompt-cache hits and an estimated breakdown. Items are estimated from text length; earlier content that cannot be separated after compaction or resumption is grouped together.
- 内置 MCP 新增市场工具；`thread_create` 支持私聊。
  The built-in MCP adds market tools, and `thread_create` now supports direct chats.

## 修复 / Fixes

- 输入框 Ctrl/Cmd/Alt+Enter 改为换行；群聊输入框新增表情按钮，提供 8 类近 400 个表情。
  Ctrl/Cmd/Alt+Enter now inserts a newline in composers. Group chats add an emoji button with nearly 400 emoji in eight categories.
- 修复多个文件解决冲突时切换文件导致白屏，以及新用户上手流程中的三处断点。
  Fix blank screens when switching between conflicted files and three new-user onboarding dead ends.
