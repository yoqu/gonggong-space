# v0.4.33

本次更新 daemon 与 macOS、Windows 桌面客户端。
This release updates the daemon and the macOS and Windows desktop apps.

- 多个 Bot 共用工作区时，只读操作不会弹窗。要写入且已有其他轮次可能写入时，可以选择并行修改或等对方结束。
  Bots can read a shared workspace without interruption. If another run may also write, choose whether to proceed in parallel or wait for it to finish.
- 话题入口显示本群未读数；Bot 在话题中的附件、卡片和提示留在原话题。
  The Threads button shows the group's unread count. Bot attachments, cards, and prompts stay in their originating thread.
- 原型画布可直接选择执行的 AI，编辑范围限于选中的页面。
  Choose an AI directly in the prototype canvas. Edits are scoped to the selected screens.
- 飞书项目需求群可归入团队分区，并配置主仓库、Bot 和回复方式。
  Feishu Project work-item groups can be organized into team sections and configured with a primary repository, bots, and reply behavior.
- 下线微信小程序预览和桌面实时画面及远程控制。
  WeChat mini program previews, desktop live streaming, and remote control have been retired.

已知限制：Codex 在共享工作区拿到写权后，本轮沙箱模式不会立即切回。构建等写入命令仍需要 Codex 主动申请权限。
Known limitation: Codex's sandbox mode does not change immediately after a shared-workspace write is cleared. Commands that write files, such as builds, still depend on Codex requesting permission.
