# v0.4.26

本次同步更新 daemon 与 macOS、Windows 桌面客户端。
This release updates the daemon and the macOS and Windows desktop apps.

- 原型画布标出 AI 正在编辑的页面，编辑完成时播放过渡效果。新版 daemon 会上报本轮写入的文件。
  The prototype canvas highlights pages the AI is editing and plays a transition when editing finishes. The updated daemon reports files written during the run.
- 原型画布新增左侧固定栏，支持页面多级分类、拖拽移动、重命名与删除，也可回看命令及执行结果。
  The prototype canvas adds a fixed sidebar for nested page groups, drag-and-drop moves, renaming, deletion, and reviewing commands and their results.
- 网页显示 Antigravity 子 Agent 和后台任务，Antigravity 在 Bot 工作区中启动。
  The web app displays Antigravity subagents and background tasks, and Antigravity starts in the bot workspace.
- 补齐计划块、Antigravity MCP 卡片及 Codex 修改文件的路径；网页现在也显示 CodeBuddy 和 OpenCode 的工具调用。
  The web app improves plan blocks, Antigravity MCP cards, and Codex file paths, and now displays CodeBuddy and OpenCode tool calls.
- 群消息附件同步至飞书，统一手机端工作台与话题的层级，细化画布缩放步进。
  Group message attachments sync to Feishu, mobile workbench and thread navigation are more consistent, and canvas zoom has finer increments.
