# v0.4.9

本次完善 Claude Code 供应商设置，并精简 Bot 的工具与提示。

This release improves Claude Code provider settings and trims Bot tools and prompts.

## 供应商设置 / Provider settings

- 所有 Claude Code 供应商都可设置「命令行参数」，包括自定义、预设和本机配置目录；输入框已移到「其他环境变量」前面。
  All Claude Code providers, including custom, preset and local-config-directory providers, accept command-line arguments. The field now appears above the other environment variables.
- 参数校验和 `--settings` 合并规则与官方登录一致：daemon 读取文件或内联 JSON，合并进共工生成的设置，冲突时共工管理项优先。
  Argument validation and --settings merging match official login: the daemon reads the file or inline JSON and merges it into Gonggong-generated settings, with Gonggong-managed values taking precedence.
- 本机 Claude 配置目录可点「浏览…」选择，支持隐藏目录。
  Pick the local Claude config directory with Browse…, including hidden directories.

## Bot 工具 / Bot tools

- 按发起人身份精简管理类工具，减少无关工具与提示；新增飞书卡片内置 Skill，团队同名 Skill 优先。
  Management tools are trimmed by the requester's role to reduce irrelevant tools and prompts. A built-in Feishu card Skill is included, with a team Skill of the same name taking precedence.

## 升级 / Upgrade

- 请先部署最新服务端，再升级桌面端与 daemon。供应商命令行参数需要新版 daemon，旧 daemon 保存相关设置时会提示升级。
  Deploy the latest server before upgrading desktop clients and daemons. Provider command-line arguments require the new daemon; older daemons will ask for an upgrade when saving these settings.
