# v0.4.21

新增 Antigravity CLI Agent，MCP 授权卡片显示工具自带的说明。
Adds the Antigravity CLI agent, and MCP approval cards show each tool's own description.

## Agent

- 新增内置 Agent 插件 Antigravity CLI（`agy`，需 1.5.0 及以上），经 `agy acp` 原生接入；用机器上自己登录的 Google 账号，共工不托管安装，在机器上按官方命令安装并运行 `agy` 登录。
  Adds the built-in Antigravity CLI agent plugin (`agy` 1.5.0 or later) over its native `agy acp`. It uses the Google account signed in on the machine; Gonggong doesn't install it, so install it with the official command and run `agy` to sign in.

## 审批 / Approvals

- MCP 授权卡片显示工具声明的标题、说明与风险标注，参数完整列出；未声明风险的工具标「工具未声明风险」。
  MCP approval cards show the tool's declared title, description and risk annotations, with every argument listed; tools that declare no risk are marked as such.

## 网页端 / Web（已随服务端上线 / already live）

- 飞书易用性改版：用词统一、接入后的「还差几步」清单、群设置 · 飞书重排、Bot 设置新增「飞书」页、进群卡片可关联已有群、管理后台飞书页加接入进度与总览。
  Feishu usability overhaul: consistent wording, a what's-left checklist after connecting, a reorganized Group settings › Feishu, a Feishu tab in Bot settings, join cards that can link an existing group, and setup progress plus an overview on the admin Feishu page.
