# v0.4.19

新增 Intel Mac 桌面端，本机 Agent 一句话自助接入，Bot 头像可跟随 Agent。
Adds the Intel Mac desktop app, one-message self-onboarding for local Agents, and Bot avatars that follow their Agent.

## 桌面端 / Desktop

- 新增 Intel 芯片 Mac 的桌面端安装包（`Gonggong_<版本>_x86_64.dmg`），与 Apple 芯片版分别签名公证、各自自动更新。
  Adds a desktop app for Intel Macs (`Gonggong_<version>_x86_64.dmg`), signed and notarized separately from the Apple silicon build and updated on its own.

## 接入 / Onboarding

- 绑定新机器改为「发给你的 Agent」：把一句话发给本机 Agent，它自己装 gg、绑定机器并后台常驻，服务端自动建好 Bot 与私聊。客户端下载、命令行与 Docker 收进「其他方式」，接入码有效期改为 30 分钟。
  Binding a machine becomes Send to your Agent: paste one message to a local Agent and it installs gg, binds the machine and keeps it running; the server creates the Bot and the direct chat. Client downloads, the CLI and Docker move under Other ways, and bind codes last 30 minutes.
- 新增 `gg service install|uninstall|status`（macOS launchd、Linux systemd 用户服务）与 `gg login --create-bot <agent>`。
  Adds `gg service install|uninstall|status` (macOS launchd, Linux systemd user units) and `gg login --create-bot <agent>`.

## Agent

- Gemini CLI、CodeBuddy、pi、DeepSeek Harness 改为内置 Agent 插件；市场按 Skill / 创作 / 工具 / Agent / 供应商预设分类。
  Gemini CLI, CodeBuddy, pi and DeepSeek Harness become built-in Agent plugins, and the market filters by Skill, Creative, Tools, Agents and Provider presets.
- Bot 头像新增「跟随 Agent」，按 Agent 显示官方形象，新建 Bot 默认使用。
  Bot avatars add Follow Agent, showing the Agent's official look; new Bots use it by default.

## 手机端 / Mobile

- 滑动消息区时收起顶部条与输入框，回到底部或点输入区即恢复。
  Scrolling the messages hides the top bars and shrinks the composer; scrolling back to the bottom or tapping the composer restores them.

## 修复 / Fixes

- 桌面端从 Dock 启动时也能找到 nvm、volta、fnm、asdf、pnpm、bun 装的 claude / codex。
  The desktop app launched from the Dock finds claude and codex installed through nvm, volta, fnm, asdf, pnpm or bun.
- Bot 提示词里的 `{cli}`、`{pkg}` 等字面量原样传给 Agent；建 Bot 失败不再丢失已生效的新令牌。
  Literals such as `{cli}` and `{pkg}` in Bot prompts reach the Agent unchanged, and a failed Bot creation no longer loses the new token that already took effect.
