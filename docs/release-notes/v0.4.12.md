# v0.4.12

本次支持在网页中升级 Linux daemon，并完善机器接入、Git 访问和自检流程。

This release adds web-based upgrades for Linux daemons and improves machine onboarding, Git access and self-checks.

## 机器管理 / Machine management

- Linux 命令行 daemon 可在网页「机器管理」中点击「立即升级」；下载新版后等机器空闲再自动重启，不打断正在运行的任务。
  Linux CLI daemons can be upgraded from the web machine page. The new version is downloaded first, then the daemon restarts once idle without interrupting running tasks.
- 机器管理重组为「机器与 Bot」，新增首次使用与三步绑定流程、Git 访问配置及网页自检。
  Machine management is reorganized as Machines & Bots, with first-use guidance, three-step binding, Git access configuration and web self-checks.
- Docker 机器支持首次启动自动绑定。
  Docker machines can bind automatically on first start.

## 其他改进 / Other improvements

- 提问中 @ 的群成员也可作答。
  Group members @-mentioned in a question can answer it.
- 点击「开启新会话」后，供应商切换提示立即消失。
  The provider-change notice disappears immediately after starting a new session.

## 升级 / Upgrade

- 请先部署最新服务端，再升级客户端。旧 Linux daemon 需要先手动升级一次到 v0.4.12，之后才能在网页中一键升级。
  Deploy the latest server before upgrading clients. Existing Linux daemons must be upgraded manually once to v0.4.12; later upgrades can be started from the web.
