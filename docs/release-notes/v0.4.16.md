# v0.4.16

本次「帮我审批」改为内置审核优先：官方供应商下的 Claude、Codex 交给 agent 自带的审核把关，几乎不再打扰；AI 预审默认关闭，需要时在 Bot 里选模型开启。另外新增 Gemini CLI 与 CodeBuddy 两种 Agent。

Review for me now prefers the agent's built-in review: Claude and Codex on their official services hand approvals to the agent's own reviewer and rarely ask. AI pre-review is off by default; pick a model in the Bot to turn it on. Gemini CLI and CodeBuddy join as agents.

## 审批 / Approval

- 「帮我审批」下，Claude 官方登录用 auto 模式、Codex 官方 ChatGPT 登录用 agent 模式审批；运行开头注明本次由谁审。第三方供应商（如 Kimi）用不了内置审核，由共工规则把关。
  Under Review for me, Claude on its official login runs in auto mode and Codex on an official ChatGPT login in agent mode; each run says who reviews. Third-party providers (such as Kimi) have no built-in review and use Gonggong's rules.
- 开了「禁止直推基准分支」的群，推送基准分支仍发卡片给你。
  In groups with direct pushes to the base branch blocked, pushing to it still comes to you as a card.
- AI 预审默认关闭，要用时在 Bot 设置「AI 预审」里选一个小模型；已有 Bot 升级后一律关闭。
  AI pre-review is off by default; pick a small model under AI pre-review in the Bot settings to use it. Existing Bots have it turned off.
- 审批规则更严：越界读取、外来代码、改过配置后的脚本不再自动放行；审批卡片显示完整命令；恢复「本次运行免审批」，新增「本次会话不再问」。
  Stricter rules: reads outside the workspace, foreign code and scripts after their config changed are no longer allowed automatically; cards show the whole command; Skip approvals for this run returns and Don't ask again this session is added.

## Agent

- 新增 Gemini CLI（机器供应商支持 Gemini 协议）与 CodeBuddy。
  Gemini CLI (machine providers speak the Gemini protocol) and CodeBuddy are new agents.
- Bot 闲置超过 6 小时后下次对话自动开新会话，省去失效缓存的 token。
  A Bot idle for over 6 hours starts a new session next time, saving tokens on an expired cache.

## 话题 / Threads

- gonggong MCP 新增 `thread_create`：Bot 可在群聊里开一个话题，并指派一个 Bot 在话题里接手，适合把一项任务拆出去单独讨论和推进；每轮最多开 3 个，仅限群聊，发起人自动关注该话题。
  The gonggong MCP adds `thread_create`: a Bot can open a thread in a group chat and assign a Bot to take it over there, handy for splitting a task out to discuss and drive on its own. Up to 3 per turn, group chats only; the requester follows the thread automatically.
