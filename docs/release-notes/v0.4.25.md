# v0.4.25

本次同步更新 daemon 与桌面客户端。
This release updates both the daemon and desktop app.

- 修复独立 Claude 配置目录无法切换模型、官方登录被误判为第三方服务的问题。刷新模型时会重新探测各配置目录。
  Fix model switching and incorrect third-party service detection for official Claude sign-ins in separate configuration directories. Refreshing models now reprobes those directories.
- 「帮我审批」不再使用 AI 预审。符合规则的操作自动放行，其余仍由用户确认。
  Assisted approvals now skip AI pre-screening. Operations that match a rule are approved automatically; the rest still require user confirmation.
- 统一 `gg` 和 `gg-cast` 的中英文术语与提示。
  Standardize Chinese and English terminology and prompts in `gg` and `gg-cast`.
