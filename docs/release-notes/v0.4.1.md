# v0.4.1

macOS 桌面端新增「关闭窗口后隐藏程序坞图标」设置。

This release adds a macOS preference to hide the Dock icon when the desktop window closes.

## Git 管理 / Git management

- 同时包含已合入 main 的 Git 管理第二期 R1–R5：提交与差异查看、检出/拉取/推送、交互式变基、三栏冲突解决、文件注解与贮藏、受控 Git 操作控制台。
  This release also contains the Git-management phase two R1–R5 work already on main: commit and diff views, checkout/pull/push, interactive rebase, three-way conflict resolution, file annotations and stashes, and a guarded Git command console.

## 使用方式 / Usage

- 在「设置」中开启「关闭窗口后隐藏程序坞图标」。关闭窗口后仅保留菜单栏图标，可从菜单栏「打开」恢复窗口和程序坞图标。
  Enable "Hide the Dock icon when the window closes" in Settings. Closing the window leaves only the menu-bar icon; choose "Open" there to restore the window and Dock icon.
- 关闭窗口不会退出后台 daemon。该设置默认关闭，保持原有行为。
  Closing the window does not stop the background daemon. The preference is off by default, preserving the previous behavior.

## 升级 / Upgrade

- 服务端部署时会自动执行迁移 `0080`，给 `git_operations` 增加 `detail` 列，只新增列，不改写旧数据。
  Server deployment automatically runs migration `0080`, adding `git_operations.detail` without rewriting existing data.
- 完整使用新的 Git 协议能力需要配套 daemon 与桌面端升级；本次 macOS 设置不涉及协议或数据库。
  The new Git protocol capabilities require matching daemon and desktop upgrades. The new macOS preference itself does not change the protocol or database.
- 已安装 v0.2.0 及以上客户端可自动更新。
  Clients on v0.2.0 and later can update automatically.
