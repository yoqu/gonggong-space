# v0.4.1

macOS 桌面端新增「关闭窗口后隐藏程序坞图标」设置。

This release adds a macOS preference to hide the Dock icon when the desktop window closes.

## 使用方式 / Usage

- 在「设置」中开启「关闭窗口后隐藏程序坞图标」。关闭窗口后仅保留菜单栏图标，可从菜单栏「打开」恢复窗口和程序坞图标。
  Enable "Hide the Dock icon when the window closes" in Settings. Closing the window leaves only the menu-bar icon; choose "Open" there to restore the window and Dock icon.
- 关闭窗口不会退出后台 daemon。该设置默认关闭，保持原有行为。
  Closing the window does not stop the background daemon. The preference is off by default, preserving the previous behavior.

## 升级 / Upgrade

- 仅 macOS 桌面端界面与窗口行为变化，不涉及服务端或数据库迁移。
  This changes only the macOS desktop interface and window behavior. No server or database migration is involved.
- 已安装 v0.2.0 及以上客户端可自动更新。
  Clients on v0.2.0 and later can update automatically.
