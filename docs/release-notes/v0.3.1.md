这一版的重点是 **Bot 共享**：把自己的 Bot 共享给同事，对方就能直接私聊它、查看它的能力，而你的目录和审批权都不会交出去。另外带来了团队 Skill、按仓库拆分的 diff 和更少的审批打扰。

The highlight is **Bot sharing**: share your Bot with teammates so they can DM it and see what it can do, without handing over your directories or your approval rights. Also new: team Skills, per-repo diffs and fewer approval prompts.

## 亮点 / Highlights

- **Bot 共享 / Bot sharing** —— 在「编辑 Bot → 共享」里添加成员；对方左侧出现「共享给我」，在 Bot 页点「私聊」即可使用。每个共享私聊使用独立的托管工作区，不会碰到主人的默认目录；命令审批仍由主人处理，可直接在通知里批准或拒绝；取消共享后对方的私聊保留历史、转为只读。
  Add teammates under Edit Bot → Sharing; they see it under "Shared with me" and start a DM from its page. Each shared DM works in a managed workspace of its own, never the owner's default folder; approvals stay with the owner, who can approve or reject right from the notification; once unshared, their DMs keep the history and turn read-only.
- **Bot 详情页 / Bot page** —— 按编辑表单的分组（基本信息、运行配置、权限、高级、共享）展示全部配置，宽屏双栏、窄屏配置在前。
  Every setting, grouped like the editor (basics, runtime, access, advanced, sharing); two columns on wide screens, settings first on narrow ones.
- **团队 Skill / Team Skills** —— 在配置中心、团队与群设置里上传和在线编辑 Skill，保留历史版本可回滚；运行时自动下发给 Claude Code 与 Codex，Agent 也能通过内置 MCP 管理。
  Upload and edit Skills in the config center, team and group settings, with version history and rollback; delivered to Claude Code and Codex on each run, and manageable by agents through the built-in MCP.
- **协作细节 / Collaboration** —— 群成员可批量添加，普通成员也能拉人（群设置可改为仅管理员）；私聊可改名；输入栏上方固定显示运行中的 Agent，点击定位到运行卡片。
  Add several members at once; members may invite (or admins only, per group); DMs can be renamed; running agents are pinned above the composer and jump to their run card.
- **按仓库拆分的 diff / Per-repo diffs** —— 工作区里的子模块与嵌套仓库分别统计改动和 Git 状态；中文文件名不再显示为八进制转义。
  Submodules and nested repos get their own changes and git status; Chinese file names are no longer shown as octal escapes.
- **更少的审批 / Fewer approvals** —— 只读命令免审；「始终允许」记录最小前缀并跨群、跨重启生效；高危命令始终询问。
  Read-only commands run unasked; 始终允许 remembers the smallest prefix across groups and restarts; dangerous commands always ask.
- **一句话发布客户端 / Publish clients from chat** —— 内置 MCP 新增 `client_release_publish`：系统管理员在群里让 Bot 把本机构建好的 `gg`、gg-cast 或桌面端安装包发布到当前空间，无需在服务器上执行脚本或输入管理员密码（需要先把服务端升级到本版本）。
  New built-in MCP tool `client_release_publish`: a sysadmin can ask a Bot to publish `gg`, gg-cast or desktop installers built on its machine to the current space, with no server-side script or admin password (the server must run this release first).
- **飞书 / Feishu** —— 在飞书客户端内打开即静默登录；飞书群与共工群成员双向同步。
  Silent sign-in when opened inside Feishu; two-way member sync between Feishu groups and Gonggong groups.

## 升级须知 / Upgrade notes

- Bot 共享、团队 Skill 与 `client_release_publish` 需要服务端与客户端都升级到 v0.3.1；服务端启动时自动执行数据库迁移。
  Bot sharing, team Skills and `client_release_publish` need both the server and the clients on v0.3.1; the server applies database migrations on start.
- v0.2.0 及以上的 `gg` 与桌面端会自动更新到本版本。
  `gg` and desktop apps from v0.2.0 on update themselves to this release.
