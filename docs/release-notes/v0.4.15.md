# v0.4.15

本次把命令审批收成一个「审批方式」三选一：每次问我、帮我审批、完全允许；「帮我审批」由 AI 先评估，改用最小模型和精简会话，开销降到每次几千 token。

This release folds command approval into a single choice of three: Ask me every time, Review for me, and Allow everything. Review for me has an AI assess requests first, now on the smallest model in a lean session, costing a few thousand tokens per assessment.

## 审批 / Approval

- 「帮我审批」：规则没放行的请求先由 AI 评估，低风险且明显是用户要求的自动批准，其余仍交给主人，审批卡片附上风险和理由；高危命令、推送受保护基准分支和客户端发版始终由主人确认。
  Review for me: requests the rules don't allow are assessed by an AI first; low-risk ones the user clearly asked for are approved automatically, the rest still go to the owner with the risk and reasoning on the card. Dangerous commands, pushes to a protected base branch and client releases always need the owner.
- 预审在空目录里进行，自动选用 agent 提供的最小模型（如 Haiku、mini）和最低推理强度；Claude 只用一句话的系统提示、不带工具，不再加载项目说明和 MCP。
  Reviews run in an empty directory on the smallest model the agent offers (such as Haiku or mini) at the lowest reasoning effort; Claude gets a one-line system prompt and no tools, without project instructions or MCP.
- 桌面端与 `gg bots` 按新的审批方式显示 Bot 设置。
  The desktop app and `gg bots` show Bot settings with the new approval modes.

## 其他 / Other

- 产物单版上限从 50MB 放大到 200MB。
  The size limit of one artifact version grows from 50MB to 200MB.
- 群里的最终回复只保留主 agent 最后一次工具调用之后的正文。
  The final reply in a group keeps only the text after the main agent's last tool call.
- 桌面端已下载更新、等待重启时继续检查新版本，久开跨多个版本时一次升到最新。
  While a downloaded update waits for a restart, the desktop app keeps checking for newer versions, so an app left open across several releases updates straight to the latest.
