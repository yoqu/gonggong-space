# v0.4.20

接入码过期改为网页确认，运行里的联网搜索合成一行。
Expired link codes switch to web confirmation, and web searches in runs collapse into one line.

## 接入 / Onboarding

- `gg` 遇到过期或已用的接入码不再退出：发起接入申请，打印确认链接与 4 位核对码，网页确认后自动完成绑定。
  `gg` no longer exits on an expired or used link code: it files a link request, prints a confirmation link and a 4-digit check code, and finishes binding once confirmed on the web.

## 运行 / Runs

- 联网搜索合成一行：搜索中显示「正在搜索 “query”」并展开来源，结束后收起为「已搜索 N 个网站」。
  Web searches collapse into one line: Searching "query" with sources while running, then Searched N sites when done.

## 网页端 / Web（已随服务端上线 / already live）

- 原型分享支持密码访问与锁定版本；分享页默认进入可点击预览。
  Prototype shares support password access and pinned versions, and open in a clickable preview.
- @ 成员、拉 Bot、加成员等列表支持拼音检索（全拼、首字母、混拼）。
  Member, Bot and invite pickers support pinyin search (full, initials or mixed).
- 发消息乐观插入，回车即出现；新增语音条与自绘视频播放器。
  Messages appear as soon as you press Enter, with a new voice-note player and a custom video player.
