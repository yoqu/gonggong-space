# v0.4.4

本次新增网页终端，校验服务器证书，并改进对话输入与 Git 状态展示。

This release adds a web terminal, verifies the server certificate, and improves chat input and Git status.

## 终端 / Terminal

- 工作台新增「终端」标签：在 Bot 所在机器的工作区里打开交互式 Shell，只有机器主人可用，空闲会话自动回收。目前支持 macOS 与 Linux 机器。
  The workbench adds a Terminal tab: an interactive shell in the Bot's workspace on its machine, available only to the machine owner; idle sessions are reaped. macOS and Linux machines are supported for now.
- 终端输出中的网址与工作区文件路径可点击打开；粘贴、复制与搜索快捷键不会与浏览器重复触发。
  URLs and workspace file paths in terminal output are clickable; paste, copy and search shortcuts no longer also trigger the browser's own action.

## 安全 / Security

- daemon 连接服务器时校验 HTTPS 证书，不再接受任意证书。公网证书无需操作；自签证书的服务器请用 `gg login --fingerprint` 或 `--ca-file` 重新绑定。
  The daemon now verifies the server's HTTPS certificate instead of accepting any. Publicly trusted certificates need no action; for a self-signed server, bind again with `gg login --fingerprint` or `--ca-file`.
- 非本机服务器必须使用 `https://`。
  Servers other than localhost must use `https://`.

## 对话与 Git / Chat and Git

- 对话中的模型选择菜单可直接「刷新模型」，列表为空或读取失败时也能重试。
  The model menu in chat can refresh models directly, including when the list is empty or failed to load.
- 修复 `@共字君Codex /new` 这类输入在选择命令后被改写的问题。
  Fix `@Bot /new`-style input being rewritten after picking a command.
- 群聊顶部显示未提交改动的新增与删除行数（超过 99 显示 `99+`），不统计 `.gitignore` 忽略的文件。
  The chat header shows added and removed lines of uncommitted changes (`99+` above 99), excluding files ignored by `.gitignore`.
- 切换会话时保持会话列表的滚动位置。
  The conversation list keeps its scroll position when switching conversations.

## 升级 / Upgrade

- 本次需要服务端与桌面端配套升级，无数据库迁移。
  Deploy the server and upgrade the desktop app together; there is no database migration.
- 已安装 v0.2.0 及以上客户端可自动更新。
  Clients on v0.2.0 and later can update automatically.
