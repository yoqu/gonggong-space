# v0.4.34

本次更新 daemon 与 macOS、Windows 桌面客户端。
This release updates the daemon and the macOS and Windows desktop apps.

- Claude 配置目录供应商的模型探测会应用各自的 `--settings`，模型、默认模型和推理强度按供应商隔离；旧探测缓存会失效并重新探测。探测未完成或失败时，不再用官方模型列表掩盖结果。
  Claude config-directory providers now probe with their own `--settings`, keeping models, default models, and reasoning effort isolated per provider. Old probe caches are invalidated and refreshed, and the official catalog no longer masks an unfinished or failed probe.
- daemon 上报会话实际使用的模型与缓存 Token 用量，供用量统计展示。
  The daemon reports the model actually served and cache-token usage for usage analytics.
- 同目录并行写入选择等待时，运行卡会显示正在等待的运行；取消等待从最多 30 秒缩短到 5 秒。
  When waiting to write in a shared workspace, run cards identify the runs being waited on. Cancelling a wait is reduced from up to 30 seconds to 5 seconds.
