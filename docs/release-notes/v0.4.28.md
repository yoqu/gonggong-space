# v0.4.28

本次同步更新 daemon 与 macOS、Windows 桌面客户端。
This release updates the daemon and the macOS and Windows desktop apps.

- 在网页预览卡片上选择「托管到服务器」，或让 Bot 构建后托管静态目录。托管后的网页可在「作品」中找到，Bot 电脑离线也能访问。仅托管静态文件，不运行后端服务。
  Select Host on Server from a web preview card, or ask a bot to build and host a static directory. Hosted sites appear in Works and remain available when the bot's computer goes offline. Hosting serves static files only; it does not run backends.
- 原型画布支持手机双指缩放，选中屏幕时左侧页面列表同步高亮；在标记或直接编辑模式下，按住 Alt（Mac 上为 Option）点击仍可操作页面。
  The prototype canvas supports pinch-to-zoom on mobile and highlights the selected screen in the page list. Alt-click (Option-click on Mac) interacts with the page in markup or edit mode.
- 原型画布新增「交互」工具，可直接操作弹窗、标签和跳转，支持触屏；切回标记或编辑时保留页面状态。
  Use the canvas Interaction tool to open dialogs, switch tabs, or follow links with a mouse or touch. Page state is preserved when you switch back to markup or editing.
- Webhook 部署通知支持飞书原生卡片。
  Deployment webhooks support native Feishu cards.
