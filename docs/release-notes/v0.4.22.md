# v0.4.22

Agent 管理完成重构，并新增 5 个 Agent；桌面端与 `gg` 同步升级。
Agent management gets a full refresh, with 5 new agents; the desktop app and `gg` upgrade together.

## Agent

- Agent 页在网页端与桌面端共用：集中查看 Node.js 状态、已安装与可安装 Agent，详情里管理版本、登录、模型与默认供应商。
  The Agent page is shared by web and desktop: see Node.js status, installed and available agents, and manage versions, sign-in, models and default providers in one place.
- 供应商改为「厂商 + 按协议端点」，同一个厂商可配置多套协议地址；Agent 注册表统一名称、图标、安装方式与登录方式。
  Providers now combine a vendor with per-protocol endpoints, so one vendor can have several endpoint sets; a shared agent registry defines names, icons, installation and sign-in.
- 新增 GitHub Copilot CLI、Goose、Kimi Code、OpenCode 与 Qwen Code，均通过 ACP 接入。
  Adds GitHub Copilot CLI, Goose, Kimi Code, OpenCode and Qwen Code, all connected over ACP.

## daemon

- 探测到空模型列表时不再把它当作成功缓存；手动刷新保留旧列表，后台探测失败后每 5 分钟重试，直到成功。
  An empty model-list probe is no longer cached as success; manual refresh keeps the previous list, and failed background probes retry every 5 minutes until they succeed.

## 网页端 / Web

- Bot 头像新增在线、运行中、离线与 Agent 缺失状态角标；聊天顶部和 Bot 名片新增一键「新对话」，名片可查看 Bot 简介。
  Bot avatars show online, working, offline and missing-agent states; chats and Bot cards get one-click New chat, and Bot cards show a profile summary.
- 多条通知会堆叠展开，附件上传完成显示对勾，运行进度完成后拨动画勾并划线，数字与分段控件加入顺滑动效。
  Multiple notifications stack and expand, attachments show a completion check, finished progress steps tick and strike through, and numbers and segmented controls animate smoothly.
- 消息正文调整为 14px，并完成这轮 UX 走查中的相关修复。
  Chat body text is now 14px, with the related fixes from this UX review pass.

## 品牌 / Brand

- 应用、桌面端图标与文档站统一换上「对眼 gg」新 logo，共字君、登录页与启动屏同步适配品牌蓝和琥珀。
  The app, desktop icons and docs site adopt the new "gg" logo, with 共字君, sign-in and splash screens updated for the brand blue and amber palette.
