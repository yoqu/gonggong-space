# v0.4.17

新增 pi 与 DeepSeek Harness 两种 Agent。

pi and DeepSeek Harness join as agents.

## Agent

- 新增 pi：经 pi-acp 运行，共工自带的 pi 扩展为它接入共工工具与 MCP、Bot 指令和审批（pi 本身不问权限，改动类工具调用改由共工按权限档位与审批规则把关）。沿用 pi 自己的登录，需要 pi ≥ 0.99。
  pi is a new agent. It runs through pi-acp, and Gonggong's pi extension brings it the Gonggong tools and MCP servers, the Bot's instructions and approvals (pi asks for nothing itself; Gonggong judges its tool calls that change things by the Bot's tier and approval rules). It keeps pi's own login and needs pi ≥ 0.99.
- 新增 DeepSeek Harness：官方 `dsh --profile acp`，权限档位对应它的沙箱，机器供应商可填 DeepSeek API Key。需要 Node.js ≥ 24.9。
  DeepSeek Harness is a new agent: the official `dsh --profile acp`, its sandbox following the Bot's tier, with a DeepSeek API key as a machine provider. It needs Node.js ≥ 24.9.

## 界面 / Interface

- 运行卡片摘要过长时限三行（悬停看全文），进度清单过高时内部滚动，按钮始终可见。
  Long run card summaries are clipped to three lines (hover for the rest), tall progress lists scroll inside, and the buttons stay visible.
