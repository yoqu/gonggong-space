Gonggong Space now has a Windows desktop app, and binding a machine is simpler: no certificate fingerprints to check, and `http://` or self-signed servers bind straight from the link. No server yet? Sign up on the demo at [http://gg.uyoqu.com](http://gg.uyoqu.com/).

## 亮点 / Highlights

- **Windows 桌面端 / Windows desktop app** —— NSIS 安装包（中英文），内置 daemon、托盘与自动更新；桌面端启动的 git、node 等子进程不再弹出控制台窗口。
  NSIS installer (Chinese and English) with the built-in daemon, tray and auto update; child processes such as git and node no longer open console windows.
- **绑定即用 / Binding just works** —— `gg` 与桌面端不再校验或固定服务器的 HTTPS 证书：自签证书直接可用，服务器换证书后无需重新绑定；`http://` 可连接任意服务器（之前仅限本机）。旧服务器复制出的 `--fingerprint` / `fp=` 仍可粘贴，会被忽略。
  `gg` and the desktop app no longer verify or pin the server's HTTPS certificate: self-signed certificates work as is and a certificate change needs no re-binding; `http://` works for any server (it was loopback-only). `--fingerprint` / `fp=` copied from older servers are still accepted and ignored.
- **演示环境 / Demo environment** —— 默认演示环境 [http://gg.uyoqu.com](http://gg.uyoqu.com/)，注册账号后用 `gg login --server http://gg.uyoqu.com --code <绑定码>` 或桌面端粘贴接入链接即可体验；仅供试用，请勿存放敏感代码和数据。
  The default demo at [http://gg.uyoqu.com](http://gg.uyoqu.com/): sign up, then bind with `gg login --server http://gg.uyoqu.com --code <code>` or paste the bind link into the desktop app. For trying things out only; keep sensitive code and data elsewhere.
- **Windows 细节 / Windows polish** —— 双击 `gg.exe` 会说明用法并等待回车，不再一闪而过；首次运行不再报日志目录错误；选择工作目录时可切换磁盘；仓库统一 LF 换行，修复 Windows 检出后 Docker 部署的服务端无法启动。
  Double-clicking `gg.exe` explains how to run it instead of flashing; no log-directory error on first run; the folder picker switches between drives; LF line endings everywhere fix the Docker server failing to start from a Windows checkout.

## 升级须知 / Upgrade notes

- **绑定 `http://` 远程服务器（含演示环境）需要 v0.3.0**：旧版 `gg` 与桌面端只允许 `http://` 连本机。v0.2.0 会自动更新到本版本。
  **Binding a remote `http://` server (including the demo) needs v0.3.0**: older `gg` and desktop builds allow `http://` only to this machine. v0.2.0 updates itself to this release.
- 已绑定的机器无需重新绑定；本机配置里旧的 `certSha256` 会被忽略。
  Bound machines need no re-binding; the old `certSha256` in the local config is ignored.
- **安全提示**：daemon 不再校验服务器证书，HTTPS 仍加密传输，但无法防范主动的中间人冒充服务器；敏感场景请在内网或 VPN 内使用。
  **Security note**: the daemon no longer verifies the server certificate. HTTPS still encrypts traffic but cannot stop an active man in the middle impersonating the server; use a private network or VPN for sensitive work.
- 服务端升级后会自动执行数据库迁移。/ The server applies database migrations automatically on start.
