# v0.4.27

本次同步更新 daemon 与 macOS、Windows 桌面客户端。
This release updates the daemon and the macOS and Windows desktop apps.

- 升级后，话题与群主会话可并行运行，同一会话仍按顺序执行，总并发仍受 Bot 的并发上限约束。需要共用工作目录时，仍会显示「目录忙」确认卡。旧版 daemon 和强制同步群继续按群排队。
  After upgrading, threads and the main conversation can run in parallel within the bot's concurrency limit. Each conversation still runs one turn at a time, and a shared workspace still prompts for confirmation. Older daemons and groups with forced sync continue to queue per group.
- 话题里的 Bot 可以用 `hand_off` 的 `thread: 'main'` 参数把任务交到群主会话，包括交给主会话里的自己。
  Bots in threads can use `hand_off` with `thread: 'main'` to delegate to the main conversation, including to themselves.
