# v0.4.23

子 Agent 的运行过程与实时上下文更清楚，桌面端和 `gg` 同步升级。
Sub-agent runs and live context are easier to follow, with desktop and `gg` updated together.

## 子 Agent / Sub-agents

- 子 Agent 现在使用固定的角色头像和独立泳道，运行中显示呼吸光圈，完成或失败带状态角标；底部汇总栏可以展开全部子 Agent，点击胶囊可定位到对应步骤。
  Sub-agents now use stable character avatars and separate lanes, with a breathing ring while working and completion or failure badges. The activity dock expands the full list, and each chip jumps to its lane.

## 运行 / Runs

- 运行页的「上下文」在运行中实时更新，区分已统计与估算增量，数字和色块随用量平滑变化。
  The Context tab updates during a run, separating reported usage from estimated increments, with smoothly animated numbers and usage bars.

## 群聊与创作 / Chat and creation

- 发起会话时可以同时创建并关联飞书群；如果飞书群创建失败，共工群会保留，并可在群设置中重试。
  New-group creation can also create and link a Feishu group. If Feishu fails, the Gonggong group is kept and setup can be retried in group settings.
- 添加成员选择器显示成员头像或默认头像；创作面板的步骤状态、必填提示和稍后处理预览更准确。
  The member picker shows member or generated avatars, and the creation panel and Later previews give more accurate validation and plain-text summaries.

## Agent 与 daemon / Agent and daemon

- Claude Code 使用本机配置目录时，可以从该目录探测并缓存可用模型，不再出现模型列表为空。
  Claude Code providers that use a local config directory now probe and cache their models instead of showing an empty list.
- Gemini 选择已不支持的 Google 账号登录时直接说明原因，未登录时不再反复打开浏览器；桌面端 Agent 页的空白崩溃也已修复。
  Gemini now explains unsupported Google-account sign-in instead of repeatedly opening a browser, and the blank desktop Agent page is fixed.
- 新建 Bot 默认选择在线机器；Agent 详情在窄屏下可以完整查看长路径、升级和安装命令。
  New Bots default to an online machine, and Agent details keep long paths and install or upgrade commands usable on narrow screens.

## 市场 / Market

- 「从已有条目引入」不再列出只作用于机器的 Agent 和供应商预设插件。
  Import from existing entries no longer lists machine-only Agent and provider-preset plugins.
