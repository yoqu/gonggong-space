# AIWS 快速开始

AIWS 让团队在一个网页群聊里指挥 AI 干活。你在群里 `@` 一个 bot 说需求，它会在**某位成员的电脑**上调用 Claude Code 或 Codex 真正动手（读代码、改文件、跑命令），过程和结果实时回到群里。

先认识三个词：

| 名词 | 是什么 | 打个比方 |
| --- | --- | --- |
| **daemon（aiws）** | 装在你电脑上的小程序，负责接活、调用本机 AI | 你电脑上的「接单员」 |
| **bot** | 群里可以 `@` 的 AI 成员，固定跑在某台电脑上 | 一个 AI 同事 |
| **群** | 大家和 bot 一起聊天干活的地方，可绑定一个 git 仓库 | 项目群 |

整体流程：**登录网页 → 绑定电脑 → 建 bot → 建群拉 bot → @bot 干活**。

---

## 一、管理员：把服务跑起来（只做一次）

> 普通成员跳过本节，向管理员要「网址 + 账号 + 初始密码」即可。

```bash
pnpm install
pnpm db:up                                   # 启动数据库
AIWS_ADMIN_PASSWORD=初始密码 pnpm dev:server   # 启动服务器（默认 8787 端口）
pnpm dev:web                                 # 启动网页（默认 http://127.0.0.1:5173）
```

1. 浏览器打开网页，用账号 `admin` + 上面的初始密码登录，按提示**修改密码**。
2. 进入「管理 → 账号与角色」，给每位成员建账号，把网址、账号、初始密码发给他们。

正式部署（HTTPS、密钥、备份）见 `docs/plan/安全说明.md`、`docs/plan/发布与平台说明.md`。

---

## 二、成员：准备你的电脑

需要安装：

- **git**
- **Node.js 22 或更高**（含 npm）
- **Claude Code** 和/或 **Codex CLI**，并在终端里**先登录好**（能正常对话即可）

然后按下一节装好 aiws。

---

## 三、安装 aiws

aiws 就是**一个可执行文件**，没有安装向导，放到命令行能找到的目录即可。按你的情况选一种：

| 你的情况 | 选哪种 |
| --- | --- |
| 管理员已经给了安装包 | **方式 A** |
| 手上有源码，想自己编译 | **方式 B** |
| 用 Mac，不想开终端窗口 | **方式 C**（桌面端） |

> 网页「绑定新机器」里的「下载」按钮暂未开放，目前只能用下面三种方式。

### 方式 A：用管理员给的安装包

文件名形如 `aiws-0.1.0-<系统>-<架构>`，按电脑选：

| 电脑 | 文件 |
| --- | --- |
| Apple 芯片的 Mac（M1/M2/M3…） | `aiws-<版本>-macos-aarch64` |
| Intel 芯片的 Mac | `aiws-<版本>-macos-x86_64` |
| Linux（x86 服务器/PC） | `aiws-<版本>-linux-x86_64` |
| Linux（ARM） | `aiws-<版本>-linux-aarch64` |
| Windows | `aiws-<版本>-windows-x86_64.exe` |

不确定芯片：Mac 点左上角  →「关于本机」；Linux 执行 `uname -m`。

**macOS / Linux：**

```bash
mkdir -p ~/.local/bin
mv ~/Downloads/aiws-0.1.0-macos-aarch64 ~/.local/bin/aiws   # 换成你拿到的文件名
chmod +x ~/.local/bin/aiws
xattr -d com.apple.quarantine ~/.local/bin/aiws 2>/dev/null  # 仅 macOS：去掉“来自互联网”标记，否则会被系统拦截
```

如果 `~/.local/bin` 还不在 PATH 里，把它加进去（zsh 为例，bash 改成 `~/.bashrc`）：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
```

**Windows：** 新建文件夹如 `C:\Users\<你>\aiws\`，把 exe 改名为 `aiws.exe` 放进去，并把该文件夹加入「系统环境变量 → Path」。（Windows 版目前未经真机验证，遇到问题请反馈。）

> 请放在**自己有写权限的目录**（如 `~/.local/bin`），不要放 `/usr/local/bin` 这类需要 sudo 的地方：服务器发布新版本后，aiws 会自动下载并替换自己，没有写权限就无法升级。

可选：核对文件完整性（管理员会一并给出 `SHA256SUMS`）：

```bash
shasum -a 256 ~/.local/bin/aiws   # 结果应与 SHA256SUMS 中对应一行一致
```

### 方式 B：从源码自己编译

**1. 装 Rust**（只需一次）：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env
rustc --version    # 需要较新的 stable（项目使用 Rust 2024 edition）
```

另外需要 C 编译器（加密库要用）：macOS 执行 `xcode-select --install`；Ubuntu/Debian 执行 `sudo apt install build-essential`。

**2. 编译并安装：**

```bash
cd ai-chat-master                        # 项目源码根目录
cargo build --release --locked -p aiws   # 首次约几分钟
mkdir -p ~/.local/bin
cp target/release/aiws ~/.local/bin/aiws
```

PATH 设置同方式 A。本机编译的文件不会被 macOS 拦截，不需要 `xattr` 那一步。

**管理员批量打包（给全员分发）**：在 Mac 上执行

```bash
bash scripts/release.sh                                  # 全部平台 + 桌面端
bash scripts/release.sh --only macos-aarch64,desktop     # 只打部分
```

产物在 `dist/<版本>/`：各平台 `aiws-*` 文件、`SHA256SUMS`、`manifest.json` 和 macOS 桌面端 `.dmg`。Linux / Windows 版在 Docker 里交叉编译，需要本机装好 Docker；macOS 版需要 `rustup target add aarch64-apple-darwin x86_64-apple-darwin`。把对应文件发给成员即可（发布到服务器、让已装的 aiws 自动升级见 `docs/plan/发布与平台说明.md`）。

### 方式 C：macOS 桌面端

桌面端自带 aiws，**不需要**再装命令行版本，也不用一直开着终端窗口。

- 拿到 `AIWS Daemon_<版本>_<架构>.dmg`（管理员用 `bash scripts/release.sh --only desktop` 打包；自己打包需先 `pnpm install`，并装好 Rust 和 Xcode 命令行工具），双击后把 **AIWS Daemon** 拖进「应用程序」。
- 安装包没有签名，第一次打开时 macOS 会提示「无法打开」：在「系统设置 → 隐私与安全性」底部点「仍要打开」（或在「应用程序」里右键图标 → 打开）。
- 打开后按引导粘贴绑定命令即可（见第五节）。关掉窗口后程序仍在菜单栏运行，要停止请在菜单栏图标里选「退出」。

### 装好后检查

```bash
aiws --version   # 能打印版本号说明装好了
aiws agents      # 能列出 Claude Code / Codex 说明 AI 工具也就绪
aiws doctor      # 绑定后再跑一次，检查连接、git 凭据、磁盘等
```

提示 `command not found` 说明 PATH 没配好，重新打开终端或检查上面的 PATH 设置。

> 首次运行时 aiws 会用 npm 自动下载 AI 适配器到 `~/.aiws/adapters/`，所以要能访问 npm 源。aiws 的所有本地数据都在 `~/.aiws/` 目录。

## 四、第一次登录网页

1. 打开管理员给的网址，输入账号和初始密码。
2. 按提示设置新密码。

---

## 五、绑定你的电脑

1. 网页右上角点**头像 → 绑定新机器 → 生成绑定码**。
2. 点「复制命令」，在你电脑的终端里粘贴执行，形如：
   ```bash
   aiws login --server https://服务器地址 --code 绑定码
   ```
   看到「绑定成功」即可。（用桌面端的话，直接把命令粘贴进桌面端。）
3. 启动接单：
   ```bash
   aiws run
   ```
   **这个窗口要一直开着**，关掉后你的 bot 就「离线」了（消息会排队，最多等 30 分钟）。桌面端用户跳过这一步，App 在运行就行。

> 绑定码只能用一次、会过期；失效了重新生成即可。
> 首次绑定会打印一个证书指纹，请与管理员公布的对一下，不一致就执行 `aiws logout` 并联系管理员。

---

## 六、创建你的 bot

1. 头像 → **我的 bot 与用量 → 新建 bot**。
2. 填写：
   - **名称**：群里 `@` 它用的名字，如 `后端助手`
   - **执行机器**：选你刚绑定的电脑
   - **Agent**：Claude Code 或 Codex
   - **系统提示词**（同时作为群内简介）：告诉它角色，如「后端接口开发，只改 server/ 目录」
3. 点「创建并绑定」。

创建后可在 bot 详情里调整：

| 设置 | 含义 | 建议 |
| --- | --- | --- |
| 触发范围 | 谁能 `@` 它干活：任何群成员 / 指定名单 / 仅本人 | 刚开始用「仅本人」最安全 |
| 默认权限档位 | 它能动多大范围；`full` 档强制只能指定名单触发 | 保持默认 |
| 并发上限 | 同时最多跑几个任务 | 保持默认 |

---

## 七、建群并开始干活

1. 左侧栏点 **新建群**（只想自己用就点 **新建私聊**）。
2. 填群名；如果要改代码，填 **git 仓库地址**并点校验；拉入你的 bot。
3. 在输入框里 `@bot名 你的需求`，例如：
   ```
   @后端助手 看一下登录接口为什么偶尔 500，找到原因后修复并跑测试
   ```
4. 回车后群里会出现**运行卡片**，点开右侧栏能看到：
   - **过程**：它每一步在想什么、做了什么
   - **diff**：改了哪些代码
   - **审批**：需要你批准的操作

没有 `@` 的消息不会触发 bot，只作为上下文补给它。可以发图片和附件（单个 ≤ 50 MB，每条 ≤ 10 个）。

---

## 八、要你拍板的时候

- **权限请求**：bot 想执行命令、写文件、访问网络等超出权限的操作时，会弹出卡片，**只有 bot 主人**能点「批准 / 拒绝」。超时未处理会自动拒绝，bot 会自己想别的办法。
- **向群成员提问**：bot 拿不准时会出选择题，发起人或 bot 主人作答即可。
- 右上角的**通知中心**会提醒你待处理的事。

---

## 九、常用指令

在输入框输入 `/` 会弹出候选：

| 指令 | 作用 |
| --- | --- |
| `/stop` | 停止运行；`/stop @bot` 只停某个 bot，不带 @ 则停本群全部 |
| `/new` | 开一个新会话（让 bot 忘掉之前的上下文） |
| `/cd` | 让 bot 直接在你本机某个目录里干活（仅分区模式；`--reset` 恢复） |

另外：运行中再发一条消息可以**打断并追加**要求；引用某条消息回复可以让 bot 针对它继续。

## 十、常见问题

| 现象 | 处理 |
| --- | --- |
| bot 显示离线 / 消息一直排队 | 确认电脑上 `aiws run` 还在运行 |
| 绑定时报证书错误 | 核对管理员公布的指纹，或按管理员给的 `--fingerprint` 参数绑定 |
| 新建 bot 时看不到 Claude Code / Codex | 先在终端装好并登录，然后重启 `aiws run` |
| 不知道哪里出问题 | 运行 `aiws doctor` 自检；`aiws logs --export` 导出诊断包发给管理员 |
| 想查本机绑定状态 | `aiws status` |
| 换电脑 / 不用了 | `aiws logout` 解除本机绑定 |
