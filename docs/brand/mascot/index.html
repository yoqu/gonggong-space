    落地说明

    • 骨架：画布 120×120，地面 y=108。四肢是带 transform-origin 与 --rest（静止角度）的分组，动作只写「相对下垂方向的角度」，所以同一套关键帧能驱动手、腿、字形笔画、气泡尾巴。
    • 状态切换：改根节点 data-a 即可，四肢有 0.25s 过渡，动作之间自然衔接；尊重系统「减弱动态效果」。
    • 接入：移植为 <Mascot kind action size /> React 组件，状态直接接 run 事件（thinking / tool_call / message / done / error）。
    • 头像：同一 SVG 换 viewBox 裁切头部，不需要另画。深色模式下线条色走 --ink token。
