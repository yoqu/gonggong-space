# 共工空间 logo 使用规范

## 1. 标志

- **创意**：两个 g 是一对搭档，也是一双看着你的眼睛。`gg` 是 CLI 的名字，也是 Gong Gong 的缩写。
- **版本**：横排（主用）、竖排、单独图形、单独文字。
- **文件**：
  - `gg-symbol.svg` 图形，`gg-symbol-small.svg` 小尺寸版（无瞳孔）
  - `gg-horizontal.svg` 横排，`gg-stacked.svg` 竖排，`gg-wordmark.svg` 文字
  - 带 `-reversed` 的用于深色底，带 `-black` / `-white` 的是单色版
  - `gg-app-icon.svg` 应用图标（墨色底）；网页图标在 `apps/web/public/`，桌面端图标在 `apps/desktop/src-tauri/icons/`

## 2. 留白

标志四周留出 **一个 g 的圆环半径** 的空白。留白随标志等比缩放，不用固定数值。

## 3. 最小尺寸

| 版本 | 屏幕 | 印刷 |
|---|---|---|
| 横排 | 宽 120 px | 宽 30 mm |
| 图形（带瞳孔） | 高 32 px | 高 8 mm |
| 图形（小尺寸版） | 高 16 px | 高 5 mm |

低于 32 px 一律用小尺寸版（`gg-symbol-small.svg`、`gg-app-icon-small.svg`、`favicon.svg`）。

## 4. 颜色

| 名称 | HEX | RGB | CMYK（近似） |
|---|---|---|---|
| 蓝 | `#3B7BFF` | 59 123 255 | 77 52 0 0 |
| 琥珀 | `#FFB224` | 255 178 36 | 0 30 86 0 |
| 墨 | `#10203A` | 16 32 58 | 72 45 0 77 |
| 白 | `#FFFFFF` | 255 255 255 | 0 0 0 0 |

- **可用搭配**：彩色标在白底或浅灰底；彩色标（白瞳孔）在墨底；白色单色标在蓝底；黑色单色标在白底。
- **不要**把彩色标放在蓝底或琥珀底上，同色的那个 g 会消失。
- 琥珀在白底上对比度低，不要单独用琥珀色做文字或细线。
- 图片或花纹背景上用应用图标版（带墨色底块），或用单色版。
- CMYK 是换算值，未打样；专色未指定。

## 5. 字体

- 标志里的「共工空间」与「GONGGONG SPACE」取自 Noto Sans SC（思源黑体，SIL OFL 开源许可），已转成轮廓，不依赖本机字体。
- 不要用键盘重新打一遍来代替标志文字。

## 6. 不要这样用

不拉伸、不旋转、不换色、不加阴影描边渐变、不调换两个 g 的颜色或顺序、不改变图形与文字的相对大小、不在小于 32 px 时保留瞳孔。

## 7. 已知事项

- 旋转 180° 读成「66」，有人会把 gg 读成「99」：使用时保持正向，并尽量和「共工空间」字样一起出现。
- 没有做商标查重，上线前需要查。
