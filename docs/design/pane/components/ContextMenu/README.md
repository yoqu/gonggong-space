# ContextMenu

右键菜单：在任意内容上按右键（或双指轻点）时，在指针位置弹出 `Menu`。最常见的是消息的右键菜单。

**你需要提供**：`items`（`Menu` 的菜单项）、`onSelect(value)`、`children`（被右键的内容）；可选 `defaultPosition`（演示用，初始即打开）。

- `messageMenuItems({self})` 给出消息的标准菜单：回复、回复话题、转发 / 拷贝、置顶、标记为待办、多选 / 自己的消息加「编辑」「撤回」，他人的消息加「删除」。破坏性操作放最后一组、红字。
- 右键菜单里的项目要和悬停操作条（`MessageActions`）一致，并且更全；只在菜单里的操作不要做成唯一入口。
- 点外部、按 Esc 或窗口失焦时关闭。

键盘：焦点在内容上时按 ⇧F10 或菜单键打开，菜单自动获得焦点，↑↓ 选择、Enter 确认、Esc 关闭。
